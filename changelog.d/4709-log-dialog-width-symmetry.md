## Fixed

- 三个日志弹窗（应用日志 / 任务执行日志 / 工作流库执行日志）加宽后左右留白不对称：内层面板重复声明了宽度类（`w-[calc(100vw-16px)]`），比被基类 `max-w-[calc(100%-2rem)]` 封顶的弹窗外壳宽出 16px，在 LTR 下向右溢出——左侧留白 16px 照旧、右侧贴边。宽度改由弹窗外壳给一次，内层面板作为外壳唯一的 grid 子项自动撑满，两侧各留 16px（#4709）。
- `@critical` 用例「日志弹窗默认够宽，且加宽按钮真的变宽」在 daily 负载下首跑假红（`Expected: > 1152 / Received: 1152`）：点击后的宽度是补间值，过渡首帧之前的「连续两眼同矩形」会把旧值误判成落定。量宽判据改为「矩形稳定且宽度已按预期方向移动」，并同批补上「加宽后左右留白对称」断言，钉住这次的修复（#4709）。
