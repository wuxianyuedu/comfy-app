## Fixed

- **「控件后行为」下拉不再被窗口下沿切掉（ISSUE #349）**：seed 行是参数表单的最后一行（画布节点里 outputs 不渲染，末尾就是它），而面板此前**固定向下弹**约 270px —— 节点贴近窗口下沿时，最后一个选项「随机值」整条落到视口之外，用户既看不到也点不到（截图里只露出前三项）。现在打开面板时按触发器的矩形算一次摆位：下方放不下就**翻到触发器上方**，并在两侧都装不下时偏向空间更大的一侧；同时给出 `max-height`（视口高度减留白）让面板自身滚动。左右也一并收口：默认右对齐触发器右沿、越界夹回视口、视口比面板还窄时收窄宽度。摆位判据抽成纯函数 `src/lib/floating-position.ts`（规范 17 第①层，脱离 React 直接单测），视图层只负责量矩形、把结果塞进 inline style；首帧用 `useLayoutEffect` 算位，不会先向下闪一下再翻上去。滚轮/缩放时重算，并给 24px 滞回，拖过视口中线不会上下翻来翻去。
