## Fixed

- 点开「仅服务端」的项目不再被要求重建：侧栏与「所有项目」那一屏读的是
  并集，所以「服务端有一行、本机索引里没有」的行看得见、点得着；而打开它这
  一跳读的是本地索引（`getProject(id)`）—— 索引里没有就交回 null，落点仍是
  「先创建或选择一个项目」那张闸门，用户对着一个已经存在的项目被要求再建一个
  （ISSUE #1874）。现在那一跳先 `hydrateProjectFromServer(id)` 把服务端这一行
  落进本机索引，再走原来的「设为活跃 + 落项目主页」；拉不到（离线 / 服务端也
  没有这一行）不抛，照旧渲染闸门。
