## Fixed

- **`pnpm ship --result` 轮询一个 `status=running` 的后台跑时，末行不再打
  「结论：exit 0 —— 全绿到终态」**：此前只读口与写链共用 `finish()` 的结论词，
  0 在只读路径上只表示「这次读成功」，却被读成「写链跑到终态且绿」，与上一行
  「这一跑没给结论」直接打架。现在单件动作（只读口 + 写侧快动作）的收尾那行改念
  「单件动作完成（**不代表**写链绿到终态）」，写链结论词不动。
- **`--result` 的退出码改为反映被跟踪那一跑的死活**：还在跑 ⇒ `4`（无终态、
  不是 0），被打断 ⇒ `2`，读不出来 ⇒ `2`，收口了照抄它的 `exitCode`；
  没有上一次（`missing`）仍是 `0`（合法读数「还没跑过」）。`pnpm ship:wait`
  另走落盘 JSON 的字段判定，不受此次改动影响。
