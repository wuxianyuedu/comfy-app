## Fixed

- **参数行的端点圆点不再压住参数名（ISSUE #355）**：画布节点 / 库内组合控件框外那三行（宽高比 / 百万像素 / 倍数）此前是 `pl-[2px]`，而端点 12px、圆心骑跨卡片左缘（-6）—— 圆点右沿正压在文字起点上，名字被圆点盖住。现在左内边距与节点上其他参数行同款（`pl-[14px]`），圆点与参数名之间留出同样的 8px 空隙。

## Added

- **「尺寸」这类多端口对外参数按端口各画一条线（ISSUE #355）**：宽高比 / 像素量 / 倍数由同一块组合控件录入，共同组成一个「尺寸」口 —— 默认状态下这三个端口各有一条线（编辑器画布与工作流库同一套规则，落在 `wiredTargetsForEntry`），不再只画自动判定挑中的那一条、让「尺寸」看着只有一个出口。作者手工改过落点后只留他指定的那一条（运行期该口只往那一个端口供值）。

- **工作流节点右侧列出「对外输出参数」（ISSUE #355）**：左列说「这个工作流对外要什么、落到哪一行」，右列说「它对外给什么」（`images` 之类）。卡片视觉与左侧输入卡片共用同一张本体，端点骑跨卡片**左**缘，线从宿主卡片的输出行圆点连过来；输出不参与映射，这一列恒为只读（无拖拽、无「恢复默认」）。

- **宿主卡片的输出行补上端口圆点（ISSUE #355）**：库内预览的 `images IMAGE` 行此前没有端点（项目画布 / 编辑器上一直有），现在是同一颗 `PortHandle`，右列的连线正是从它出发。
