## Changed

- **模型库不再按目录启用 / 停用**：所有 ComfyUI 模型目录默认全部启用，与 ComfyUI
  自身的默认状态一致；扫描以 `GET /api/models` 返回的目录清单为准。随之下线
  「模型目录配置」入口与弹窗，`model.configSave` / `model.configDelete` 两个写接口
  一并退役，`UserModelConfigRepository` 不再参与扫描与创作面模型并集。
- **模型库改为左侧目录 + 右侧列表**：左侧一列目录（展示名 + 数量，`aria-current`
  标记选中），右侧只显示该目录的模型；顶部类型筛选 chip（含「全部」）整排退役。
  模型行更紧凑（去掉目录内的重复类型标签），搜索只在当前目录内生效。
- **空态按真实原因分档**：有模型就显示模型；只有设置里没填 ComfyUI 路径时才提示
  「ComfyUI 还没有配置」并给出去设置入口，已配置但无模型时提示「模型库里还没有模型」；
  不再出现「没启用任何模型目录」这类配置引导。
