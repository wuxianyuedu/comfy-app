## Fixed

- 应用日志面板按「应用日志」反馈（#4567）整批整改：
  - **壳日志不再整份并成一条**：壳自持日志（shell.log）的行形态 `[日期][时刻][级别][模块] 正文` 此前不匹配任何记录头，行首 `[` 又命中「JSON 片段」续接判据，整份文件被并成一条巨型记录（「壳日志有很多条，显示只有单条」）。新增 `SHELL_LOG_RE` 记录头：每行独立成条，时刻 / 级别从行结构解析，模块路径保留在正文。
  - **一行内容不再占两行空间**：软换行估高从「每字 13px 均摊」改为按字符宽度累计（窄字符 8.1px / 宽字符 14.7px）——等宽字体下的长 ASCII 路径行不再被多估一行；正文列开销按实测校准（260 → 320px），隐藏元信息列时另有小开销档。
  - **类别前缀调暗、正文更清晰**：`[app_lib::shell_launch]` / `[orchestrator]` / 会话短 id / `>>>` 这类类别 token 落到灰色背景层（类别保留、不抢正文），级别词保持状态色；端口这类四位数字括号不误伤。
  - **新增「隐藏元信息列」开关**：面板工具栏眼睛按钮（及设置页开关）一键收起时刻 / 级别 / 位置 / 来源列，鼠标框选多条日志不再带上无用信息；行内复制按钮随同一开关只复制正文。
  - **新增「日志行距」配置**：设置 → 日志提供 紧凑 / 标准 / 宽松 三档，与虚拟滚动行高常量同源，即时生效并自动记住。
