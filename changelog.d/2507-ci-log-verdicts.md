## Changed

门禁脚本与 CI 跑批的结论行**收成一个出口**：`scripts/ci-log.mjs` 的 `gatePass` / `gateSkip` /
`gateFail`，一条判决一行、三态分明（ISSUE #2506 的诉求，改动挂在 #2507）。

原来同一件事有四种形状并排在平台日志里（`✓ …` / `[format] OK` / `[cp936-glyph] 扫描面 N 个
文件：没有…` / `[重档] … ok …`）。比不好看更贵的是第二层：判据打「暂存区是空的 ⇒ 这一批没有
要判的东西」并退 0，跑批那边只能看见 `ok` —— **「判了且干净」与「没有判」逐字同形**。

- `[ok]` 判过且干净、`[skip]` **这一轮没判**、`[红]` 判出问题。读数里带「暂存区是空的」这类
  固定说法时，`gatePass()` 自动降级成 `skip`（不让「说对」押在每个人每次的记性上）；
  证据为空时 `gateFail()` 一条都不打 —— 屏幕上不该出现「命中 0 条」的红。
- 跑批那一格（`ci-heavy-gates.mjs`）不再自己拼标签，并按三态打印；红步的取法从「猜哪一行是
  结论」改成按位置（头 5 行 + 尾 15 行，中间报数）；绿步读数压到 90 字，超了写「又 N 字」。
- 收口三处「同一件事的第二种说法」：`quality-gate.mjs` / `quality-gate.ps1`（两个宿主逐字同形，
  「没跑起来」不再与「跑了且失败」共用前缀）、`premerge-check.mjs` 的段判。
  `base-check.mjs` 的逐条判决也走出口，而 `[base-check] 结论：<verdict>` 那一行**一字未动** ——
  它是 `premerge-check.mjs` 的 `lastSummary()` 读回的对外契约。
- 已迁移的判据：文件结构硬规则 / UI/逻辑分离 / CHANGELOG 碎片 / 跨文件重复块 / 函数长度 /
  零消费导出 / prettier 格式 / CP936 字形登记 / 格式化提交分离。

判据：`tests/ci-log.test.ts`（三态前缀互不相同、降级是自动的、截断报数、空证据不打红）与
`tests/quality-gate-ps-precheck.test.ts`（两个宿主措辞同形）。规范 §13.5.29。
