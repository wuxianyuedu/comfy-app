## Added

- **工作流库「执行日志」新增「查看完整输出」入口**：comfy-cli 的原始 stdout/stderr 输出此前在日志面板里被单行 400 字符、最多 300 行截断，排障时看不到被截掉的完整 JSON 与大对象。现在后端按任务完整留存 comfy-cli 原文（`runner-state` 的 `rawCli` 缓冲，上限 5000 行），并经新增接口 `/api/tasks/[id]/raw-cli` 暴露；「执行日志」弹窗头部新增「查看完整输出」按钮，打开后把 `[comfy-cli 原始]`/`stdout`/`stderr` 中的 JSON 行用 JsonViewer 折叠 + 语法高亮展示，其余原文按行显示，运行期自动轮询刷新。

- **「实际使用」页签的执行日志入口默认常显**：此前只有跑过一次才出现，现在随时可点开（弹窗内显示空态）。
