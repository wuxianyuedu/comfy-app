## Added

- **角色库（ISSUE #5009）**：新增跨项目的二次元角色档案池，供动漫制作选角。
  侧栏新增「角色库」全局视图：竖版立绘网格、状态徽标（待生成 / 生成中 / 已就绪 /
  失败）、关键词搜索（名字 / 原型 / 描述）与按特征标签筛选（多选取交集，带命中数角标）。
  每个角色档案含详细描述（外形 / 服饰 / 性格 / 能力 / 背景），**特征标签从描述
  自动提取**（受控词表 + 发色 / 瞳色生成式匹配，确定性可复现，描述更新即重提）。
  内置组合式角色生成器可一次预置 100~1000 个描述详尽、名字唯一的角色
  （同种子重跑幂等）；接工作流库（如 minimax_h3_image）可对全部或点名角色
  批量入队生图，产物复制进角色库自有目录（与任务生命周期解耦），生成进度
  按任务终态自动对账回写。数据落 `characterProfile` 表，路由 `characterLibrary.*`，
  领域代码在 `src/lib/character/`。
