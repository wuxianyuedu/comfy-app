## Changed

- **主页那几个页签不再把屏名写两遍：页头那行大标题去掉，那句长说明收成悬浮「说明」按钮（ISSUE #1693）**。现场是「队列」这一屏同时出现两次「队列」——一次在页签上、一次是屏内 1.5rem 的 `h1`，底下还压着一行副说明，标题区实打实吃掉首屏上沿一大块，而读者什么都没多知道。`PageHeader` 因此支持**省略可见标题**（`srTitle` 把屏名退到 `sr-only`：视觉上不占位，读屏仍能按标题跳转）与**把说明收成悬浮按钮**（`help`，走 `ui/hint` 的唯一出口，不用原生 `title=`）。队列 / 历史 / 模型（两处）/ 资源库 / 控制台 六屏同批改到位；`description` 与 `help` 二选一，同时传以常驻为准（同一句话不说两遍）。

- **页签已经在说屏名时「标题行」整块不渲染**：`title` / `titleSuffix` / `extra` / `help` 四件都没有时，页头只留右侧动作组那一行。`h1` 不会因此消失（`srTitle` 仍然写进 DOM）——「别占空间」与「没有标题」是两件事，规范 06 要求每一屏都能按标题跳转。
