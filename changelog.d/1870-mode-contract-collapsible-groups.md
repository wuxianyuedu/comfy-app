## Changed

- **「模式契约」左栏的每个输出类别改成可折叠（ISSUE #1870）**。用户反馈「每一类需要可折叠」。
  - 树形页签收起来之后，最长的那个类别（图像，11 条模式）仍会把另外两类挤出可视区 —— 而切类别正是「先找到那一类」这条路上的第一步。现在每个类别的父行是一个折叠开关（`▸/▾`），默认**全部展开**：收起是「先看别的类别」的临时动作，默认折着等于把当前模式藏起来。
  - 折叠三层各归各的出口（规范 16 §16.2.4.13 / .17 / .39）：**哪些类别折着** → `useExpansionSet`（键 = 类别）、**父行怎么折** → `Disclosure`（`aria-expanded` / `aria-controls` / 键盘 / `hidden="until-found"`）、**折起来的那一摞怎么画** → `TreeChildren`（缩进档 + 引导线）。
  - 父行从此**不再是 `aria-hidden` 的纯分组头**：它一旦可点，`aria-expanded` 就是这一层唯一的语义载体，再标隐藏会把折叠态从可访问树里抹掉。`aria-label="选择要配置的模式"` 不变（这一块的职责仍是「选一条模式」，折叠只是顺带）。
  - 收起是**折叠**不是「移除」：面板留在 DOM 里带 `hidden="until-found"`，浏览器页内查找命中折叠内容时仍会自动展开它。

## Tests

- `ModeContractModeNav.test.tsx` 增补三条：默认每个类别都展开（`aria-expanded=true`）、点父行收起/展开且**只动这一类**（另一类的开关与模式行都不受影响）、收起后那一摞仍在 DOM 里带 `hidden="until-found"`（折叠不是条件渲染掉）。
- 既有的「每个类别都是一个父行 + 它的子行集合」一条改按 `data-category` 分组取子行（父行可点之后不再能靠 `aria-hidden` 判它是不是纯分组头）。
