## Fixed

- 工作台视图页签的落盘不再等待「侧栏页签行为」配置面取回（#3657）：页签的存取都在
  客户端（sessionStorage），此前加的「配置没到不落盘」闸门在配置接口没答上来时
  （e2e 桩、或任何后端故障）会把落盘永久卡死——新建项目刷新后回到首页、项目页签
  丢失。现在落盘照常进行（判据未取回时即项目默认，与界面所见一致），配置取回后
  按生效判据重写；落盘形状跟随当前判据，不再固定用默认判据。
- 修「文件选择器点了没反应」的一处根因（#3657）：`useFilePicker` 的隐藏 input 此前
  随调用方每次重渲染被卸载重挂（`onPick` 内联箭头让 `useMemo` 形同虚设），重挂窗口
  里落下的文件选择事件打在已脱离 DOM 的旧节点上，React 收不到——设置页选字体文件
  后界面毫无反应。现在 `Input` 身份恒定，最新回调经 ref 注入，事件始终落在活节点上。
- e2e 判据与产品现状对齐（#3657）：
  - 外观页「字阶只作用于标题」的标题定位钉 h1 全字匹配——页面新增的分区小标题
    （数据存放位置总览的「应用设置」h4）与子串匹配撞车，strict mode 误报。
  - 「左轨按窗宽自动让位」的宽度断言改按 `~/lib/layout-budget` 的账推导（展开
    160 / 收起 48），不再写死「差值 ≥150」——侧栏按 #3587 收窄到内容实需后该
    魔法数已过期。
