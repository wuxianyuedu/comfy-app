## Fixed

- **设置页的标题去重 / 正文补大类标题 / 控件未选中态看不清 / 实例目录那块的排版（ISSUE #3527，承接 #3495 的四条新评论）**
  - **标题去重**：正文那一列先来一行分区标题（`应用更新  检测并安装应用新版本`），紧跟着又来一张同名标题的卡片 —— 两个出口说同一件事。现在分区标题那一行留在正文里，卡片只留内容（`SettingsCard` 的 `title` 改为可选，不传就不渲染标题行）；一节里有多张卡片时（「备份与恢复」下的「创建备份 / 恢复备份」、「外观」下的「本地更新检测」）每张卡片仍各带自己的标题。
  - **正文补大类标题**：左侧导航树里的大类（模型 / 后端 / 数据 / 应用 / 诊断）在正文那一列原先完全不出现；现在每个大类的**第一个**分区上多一行弱一档的大类标题，长页里读得出「这几节属于一类」。
  - **标题不再比正文还暗**：段级标题此前走**正文字体**（17px/600），深色下笔画峰值只到 `#c2c2c8`，而同屏 14px 的行标题是 `#ededf2` —— 标题比正文还暗（实测）。段级标题补上 `font-title`（与屏级标题同一族），层级与亮度都对上。
  - **控件未选中态**：单选圈与勾选框此前用 `border-input` 那根 1px 发丝线，在 1.5 倍屏上与容器底混成深色 1.09:1 / 浅色 1.02:1（实测），未选中等于不存在。现在走 ink 的 alpha 档（浅 `ink/50` / 深 `ink/40`），对卡片 3.3:1 / 3.5:1 —— WCAG 1.4.11 对「控件的视觉边界」要的就是 3:1；选中态仍走品牌色。
  - **实例目录（只读）**：每组目录此前是一行灰标签 + 一串路径，组与组之间没有承载面，一屏读下来是一堵字墙。现在每组一块行表面（与设置页其它「卡片内的一行」同一档 `SETTINGS_ROW_CLASS`），标签提到正文档，组间有了间隔。
  - 新增判据（`tests/surface-ladder-contrast.test.ts`）：控件基类的未选中描边不许再是 `border-input`（那根发丝线）—— 这一族是「类名写了、却看不见」，色值扫描与 tsc 都看不见。
