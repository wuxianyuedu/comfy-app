## Fixed

- **`Change.key` 撤掉：写进改动清单而全文件没有一处读它（ISSUE #2717）**：
  `scripts/tw4-spacing-canonical.mjs` 的换算清单原来有三格 —— `from` / `to` / `key`
  （`base + bang`，即「这条换算挂在哪个 spacing 槽位上」）。清单的每一个消费点取的都是
  `from` / `to`（以及 `changes.length`），`key` 的读者是 **0**；同值 `w-K h-K → size-K`
  那一路还压根不给它，于是它在类型上只能是可选 —— 「有写无读」加上「两条路不对称」，
  留着的全部效果是让下一个读 `Change` 的人以为它在承重。
  **单里给的两案里择了第 2 案（删）**：第 1 案要改屏幕上的读数（「待改写 N 处」按槽位分组），
  而这一档的判定只回答「有没有残留的任意值 px 写法」，没有人要按槽位看。
  放弃了什么也写在这儿：**「换算挂在哪个槽位上」这件事在清单里不再留痕迹** ——
  将来要按槽位分组，得先给分组一个读者，再一起把字段加回来。
  同批把 `canonicalize` 的 `@returns` 从内联的 `{from,to,key}` 改成 `Change | null`，
  现在这份文件里清单只有一份声明（`:143` / `:190` / `:227` 三处消费全用它）。

- **同一处还有一个形状错，是这支清账自己带进来的（一起修）**：批 15 把 typedef 块插进
  `canonicalize` 那份已有 doc 的中间，**没带上原来那个 `*/`** ⇒ 上面的
  「单个候选 → 规范化候选（不改写时返回 null）」与下面整块 typedef 长成了**同一个注释块**，
  那句话不再挂在任何函数上。它跑过了 `node --check`、eslint、脚本档 tsc、tw4 那 18 条用例与
  平台 CI —— 因为「注释块没闭合」在语法上是合法 JS，没有任何一层读得到。
  现在两个块各自闭合，`@param {string} token` 回到它自己的函数头上。

- **顺带量了一件事：这一类不能升级成判据**（免得下一个人再去试）。
  直觉的机器形状是「逐份文件数注释块开合：`/*` 与 `*/` 不等 ⇒ 有一处没闭合」。实测：
  扫 `src` / `scripts` / `tests` / `e2e` 共 **2351 份** `.ts` / `.tsx` / `.mjs` / `.cjs` / `.js`，
  按 `/**` vs `*/` 数 ⇒ **1836 份**不平衡（口径本身就错：普通 `/* … */` 不开 `**`）；
  改成 `/*` vs `*/` ⇒ 仍有 **290 份**不平衡。当场看过其中一处（
  `src/components/studio/debug/debug-store.ts`）：文件头注释里写着目录通配
  `project-canvas/*` —— 那是**内容里的 `/*`**，被计数器多算一个开符。
  这一族的误报来源是确定的（注释或字符串里的 glob / 拿注释语法当被测内容的夹具），
  不是「可能误报」。
  ⇒ 误报为主、判不到真形，按 AGENTS 硬规则 24 末句与「不新造启发式扫描器抓怪癖」那条口径
  **不做判据**；这一类的防线是「改完看自己那一跳的 diff」。

  凭据（都是当场读数）：
  ① `--check` 的屏幕输出与改动前**逐字相同**（`diff` 两份捕获文件为空，
  改动前后都是「待改写 0 处（0 个文件）」、退 0）；
  ② 删字段动的是携带数据的对象，所以拿一次性夹具真跑了一遍生产入口的**改写那一面**
  （仓库外的临时目录，跑完即删）：`min-h-[22px] → min-h-5.5`、`w-[40px] h-[40px] → size-10`
  （合并那一路）、`p-[10px] → p-2.5`，「已改写 5 处（1 个文件）」；再跑一遍 = 0 处（幂等）；
  ③ `tests/tw4-hardgate-behaviour.test.ts` 8 条 + `tests/tw4-canonical-ratchet.test.ts` 10 条
  串行全绿（含 spacing 硬闸那四条：干净输入退 0、一条真候选即阻断、注释里的示例不算候选、
  `--update` 出口已断头）；
  ④ 脚本档账面不变：`tsc -p tsconfig.scripts.json` 仍 **13 处**（本份文件零格，没长新格）；
  `node --check` 通过；`pnpm exec eslint` 对该文件零输出。
