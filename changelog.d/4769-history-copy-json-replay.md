## Added

- **历史「复制去重投」改为复制全量参数 JSON，测试模型新增 JSON 输入模式（ISSUE #4769）**：
  历史页的「复制去重投」现在把该次提交的**全部参数**折成 `{ mode, inputs }` JSON 复制到剪贴板
  （与详情弹窗的「工坊参数」表同一套派生，尺寸口按 pin 展开成测试页的四把键）；
  测试模型的输入面板新增「统一输入 ⇄ JSON 输入」切换 —— JSON 模式粘贴历史复制的载荷，
  点「生成」解析并写回表单值、随同一次点击按这些值重跑（解析失败 / 缺 `inputs` /
  没有认得的键都在反馈位给错并拦下，不发起生成；解析成功自动切回统一输入，
  填进去的参数可见）。
