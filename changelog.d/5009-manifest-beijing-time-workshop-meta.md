## Fixed

- **产物 manifest.json 的时间落北京时间**（ISSUE #5009 反馈）：此前 `createdAt`
  序列化为 UTC（`…T18:53:44.915Z`），与本机时钟差 8 小时。现分为
  `time.createdAt`（任务创建）与 `time.writtenAt`（manifest 写入），均为
  北京时间（UTC+8，ISO 带偏移，如 `2026-11-25T02:53:44.915+08:00`）。
- **manifest 结构分块补全**：`workshop`（工坊模型名称 / 模式代号 / 模式名称）、
  `params`（工坊提交参数：提示词 / 负向 / 种子 / 尺寸 / 参考图 / 工作流入参）、
  `workflow`（工作流模板信息 + 本次实际执行的采样参数），每部分清晰可读。
  工坊元数据为尽力而为读取（宿主未注入时相应字段为 null，不阻塞收口）。
