## Fixed

- **「所有项目」屏不再永久停在「正在读取项目列表…」**（ISSUE #4781）。dev 的 StrictMode
  双挂载（挂载 → 卸载 → 再挂载）会复用同一个 `aliveRef`：第一次卸载把它置 false 后，
  第二次挂载的 effect 不先复活它，本次取数的回包就被「上一次已卸载」的状态误丢 ——
  网络 200、无报错，列表却永不落定。现在每个 effect 运行周期先复活判活标记（与
  use-agent-run / use-console 同族 hook 的写法对齐），卸载守卫语义（#4239）不变；
  同批补上 StrictMode 双挂载回归用例（修复前稳定红）。
