## Fixed

- **应用有时无法切到前台（点托盘图标、再次双击启动都没反应，得多点一次任务栏才出来）**：主窗处于最小化时，唤起路径是 `show()` → `set_focus()`，而 `show()`（tao 走 `SW_SHOW`）**不会还原最小化窗口**——Windows 只把它「按最小化状态」显示、并把前台记到这条仍是最小化的窗口上，用户看到的就是「点了没反应」；再点一次任务栏能出来，是因为那次走的是系统自己的还原路径（这也解释了为什么是「有时候」）。现在唤起前先 `is_minimized()` + `unminimize()`：托盘「打开主界面」/ 点击托盘图标、二次启动的单实例回调、启动器判决给前台的窗口交接、壳内 ComfyUI 页签四处一同修正；且**只在确实最小化时**才调（`unminimize` 内部是 `SW_RESTORE`，对非最小化窗口带激活语义，无条件调会把「不抢前台」策略架空）。规范 §1.3 的「执行（窗口交换时）」一行同步补充该步骤；release 壳已按硬规则 5 重编（`cargo build --release --features custom-protocol`）。
