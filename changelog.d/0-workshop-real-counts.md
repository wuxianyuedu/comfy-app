## Fixed

- **工坊右侧「缺失素材 / 下一步」不再喊编出来的缺口**：清单里写着固定目标 —— 角色卡 2 个、场景 3 个、分镜 16 镜。角色数与场景数由剧本内容决定，不是目标；那个 16 更是「默认 16 镜占位」被删掉之后留下的孤儿常数（删占位时没连带清理这里）。于是一个真实项目会被喊「还差 16 项待补」，用户照着凑数、或干脆不信这块。现在：镜头目标**由场景表派生**（各场景 `shotCount` 之和，与导入时铺占位镜头的口径同源，见 `docs/guides/feature-workshop-flow.md`），场景还没拆出来时不给目标、只报已排数；角色卡与场景不给目标，只报「已建立 / 尚未建立」。判据单测见 `src/components/workshop/stage-config.test.ts`（5 条，含「不输出任何颜色」那条）。
- **资源库面板去掉两行假内容与一个死按钮**：`剧本大纲.md`、`分镜脚本.json` 与固定「参考图 / 音效 0 项」是写死的文案，不是项目内容；「+ 导入素材」按钮没有 `onClick`，点了没反应。现在只列真有计数的三行，并明确素材的实际管理入口在画布素材库。顺手改一个错名：那一行数的是**已出图的镜头**条数，原来写着「场景图」。
- **清单的颜色改成语义档**：原先每行带一个内联十六进制色（`#FF5C76 / #FFB553 / #5CA8FF`，靠 `check-theme-colors` 按行号逐条豁免）。现在派生层不给颜色，视图按 `done` 取 `bg-success` / `bg-warning`，那三条按行号的豁免随之删除 —— 行号豁免本身就是脆的，改一次函数就会让门禁静默失效或误报。
