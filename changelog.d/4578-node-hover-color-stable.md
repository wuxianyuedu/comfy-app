## Fixed

- 旁路 / 停用节点悬停时颜色不再漂移（#4578 补充，用户二次实测推翻「无法复现」的旧结论）：这类节点旧实现是「半透明卡 + `backdrop-filter` 透采画布」，而悬停会把节点 z-index 抬到 1180（ISSUE #400 的压线需求）——抬层改变了毛玻璃取样到的背影（邻点 / 连线是否在它身后），合成色跟着悬停漂移。用户截图像素实测：同一节点头部非悬停 `#403848`、悬停 `#303038`。旧结论用 `getComputedStyle` 量声明样式，量不出合成像素的变化，故而误判。
- 修法：旁路 / 停用节点卡片改铺**不透明角色底色**（`palette.nodeBgOpaque`，与普通节点同一着色代数），`<NodeFrost>` 只在不透明底上叠模式色（旁路粉 `#ec4899` / 静音灰，α 保留）——不再透采画布，颜色与层叠序彻底解耦；子图封装节点同一修正。悬停抬层（压线）行为保留。回归：`WorkflowNode.test.tsx` 新增两条（mode=4 卡片底不透明；着色层叠旁路色且无 `backdrop-filter`）。
