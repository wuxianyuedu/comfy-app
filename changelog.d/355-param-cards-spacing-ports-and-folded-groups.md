## Fixed

- **对外参数卡片与工作流节点拉开距离，连线看得清（ISSUE #355 复审）**：卡片列与宿主卡片此前只隔 16px，两端几乎贴在一起 —— 线短到看不出哪条连到哪一行。两列之间现在留出走线的横向空间（与编辑器画布上卡片列的留白同量级），线的两端一眼可辨。

- **「尺寸」这类多候选参数补齐输出端点：一个候选一颗（ISSUE #355 复审）**：卡片右侧此前只有**一颗**输出端点，而「尺寸」有宽 / 高 / 宽高比 / 像素量四个候选 —— 用户看到的是「明明有 2 个参数，却只有一个输出端点」。现在输出端口 = 候选落点本身：每个候选一行、各带一颗端点与自己的 handle id，拖哪颗就连到哪个候选；连上之后只留被落到的那一颗。端点 id 用 ioKey（不再是端口名）—— 同名 pin 出现在两个节点上时，线不会接到同名 handle 的第一处。

- **组合参数收窄成逐行参数，输入端口露出来（ISSUE #355 复审）**：「比例 + 像素 + 倍数」那块组合卡在画布上占满整行，用户看不到 `aspect_ratio` / `megapixels` 各自的输入端口，连线也无从落手。画布与工作流库现在默认把它**折叠成普通参数行**（一个端口一行、各有可连端点），需要组合录入时用行内按钮展开（宽版表单 / CreatePanel 的既有观感不变）。卡片与表单对「哪些端口被组合控件接管」用同一份判定（`inferGroups`），卡片不再重复列出已被接管的端口。
