## Changed

- **应用日志切到满页（2000 行）时的明显卡顿**：面板此前把一页 2000 行**全部**挂进 DOM，行内还有 ANSI / 词法分片，满页时节点数在 15000 上下 —— 切页那一帧的样式计算 + 布局就是用户感知到的卡顿。现在改成**虚拟滚动**：只渲染视口内的几十行（实测 2000 → 约 35 行，切页耗时 1000ms 量级 → 90ms 量级），撑开滚动条的是按行高常量估算的总高（超 `scrollHeight` 精度上限时按比例压缩）。行高常量与行内 class 同口径（不换行 27px、每多一行 +18px），因此不需要动态测高那一轮额外测量。三条既有契约显式兜住：`data-log-index` 仍是页内绝对序号（贴底找不到节点时按估算位置滚）、量不到视口高度就整页渲染（jsdom / 首帧，虚拟化不能变成内容看不见）、换页把 `scrollTop` 收回头部（渲染哪一段现在是由它算出来的）。新增纯逻辑模块 `log-virtual.ts` 与 16 条单测、1 条真实 Chromium 的 e2e（DOM 行数 < 200、总高 = 2000 × 27px、滚得到最后一行）。
