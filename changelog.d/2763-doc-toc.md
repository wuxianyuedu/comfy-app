## Added

- **`pnpm doc:toc <章节> [关键词]`：按节定位规范文档的只读入口**（ISSUE #2763）。规范章节的体量
  已经到「整篇读一遍不现实、`grep` 猜词读到半句就下结论」的程度（13 章近百万字节 / 一万行），
  缺的是「这一节在第几行到第几行」这一跳。新入口打出「标题 → 行号」目录（可选关键词过滤），
  并对每个命中给出可直接照抄的 `Read(offset, limit)` 区间；标题树跳过围栏代码块里的 `# 注释`、
  保留列表项里缩进的子标题（`13.6.2.1` 那一层）。输入面直接复用 `scripts/doc-facts.cjs` 的
  `SCOPED_DOCS`（不另立名单）；**默认读源**，`--rendered` 才读 `docs/generated/**` 镜像并明写
  「行号属于生成态镜像」——两份同名、行号不同，拿错不会报错。三态：`0` 读到并打出目录
  （关键词 0 命中也是 0）、`2` 没读成（认不出 / 前缀命中多份 / 文件不在盘上 / 旗标不认识）。
  判据在 `tests/doc-toc.test.ts`（11 条：解析 / 区间 / 解析文档名 / 三态）。
