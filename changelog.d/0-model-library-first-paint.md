## Changed

- **模型库首屏不再被后台目录同步挡住，加载态换成骨架屏**：`useModelLibrary`
  原来「挂载先 sync（重扫 ComfyUI 全部模型目录）→ 完成后才 refetch」串行执行，
  首屏要等整轮扫描（多目录时以秒计），且只有一行「加载中…」。现在 `list` 与
  `sync` 并行发车，`loading` 只表示「列表尚无数据」，DB 存量回包即渲染；sync
  完成后静默替换，筛选行右侧给一颗「同步中…」指示。loading 态渲染与真实行同形
  的骨架（类型药丸 + 文件名 + 大小，`role="status"` 播报），档位 chips 同步
  骨架化，不再闪「全部 (0)」。
