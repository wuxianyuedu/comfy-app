## Fixed

- **文档集的一批形式不规范与失效引用**（ISSUE #1926）。三类问题，都是「没有判据
  会因此变红」的那一类：
  - **索引自身的内部矛盾**：`docs/README.md` 引言写「standards，README + 01~15 章」，
    而同一文件的三处（§1 尾注 / §5 标题 / §8.1 表）写 01~18 章；主规范第 5 行的
    「README + 01~15 章」同源过期。两处都改成 01~18。
  - **不该进版本库的私有输入**：`docs/README.md` 头部把开发机绝对路径
    `F:\AI\Other\Comfy-APP-T3` 当作「仓库」（同文件其它位置一律用相对路径）；
    `docs/guides/sync-after-pull.md` 带 UTF-8 BOM（同目录其它文档都没有）。
  - **台账类计数与标签过期**：`docs/README.md` 写结构检查是「R1~R10」，实际钩子标签
    是 `文件结构硬规则(R1-R12，R5 硬闸)`（`R13` 由独立脚本判、`R14` 同族）；
    同文件称 `docs/audits/` 「现存两份」，实际是三份 md。计数一律改成不记数
    （份数以目录 `ls` 为准），标签对齐钩子；`docs/README.md` 末尾一行
    「（内容由AI生成，仅供参考）」也在仓库自己的规范索引里，删掉。

- **14 处失效相对链接 + 27 处失效锚点**（ISSUE #1926）。相对路径类的根因是
  「以谁为基准」写错：`docs/glossary.md` 用 `../standards/`（它在 `docs/` 下，
  应为 `standards/`）、`docs/guides/PRODUCTION-GAPS.md` 用 `../../standards/`
  （应为 `../standards/`）、`docs/guides/TESTING.md` 用 `standards/`
  （应为 `../standards/`）。锚点类的根因是**标题后来被加长**而链接停在旧 slug 上
  （如 `#137-换行符与提交噪声lf` → 标题实为「13.7 换行符与提交噪声（LF，对齐主规范
  §11.2）」，正确锚点是 `#137-换行符与提交噪声lf对齐主规范-112`）；另有
  `docs/standards/07-日志系统.md` 指向 `launch-and-build.md#4.1` 的锚点写的是
  改名前的旧标题。**这一类此前没有任何判据**（`.md` 不在 prettier 面里、
  `doc:check` 只核值与路径存在性，不核锚点），全部按标题实算修正。

- **`docs/standards/16-shadcn-ui与表单校验.md` 的三处重号**（ISSUE #1926）：
  `16.2.3.1` 出现两次（「分层：预计算层 + 判据分档」与「浮层的「位置由谁定」」）、
  `16.2.4.73.1` 出现两次（「一屏一名」的下半截 / 同一 ISSUE 的另一半）、
  `16.6` 出现两次（「团队 Registry」与「base-ui 注意事项」）。重号让 `§16.x.y`
  失去唯一所指，也让 `check-commit-claims.mjs` 那类「按节号核事实」的判据可能
  指到另一节。后三处分别改 `16.2.3.16` / `16.2.4.73.3` / `16.6.1`，并把文档内
  唯一指向它们的引用（`§16.2.3.1`、两处 `16.2.4.73.1`）一并改成新号。
  `changelog.d/**` 里的历史碎片按硬规则 14 不改写。
