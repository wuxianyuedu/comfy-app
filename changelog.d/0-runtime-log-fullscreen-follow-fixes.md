## Fixed

- 设置页「启动日志」全屏视图的三处体验修复（用户实测反馈）：
  1. **新一轮启动自动切到最新**：会话下拉此前停在用户正在看的旧会话上，新一次启动写入横幅后
     也不会跟过去；现在轮询 / 刷新发现新会话（按会话开始时刻判别，不拿会随尾窗滑动平移的
     行号 id 判）即自动切到下拉里的最新一项，没有新启动时仍保持用户选中的旧会话。
  2. **底部显示不全**：全屏面板此前铺到 `bottom-0`，最后 24px 被底部状态栏（`fixed bottom-0
     h-6`、z-toast 恒在最上）压住，最后几行读不到；改为底边让出状态栏
     （`full-screen-layer.ts` 新增 `FULL_SCREEN_LAYER_ABOVE_STATUS_BAR_CLASS`）。
  3. **点标题栏误关**：base-ui Dialog 默认「点弹窗外即关闭」，全屏视图铺满后弹窗外只剩窗口
     标题栏，用户一点标题栏整个全屏视图就被关掉；改为 `disablePointerDismissal`，只留退出
     按钮与 Esc 两个显式出口。
