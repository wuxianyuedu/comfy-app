## Fixed

- **侧栏打开项的三个后续反馈（#3740）。**

  1. 悬停 / 聚焦侧栏项右侧的关闭按钮时，整行仍带上悬停色（此前光标落在按钮上，行自身的 `:hover` 不触发，行会变灰回去）。
  2. 打开态从「品牌色实心角点」改为「图标落进一枚品牌浅底（`primary-soft`）胶片」——角点与未读通知共用形状通道，容易误读；胶片只表达「这一页在用」。
  3. 顶部视图页签条不再渲染侧栏常驻项的页签（首页 / 模型 / 历史 / 队列 / ComfyUI / 工作流库 / 模型适配 / 测试模型 / 模式契约 / 控制台）：它们在侧栏里恒在、可切可关，页签条再平铺只贡献占宽。transient（设置 / UI 控件总览）与项目类页签照常进页签条；标题行（桌面壳）与内容列两个形态的条同时受。

  侧栏常驻页签的打开态 / 悬停关闭按钮行为（#3745 已交付）保持不变；图标轨（collapsed）态仍不放关闭按钮（关页签走展开态）。
