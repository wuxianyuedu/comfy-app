## Added

- **「合并前的固定动作」是**一条命令**，不是三条纪律**（规范 §13.6.2.1 / ISSUE #1611 拍板）。这一跳此前有三条**都天然跑不进 `pre-commit`** 的判据（本地钩子面前根本没有那次 squash 合并）：`--base` 复算（#1591）、`check:claims`（#1605）、合并面（#1617）。三条各自的判据都不缺，缺的是**「记住跑全」这件事本身** —— 写成文档里的三条命令就是把执行者交给纪律，而纪律的三种漏法（漏跑一步 / 顺序反了 / 只跑了自己记得的那条）**都不报错**（§9.2 第 3 条禁止的静默失败）。
  - 新入口 `scripts/premerge-check.mjs`（`pnpm check:premerge`）**合成三段、不发明第二套编排**：`base` 段**直接 import** 既有实现的 `baseCheckMany` + `resolveMergeBatch`（连「面从钩子里现算」都不再抄一份），另外两段是子进程 + 退出码**原样**透传。本入口只做两件事：**筛段**与**合成总码**。
  - **总码合成：「没跑起来」(2) 压过「红了」(1)**；四态 ⇄ 退出码的折算只在**一处**（`current-green`=0 / `yours`·`baseline-red`=1 / `inconclusive`=2）；三段全被跳过 ⇒ **退 2**（不许「什么都没复算」被读成「复算过且全绿」）。
  - 「合并有没有丢一侧」那一格在 HEAD 不是合并时（日常、以及平台侧 squash 出来的提交）**跳过并退 0，但要说话**（打印「跳过：…」与原因）—— 这个 0 由「确实没有合并可判」担保，不由「判据没跑」担保；它与「取不到提交 / 浅克隆」（退 2）是**两档**，混成一档会让这个动作天天报「不构成证据」而把真故障淹没。
  - 跨平台两处同步：`quality-gate.mjs` 的 `GATES.premerge`（`run: false`，不在 `all` 里）与 `quality-gate.ps1` 的 `$Blocks` + `-Mode` 单选值。登记进 `scripts/.on-demand-duties.json`（`premerge-fixed-action`，机器事实取 `GATES.premerge` 的 `run: false`）与 §11.23.3 的声明 ⇄ 读者索引。

## Tests

- `tests/premerge-check.test.ts` 17 条：总码合成（全 0 / 有 1 / **有 2 压过有 1**）、从 `base-check` 报告里读回结论词（**按 `结论：` 那一行取**，不被正文里的同一个词命中；缺那一行 ⇒ `null` 不默认成绿）、段的筛选（**三段全跳过退 2**、`--only` 点名不存在的段退 2、`--only=claims` 真的只跑那一段、`--json` 逐段给结论）、**不发明第二套实现**的形态判据（含反面：不许自己再拼一遍 `worktree add` / `readHookSteps`）、**带锚点的那一段真的在跑**（见下）。

## Fixed

- **`mergeLoss` 段此前恒退 2，整个入口恒报「不构成证据」—— 三段里有一段一次都没复算过。** 这一段落成了裸 `script` + `args: []`，而 `check-merged-side-loss.mjs` 缺 `--baseline` 会**直接 exit 2**；本入口又「原样透传」退出码，于是每次敲 `pnpm check:premerge` 都得到「有段没跑起来」。它恰好是这套编排自己要消灭的那类静默失效：**看着在跑、事实一次没复算**，而且形态极像「环境问题」，很容易被当成噪声学会忽略。
  - 修法：`mergeLoss` 改成 `anchored` 那一档，**由本入口算出锚点**（`resolveLossBaseline()`）。锚点 = **分叉点** —— `merge-base(<要并进去的那条>, HEAD)`，与 `.githooks/prepare-commit-msg` 那条提交前档（#1618）同源。语义对得上判据本身：它问的是「结果版是不是退回了**基线之前**的某一版」，拿上游**尖端**当基线会把分支侧自己的正当改动整片读成差异。
  - 为什么这个锚点**算得出来**、而 #1605 判过的「天真形态」算不出来：那不是同一个问题。天真形态要推「被丢的那一侧是谁」（squash 之后常已不可达，实测 `ad81a912` 上 128 份改动 → 0 命中），而**分叉点**由 `merge-base` 直接给出。
  - 算不出锚点时（无上游引用 / 浅克隆）仍然**退 2 并说清原因**，绝不静默退 0 —— 与上面那条口径连着。
  - 用例把这一格钉住：`--baseline 不再是「缺参」`、锚点**等于分叉点且不等于上游尖端**（在真的分叉仓库里判，否则「取尖端」这个变异也能通过）、算不出锚点时必须给出原因。
