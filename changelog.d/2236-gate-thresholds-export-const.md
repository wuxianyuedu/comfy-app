## Fixed

- **判据数值账的覆盖面认得 `export const` 了**（ISSUE #2236，`scripts/check-gate-thresholds.cjs`）。
  两处正则都只认行首 `const` ⇒ `export const` 形态的顶层阈值整体在面外。**一条阈值承不承重，
  与它会不会被别的文件 import 无关** —— 按可见性划覆盖面，等于教下一个人把阈值藏到 `export` 后面。
- **不是假想的形状**：上一批新增 `PER_FILE_RERUN_MAX` 时先写成 `export const`，账一个字都没念它
  （#2188 那条「整份未入账」也帮不上 —— 它用的就是同一条正则，扫出来是「这份文件零个顶层数值
  ⇒ 不必入账 ⇒ 绿」），改成非导出才进得来面。
- **两处消费、一把尺子**：扫面的 `CONST_DECL` 与「按账上点名的常量取值」的 `sourceValue()` 现在
  共用同一处 `CONST_HEAD`（`^(?:export\s+)?const\s+`）。只放宽扫面会造出一种自相矛盾的红 ——
  「这份文件被扫到了，但账上那条按老形状找不到」；只放宽取值则永远不会新抓到东西。
  三个方向各一条用例：未入账的 `export const` ⇒ 红并点名；已入账的被改大 ⇒ 漂移红且念成「变松」；
  账与源码一致 ⇒ 不许有红。
- **放宽当场就吃到 2 处**（不是"以后可能会抓到"）：`scripts/run-affected-tests.mjs` 的
  `SAFE_ARGV_BUDGET = 24000` 与 `DEFAULT_MAX_WORKERS = 4` —— 两条都以 `kind: "report"` 入账，
  理由分别写在账里（命令行预算 / 并发旋钮，都不是松紧量；§13.6.4 那句「降负载的杠杆是并发，
  不是预算」正好说明为什么第二个不该被当成判据强度）。账的条数由脚本自己念，散文不抄。
- **规范同步**：§13.5.26 加一段（可见性不是分界 + 两处消费同一把尺子 + 这次的 2 处），
  判据文件头第 3 判那一条跟着补一句。
