## Fixed

- **工作流编辑器画布：鼠标悬浮的节点现在真的会浮到连线之上（ISSUE #400）**。原先的实现在节点卡片本体上写 `data-hovered`，而抬层级的 CSS 选择器是 `.react-flow__node[data-hovered="true"]` —— 属性落在了 React Flow 节点外壳**内部**的子元素上，选择器永远不命中，悬浮抬升静默失效（实际表现就是「鼠标停上去层级毫无变化」）。现在由 `useHoverElevation` 通过 ref 定位最近的 `.react-flow__node` 外壳再写属性：鼠标指到哪个节点，那个节点就抬到 1180 层（高于节点自带 z-index 与选中态的 1010），移开后还原；普通节点、子图卡片、对外参数卡片三种节点一致生效。悬浮状态仍挂在被指的那个节点自己身上，鼠标进出只重渲染它一个，大图拖动/缩放开销不变。
