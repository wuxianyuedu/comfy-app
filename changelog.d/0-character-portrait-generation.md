## Added

- **工坊「角色卡」阶段可以为角色生成 / 导入定妆照，并把挑中的一张存到角色上供后续分镜图当参考图**。此前角色卡只能靠文字描述与提示词预览，人物长相全凭生图时的运气；分镜图之间也没有统一的人物形象锚点。现在每张角色卡下方多出「定妆照」区块：按角色的正 / 负向提示词选择**本地（ComfyUI 工作流）或远端 API** 通道生成，尺寸沿用镜头生图的比例 / 像素 / 对齐三段选择（默认竖版 3:4）。一次生成常常不满意，所以**历次结果与外部导入的图都会留在候选缩略图里**（单角色最多保留 12 张，按时间倒序），点任意一张即定为定妆照（第一张自动选中），可随时删掉不要的候选；也可以直接「导入图片」把外部做好的定妆照放进候选（写入素材库「角色」分类）。定妆照作为角色数据的一部分随草稿保存，切换页签、切项目、重启应用都不丢。生成通道的门禁会明确提示缺什么：本地通道需要先在右侧「生成资源」选 Checkpoint，远端通道需要先配置 API 生图通道（可就地打开设置弹层）。远端通道返回内联 b64 图片时会先落成本地素材再引用，避免把 base64 塞进草稿撑爆浏览器存储。定妆照目前是「记在角色上、可被后续阶段引用」的资源；把它自动作为参考图喂给分镜生图（内置 txt2img 无图输入，需走带图片输入的工作流）是紧接着的下一步。
