## Fixed

- **`pnpm e2e:which` 对「改 spec 本身」的改动面给出该 spec 自身的建议**（ISSUE #4942）。映射此前只有「应用侧源文件 → 依赖它的 spec」方向，且判据说明登记表只收了 8 条高价值 spec——改未登记的 spec（如 `nav-auto-collapse`）时，改动面落不进任何判据面，工具答「无登记、自行判断」，而规范 §11.3.1 的口径恰是「改了哪条 spec 的判据就跑哪条」。现在补一条恒等映射：改动面命中哪个 `e2e/**.spec.ts`，它自己就进「相关 spec」与可复跑命令；登记过的 spec 仍用原登记说明，`e2e/support/**` 等非 spec 文件仍走公共地基提示，不改变其余语义。
