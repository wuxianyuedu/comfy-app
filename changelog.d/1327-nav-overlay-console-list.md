## Fixed

- **master 上那条 `nav-items` 硬闸红收掉**（ISSUE #1327 落地时漏改的判据，非本批引入）：
  #1327 给侧栏加了第三个应用级浮层入口「控制台」（`OverlayEntryId` 与
  `OVERLAY_NAV_ITEMS` 都加了 `console`），而 `nav-items.test.ts` 那份**清单判据**
  还写着「恰好两项」—— 表现是 `pnpm run check:all` 的 test 门从那天起每次全量都红一条，
  于是「全绿」这个信号在所有人手上失效（硬闸类须为 0，没有带病通行的中间态；
  复算过程见本批 PR 说明：干净 `cnb/master` worktree 上单跑该文件同样红）。
  修法是把清单补成三项（这判据本来就是「新增浮层入口必须同时登记这里」），
  不是放宽它。
- 同一段注释里的**数量措辞去掉**（「这两项不改变视图」「多出两个到不了的值」
  「紧跟流程之后的两项」「顶栏那四个之一」）：数字写进注释就是下一次加项时必须被
  顺手改掉的隐藏耦合，而漏改没人拦 —— 改成不带数量的说法。
