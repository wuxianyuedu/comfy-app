## Added

- **每类数据配一枚「存放位置」图标，并在该类数据被配置的地方显示它（ISSUE #3625）**：
  此前「数据到底存在数据库、应用、项目代码库还是别处」只有读过实现的人才答得出，
  而它恰恰是迁移数据时第一个要问的问题。
  - **落点登记收成唯一出处**（`src/lib/data-location/data-locations.ts`）：数据种类 ×
    存放位置 → 类别 / 图标 / 落点 / 迁移办法。界面上的徽标与设置页的总表都从这儿取，
    不再存在第二份「存在哪儿」的字面量。
  - **图标按「存放位置类别」配**（数据库 / 本机应用数据 / 项目代码库 / 本机磁盘 /
    浏览器存储）—— 用户问的是「存在哪儿」，同一个落点上的数据用同一枚图标。
  - **徽标落在该类数据被配置的地方**：模型适配页头、模式契约编辑器的保存区、
    设置的远程模型 / 本地模型 / 数据库 / 备份与恢复 / 创作后端各分区、工作流库
    列表顶部；悬浮说明给出具体落点与**迁移办法**（迁移时照着这两句做即可）。
  - **设置页新增「数据存放位置」分区**：按数据种类铺一张总表，每类数据说清存在
    哪儿、迁移时怎么搬。
  - 本应用**不把数据托管到远端服务**，所以登记表里没有「远端服务」这一类 ——
    不预置空转的位置。
