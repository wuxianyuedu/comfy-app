## Fixed

- **「测试连接」失败只给一段 HTML，看不出错在哪**（#3517）。连通性探测
  （`/api/llm/test`）、候选模型拉取（`/api/llm/models`）与实际调用测试三条链路
  各拼一份 `HTTP {status}：{响应体}`，上游返回控制台 / 网关的网页时就把
  `<!DOCTYPE html>…` 截一段灌进提示 —— 用户照着截图里的 404 只能去猜。
  现在三处共用 `~/lib/llm/http-failure` 的同一份归因：响应体是 HTML 页面时直接说
  「这个地址返回的是网页而不是接口响应 —— 多半把控制台或官网地址填进了 Base URL」，
  401/403 与 404/405 各补一句归因，并在文案里点名实际探测的地址。
- **Base URL 看不出接口版本段时给提示**（#3517）：详情页与新建弹窗在「实际请求地址」
  下多一行提醒（如 `/v1`），但**不自动补**——各家版本段位置不同（有的在域名后、
  有的在 `/api/v1`），替用户猜只会造出看着对却 404 的地址。示例占位符也从
  某个具体产品的控制台域名改成中性的 `https://api.example.com/v1`。
