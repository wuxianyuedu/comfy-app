## Added

- **工坊「剧本」阶段可直接选择本次生成用本地还是远端模型**。此前剧本阶段只能沿用「LLM 设置」里的全局模型，想换模型必须改全局配置（会同时影响角色卡、分镜等其它阶段）；角色卡阶段的「用一句话生成角色」早已支持单次独立选择，剧本阶段却没有，界面上只有一个只读的「远端 API · qwen3:14b」标签。现在「生成剧本」区块标题右侧多出一个本地 / 远端模型下拉：候选来自设置里已保存的本地模型与远端独立模型，选中即用（显式带 provider + model 调用），不选则继续沿用全局配置；选完会校验对应服务是否可达，成功后提示本次实际使用的「本地 / 远端 · 模型名」。下拉选项值与「独立选择 → 生效模型」的换算抽到 `src/lib/workshop/channel-options.ts` 纯函数，剧本与角色卡两处共用同一口径（角色卡行为不变）。「模板生成（离线）」不受影响，仍为纯离线模板。
