## Changed

- 对外参数的**落点分类改按类型**：端口的**声明类型**定族（STRING → text、
  IMAGE / MASK / IMAGEUPLOAD → image、INT / FLOAT / NUMBER / COMBO / 未知 →
  number），判据不再看端口名 —— 按名字判错的时候用户无从察觉（一个普通数值口被
  静默判成「尺寸 · 宽」、一条普通文本行被静默判成负向）。`classifyPin`（含
  `searchText` / 首尾帧正则 / 时长正则）整条删除。
- 同一族的几个对外参数**共享候选**：提示词 / 负向提示词都收 STRING 行，参考图 /
  首帧 / 尾帧都收图片行，尺寸六个子口与「时长」都收数值行 —— **谁是谁由作者的
  连线声明**（与「尺寸形态由子口声明」同一口径，ISSUE #632：不猜落点）。手工拖线
  的闸门 `pinAcceptsEntry` 同步改成「同族」判定。
- 连带简化：
  - `wiredTargetsForEntry` 只报作者连上的那一条（候选按类型收之后，组合控件的
    「一对多摊开」会把兄弟口子的落点画到本口名下）；
  - 未连线时不再按候选逐个兜底下发工作流默认值 —— 没连就是「未配置」，工作流图
    内自带的默认值照旧生效；
  - 删掉 `typeBasedPins` 字段与「无模式语境下按节点 + 端口名聚类」那条旧构造路径
    （对外有哪些参数只由契约决定）。
- 存量数据：拆分之前那条 `size` 线仍按旧的名字表归到对应子口（只读迁移，
  `legacySizeFormOf`）；`<节点 id>|<分类>` 旧键的读取口径不变（含新加的
  「不因历史键而多出落点」用例）。
