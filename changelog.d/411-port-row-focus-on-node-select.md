## Added

- **工作流编辑器画布：选中节点后，连到它的参数行（端口行）也跟着变化（ISSUE #411）**。此前选中节点只让相连的线加粗提亮，仍答不出「这条线落在节点的哪一行」——上游线接到一串参数行的哪一行、下游从哪个输出口出去，都要沿线去数。现在同一帧里连端口行一起标：有连线落到的那一行标签提亮加粗、行背景提亮、端口圆点放大并增强光晕；没有连线落到的行压暗；`related`（两端都选中的多选 / 自环）只作提示不加亮，因为说不出值是从上游来还是往下去。判据与连线同源（端点解析先归位到节点、再判方向），端口身份按 **(节点 id, 端口名) 二元组**匹配——只按名字匹配会让选中节点的 `seed` 因为另一个节点的 `seed` 也连线而亮起来。取消选中、断开连线后标记都会清干净；没有选中任何节点时整张图保持原样。工作流编辑器画布与项目画布两处一致；「对外参数卡片 → 宿主节点端口」的映射线不参与判定（它表达的是「参数落到哪一行」，不是图上的数据流）。
