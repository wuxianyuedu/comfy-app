## Fixed

- **模型卡片点进去是 404**：卡片一路链到 `/models/${id}`，而 `src/app/(main)/models/` 下只有 `page.tsx` —— 那条路由从来不存在，点任何一张卡都是死链。现改成**整张卡是打开详情的触发器**，详情以弹窗呈现（`ModelDetailDialog`），列表上下文留在原地。
  - 为什么是弹窗而不是补一条路由：补路由要把列表→详情→返回的往返接进页签栏、`ProjectGate` 与视图恢复那一套，而这一屏要给用户的答案只有「这个模型是什么、在哪、能不能用」。
- **模型封面从来没渲染出来过**：卡片读的是 `cover`，库里那一列叫 `coverUrl`，中间没有任何映射层（hook 把数据库行直接 cast 成卡片数据）——于是每张卡都在走渐变兜底，而界面上看起来「只是这个模型没图」。现在按真字段取，缺图与字段名写错才是两件能分开的事。
- **「放大」这一类模型看得见却筛不出来**：类型标签表认识 `UPSCALE`、列表的筛选档位里却没有它（两份各自列举同一批类型）。现在档位表由标签表**派生**（`model-type-labels.ts`），新增一类只改一处；并配一条防漂移判据：标签表里每一类都必须有对应档位、且档位标签与徽标标签逐字相同。
- **基座未知时不再写死「SDXL」**：原先 `model.baseModel ?? "SDXL"` 会把一个 SD1.5 模型在卡面上说成 SDXL，而用户没有别的地方能看出来。现在给占位符，明确表达「不知道」。

## Added

- **模型详情弹窗**：列出库里真有的字段 —— 展示名、文件名、类型、所在目录（`folder` + `subfolder`，任一为空不留孤零零的斜杠）、基座、来源、可用性、入库时间、描述（有则给）。
  - `isAvailable` 为 undefined（这一列没给）与 false（明确不可用）分开说，不把「没数据」讲成「不可用」。
  - 弹窗底部明确写出「使用量、作者、许可证等本地扫描拿不到，因此不在这里显示」——不留一片空白让用户以为在藏。
  - 刻意**没有**搬原型上的「N 次引用 · N 次收藏」：`model` 表没有这两列，本机模型库不是模型站，落进来就是假数据。原先卡片上那两个字段是永远 undefined 的假字段，渲染出一个永远空着的格子，一并删掉。
