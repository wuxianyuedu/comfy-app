## Fixed

- **工作流库「画布节点」里线不接端点、有的口拖不动也落不下（而且没有任何提示）**：三列节点在节点对象里用 `width` / `height` 声明了首帧尺寸，而这两个键会被 React Flow 写进节点 DOM 的**内联样式**，且 `handleBounds` 量到之后**仍然取声明值**（`getNodeInlineStyleDimensions`）—— 外框从此被钉死：卡片内容长高（表单随 IO 到位多出几行、换模式换掉候选口）不再触发 ResizeObserver，端点坐标（`handleBounds`）停在第①次测量那一份，边于是从卡片半空出发、落在圆点旁边。更要紧的是首帧之后才出现的端点**从未登记**进去，而 React Flow 起手就是按它找 handle（`getHandle` 取不到即**静默 return**），连 `onConnectEnd` 都不回调 —— 「连不上，也没有提示」正是这么来的。现在内容节点只用 `initialWidth` / `initialHeight` 声明首帧尺寸（量到即撤、外框由内容决定），并在端点**清单**变化（IO 到位 / 换模式 / 只读 ↔ 可连线）时主动重算一次落点；背景板的尺寸**就是**声明值，继续用 `width` / `height`。顺带把「落点被拒」的提示按现场算原因：原先不管什么原因都报「类型不同」，方向不对（同列 / 反向）或端口已不在契约里时，用户照着那句话永远改不对。
