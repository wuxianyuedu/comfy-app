## Changed

- **首页背景换掉：撤掉两团极光光斑，改成一条只由语义令牌构成的顶部渐隐带。**
  - 换掉的理由不是审美偏好，是两条实打实的问题：那两团是 `mix-blend-screen` + 饱和色（violet / cyan），**没有浅色回落** —— 浅色主题下右上角会糊成一块粉，而首页正是浅色态最常落地的屏；且首页本来就有标题、四个入口与两张状态卡，装饰性光斑压低的是内容可读性。
  - 新做法不给颜色、只给纵深（`from-surface-1` → 透明的单向渐隐），深浅两态共用同一份令牌，不需要各写一套回落。
  - 范围只有首页。`AuroraBackground`（非 home 视图的公共底）与 `AuroraGlow` 在登录页 / 成片 / 训练屏的使用点**未动** —— 它们各自有浅色态的 opacity 回落，且不是本次被指出的问题；训练屏把 `--color-aurora-*` 用作图表 stroke 的那几处也照旧。

## Tests

- 新增 2 条防回归判据：
  - 「首页不再渲染任何径向渐变光斑」—— 判据取**内联样式里不许出现 `radial-gradient`**，而不是数类名：那团光斑的实质就是内联径向渐变（`AuroraGlow` 把它写在 `style` 上），类名怎么换都逃不掉这条；
  - 「顶部渐隐带仍在」—— 替代物也要钉住，否则"撤掉光斑"会被连背景一起删干净；顺带判它只该有类、不该有内联样式。
- 负向验证：往首页塞回一团 `radial-gradient` 光斑 → 第一条立刻红，从备份复原后 6 条全绿。
