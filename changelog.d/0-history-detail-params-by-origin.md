## Fixed

- **历史任务详情的参数区不再「乱糟糟的」**：
  - 删掉「独立」的**提示词块**与**生成参数卡**（种子 / 步数 / CFG）—— 它们显示的内容与下面的参数表重复（同一句提示词出现两次），而那张卡只认一小撮硬编码键名，还反过来把 `seed` 从参数表里过滤掉。现在提示词就是工作流的 IO 参数（或工坊参数），种子也照常出现在参数表里。
  - **按来源分块**：工坊发起的任务把「工坊参数」（工坊对外值：正向 / 反向提示词、首尾帧、帧数）单独摆一块，「工作流参数」（下发给工作流的 IO 端口）摆另一块；工作流直接发起的任务（工作流库就地运行、画布节点运行）只有后者。来源判据是 `params` 的**顶层键形状** —— 工坊链路的对外值会作为顶层键落库，而工作流直接发起只有 `workflow` + `workflowInputs`（DB 没有来源列，`generate.generate` 把整个入参对象直接当 `params`）。
  - **参数名可读了**：历史里存的只有 pin 名（`text` / `aspect_ratio` / `megapixels` / `multiple`），那是 ComfyUI 的程序名；现在按 `params.workflow` 查该工作流的 `workflowIO`（轻量的 `workflow.detail`，一次 DB 读），取其**作者标签**（「宽高比」「百万像素」）作展示名；查不到标签、工作流已删除、或节点 id 对不上（子图的 `host:inner` 形态）时逐档放宽后**如实回落 pin 名**，不编。悬停时给出原始 pin 名，便于排查 / 对照 ComfyUI 报错。

- **历史记录的筛选胶囊在浅色模式下看得清了**：选中态的计数徽标写的是 `bg-subtle5`，而那个类**在样式表里根本不存在**（全库只此一处），背景因此是透明的 —— 白字直接压在浅色胶囊上，「全部 47」的数字几乎看不见（用户实测）。改成 pill 自身前景色的半透明底（`bg-primary-foreground/20` + `text-primary-foreground`），深浅两套主题都由语义 token 给对比度。
