## Fixed

- **对外参数卡片上的「类型」不再跟着连线改动**：芯片原先取的是「有落点就显示落点那一行的真实类型」—— 同一个「首帧图片」连到 `IMAGEUPLOAD` 的装载行就显示成 IMAGEUPLOAD，断开又变回 IMAGE，读起来像口子自己换了类型。现在恒取这个口自己的类型（按族；尺寸子口按形态），落点那一行声明成什么另存 `targetType`，只在行的悬停提示里露面（否则「类型不同」在界面上就查不到了）。
- **「画布节点」列出的对外参数改用该模式生效的契约（不再用内置默认）**：此前画布按 `exposedParamsForMode(mode)` 列口，而「模式契约」编辑器读的是该模式**生效**的契约（改过的模式走注册表）—— 于是画布上多列出契约里已删掉的口（用户报的「画布有时长，打开契约却没有」），同时漏掉用户在契约里新增的口。现在两处同一份清单：`buildParamEntries` / `deriveLibraryParamCards` / 派生封装状态都接收 `contractIds`（生效契约的 id）。
