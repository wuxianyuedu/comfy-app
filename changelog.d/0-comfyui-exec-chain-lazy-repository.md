## Changed

- **`enqueue.ts` / `reaper.ts` / `executor-ws.ts` 的 `../core/repository` 静态值 import 全部 lazy 化（P3 §5 第 1 期·最后一步）**：整条 ComfyUI 执行链现在**没有一处**静态引 `../core/repository` 或 `~/lib/db`。同 #1053 runner-state / #1068 executor-finalize / #1071 executor-cli 的模式，各模块加 `configureXxx({ taskRepo })` + `resolveTaskRepo()`（未注入 → dynamic import 拉 Next 侧真单例、纯 Node 未 configure 时 async 函数直接 reject 让 caller 感知）。
  - `enqueue.ts`：只两处 `taskRepository.xxx`（findStatusAndPromptById / cancel），都在 `cancelTask` 里；`configureEnqueue` + 顶部一次性 resolve 成同名局部，下游 closure 沿用旧名。
  - `reaper.ts`：四处 `taskRepository.xxx`（listStaleQueued / listStaleRunning / finalizeFailure / finalizeFromReaper），分在 `reapStaleQueuedTasks` / `reapStaleRunningTasks` 两个 async 函数；`configureReaper` + 两函数各顶部一次性 resolve。
  - `executor-ws.ts`：只一处 `taskRepository.updateProgress`，就地 `const taskRepository = await resolveTaskRepo();` 前置于 progress 分支；`configureExecutorWs` 供 host 注入。
  - **为什么这一步收口 P3 §5 第 1 期**：之前 `enqueue` 与 `reaper` 各自静态引 `../core/repository` 一条边就足以让整个执行链在纯 Node 里 `import` 失败——`../core/repository` 是 barrel，底下 12 个 `repository-*.ts` 各自静态引 `~/lib/db`（→ `src/server/db.ts` 里 `import "server-only"` + `import { env } from "~/env"`）；只要有一条静态边进 barrel，`server-only` throw 或 env 校验就崩。现在**整条链零静态 repository 边**，P3 §5 第 2 期 `scripts/executor-host.mjs` 起手时的静态边**彻底扫清**（数据层 `../core/repository` 自身仍带 server-only，但**只从 dynamic import 进**——host 通过 `configureXxx` 注入自带实现就不触发那条 dynamic）。
  - 各模块新增 `configure*` smoke 锁测（`enqueue.test.ts` 1 例 / `reaper.test.ts` 追加 1 例 / `executor-ws.test.ts` 1 例）：兼作 `check-dead-exports` 眼里的 `configureX` 消费方；`enqueue.test.ts` 额外 mock `~/lib/db` 一层，堵住 barrel mock 不阻子模块经旁路静态边拽出 `src/env.js` 校验的**已知 vitest 局限**（`Invalid environment variables` unhandled rejection 会污染整个 test run）。
  - 验证：`tsc --noEmit` / `eslint --max-warnings 0` / `vitest run src/lib/comfyui tests/lib-node-only-declarations.test.ts` **540/544 全绿**、无 unhandled error（含 4 条既有 skip）/ `.githooks/pre-commit` 28 步全过；`lib-node-only-scan.mjs` `unguarded=22`（前批 + 本批 3 模块自身仍无 Node 内建 value import 因此不入 unguarded 列表——只是把静态 repository 边拆干净、scanner 视角不变）。
