## Fixed

- **状态栏偶发误报「ComfyUI 未运行」**：ComfyUI 明明一直在跑，底部状态栏却时不时闪一下「未运行，显存/内存暂不可用」。根因是轮询 `/api/comfy/stats` 的 controller 只要**一次**失败就立刻翻离线，而服务端 `getSystemStats()` 对 ComfyUI 的 `/system_stats` 设了 2.5s 超时——跑图时该接口响应变慢、或单拍网络抖动都会返回 `online:false`，于是状态栏忽明忽暗。现改为**连续失败迟滞**：任一次成功立即清零并刷新数据，单次失败保留上一次的好数据不翻离线，连续 3 次（约 12s 持续失败）才判定真离线。真掉线时仍会正常报出，只是不再被瞬时抖动误触发。
