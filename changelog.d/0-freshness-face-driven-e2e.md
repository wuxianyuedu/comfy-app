## Changed

- **三档「每天首次自证」收成同形：全量 e2e 那一档改成吃输入面**（规范 §11.8 / §13.5.4，
   钩子重构 4）。立案现场是**本机账**（`.git/comfy-precommit-timing.jsonl` 最近 17 次提交、
   6 次红）：**6 次里有 3 次是 `freshness-gate.mjs` 拦下的，而那三次改的都不是 `src/`**
   （一笔只动 `.githooks/` 的编排改动、两笔文档与账）。旧口径「按本地日历日、不看面」让
   「跑与不跑结论都不变」的那类提交也欠一次十几分钟的全量 e2e —— 代价是钱、收益是零，
   而下一个人学会的动作是绕过它。
  登记处原来那句理由（「同一份 spec 在任何改动上都该绿」）**对改动本身成立，对
  「这一笔提交是不是那个改动」不成立** —— 这句话留在 `FRESHNESS_TRACKS.e2e` 的注释里连同
  现场一起，不是被删掉。现在 e2e 与另两档同形：`dirty = src/ / e2e/ / playwright.config.ts /
  next.config.js / pnpm-lock.yaml`（e2e 观察得到的运行时输入），当天动过就必须今天证一次，
  没动过以 7 天为宽限；`graceMs: 0` 与 `dirtyHow: null` 那两格随之消失（它们与「不吃面」
  是同一件事的三个投影，只改一个会得到一份自相矛盾的登记）。
  **⚠️ 顺带修掉一处注释事故**：那一格下面同一段话（「这一档**不吃输入面**…」）被逐字写了两遍，
  两处都会随口径腐烂 —— 删掉一份，留下的那份改成写清「吃什么面、为什么不放宽成一切文件」。
- **为什么敢给 7 天宽限**（这是这条变更唯一可能被读成「放松判据」的地方，所以写全）：
  「app 端到端是不是坏了」这个问题在**每个 PR** 上都有人答 —— 平台侧 `E2E 关键流程`
  跑 `e2e-run.mjs --grep=@critical`（与本地同一入口）。它是子集、**不构成整档凭证**，
  `isWholeTrackRun` 因此不给它记账（带参数的跑法一律不记账）；它守的是「功能链路坏了还
  无人知晓」那一格，整档那一层由「动了面 ⇒ 当天证」与 7 天宽限两道夹住。
  **放宽的是触发面，不是时限**：超出宽限没跑照样拦，这一条有正面用例钉着。
- **`scripts/e2e-run.mjs` 现在有两条出路，与另两档 runner 同形**：`--skip "<理由>"`
  （今天故意不跑）之外补上 `--dirty "<理由>"`（这次改动不吃这一档）。解析与落账都复用
  `daily-run.mjs` 那份 `parseLedgerFlag` / `writeLedgerNote`（四档共用一份，§12.12），
  两栏各写各的（`skippedReason` / `dirtyReason`）—— 混成一片之后「这一档三个月没跑」与
  「三个月每次都声明不吃它」在账面上就长得一样了。`parseSkip` 因此多返回一栏 `mode`：
  调用点要把「哪一条出路」原样传给落账，而不是再判一次旗标。
- **`--ledger` 那一档改过一次用途**（= 新增入口 `pnpm check:freshness`）：它原本只印账面
  （时刻 / 距今 / 谁 + 按哪条命令）就 `continue`，于是「开工先看一眼」的人看得到上一次是
  谁什么时候跑的，却看不到**按今天这笔要提交的改动，我欠不欠一次自证** —— 而那恰恰是这一眼
  要看的。现在它把同一份判决（`runGate` 已经算完，不额外花一次钱）作为**待办**打出来，
  措辞是「欠」而不是「✗」，**退出码照旧 0**：阻断的那一份在钩子里（D0 形态前置档那一步），
  两个读者各有各的出口（§13.5.12：别让一条读数线变成必经之路，也别写一把没人读的判据）。

## 验证

- `tests/daily-tracks.test.ts`：
  ① 正面钉新语义 —— 昨天证过 + 今天没动面 ⇒ **放行**；+ 今天动过面而账停在改动之前 ⇒ **拦**
  （话术里要出现「输入面」与那份面清单）；先跑后改同样放行；
  ② 钉**清单内容本身**（`dirty` 被悄悄放宽成 `[""]`、或收窄成只剩 `e2e/`，都不会让任何别的
  判据红，而两种都把这条判据变成装饰品）—— 正反两向各列具体路径，前缀写错也是静默的；
  ③ 机制那一格换成合成档：`dirty` 为空的档**必须忽略** `dirtySince`（否则「今天动过任何
  文件」被读成「这一档已自证」，日历日那条判据在有人动过代码的日子里整个失效而账面一切
  正常）—— 三档现在都吃面，登记表里已经没有空面档，所以它判的是机制而不是某一档的截图；
  ④ 超出宽限（14 天）照样拦，措辞里带「宽限」。
- `tests/e2e-run.test.ts`：昨天证过 + 今天动过面 ⇒ 拦；昨天证过 + 没动面 ⇒ 放行；14 天没跑 ⇒
  拦（三条各钉新语义的一侧，缺一条就可能只改了数据没改口径）；`parseSkip` 三种形状 × 两个开关
  （`mode` 跟着返回、两开关互不串档、`["--dirty"]` 后面什么都没给与占位理由都判「不合用」）；
  登记表的形状判据从「e2e 不吃面」改成「三档**都**要有 `dirty` + `dirtyHow` + `skipHow`」
  —— 没有出路就等于拦人而指不出退路。
- `--ledger` 那一格用形态判据钉：那一支必须读 `result.exitCode` / `result.problems` 并打出
  「欠」，且**不许**碰 `failed`（那是钩子那一份的退出码来源）；`package.json` 里
  `check:freshness` 必须挂着这一条命令。
- **两次真跑**：`pnpm check:freshness` 打印三份账的时刻 / 距今 / `who` / `how` 与每档的
  「现在**不缺**」，退出码 0；`node scripts/freshness-gate.mjs` 判决档同样 `[ok] × 3`、退出码 0
  （本检出今天的账由平台侧那一跑记下：`who=cnb.dQh7kaCfAPA`，`how=PNPM_START=1 pnpm test:e2e`
  —— 与 §13.5.4 那句「回写的那一笔是机器写的」对上）。
- 三个测试文件合计 **166 passed**；`pnpm doc:render` + `pnpm doc:check` 绿；
  `check-on-demand-duties` / `check-declaration-readers` / `check-gate-executors` 全部 exit 0
  （`.on-demand-duties.json` 里那一行的执行者措辞随 D0 与「同形」一起改了）。
- 没动的东西：账文件位置与五栏形状、`isUsableSkipReason` 的理由下限、`isWholeTrackRun`
  「带参数不记账」那条纪律、跑法脚本的记账语义 —— 本笔只改「什么时候欠」与「欠了有几条出路」。
