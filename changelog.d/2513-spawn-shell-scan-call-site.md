## Fixed

- `scripts/spawn-shell-scan.mjs` 的判据面收在「起子进程的那几个调用的实参对象」上
  （ISSUE #2513）：第一版按**行的字面形态**认任意 `shell:` 键，于是与子进程毫无关系的
  普通数据字段（#2494 在 `ci-cache-slot.mjs` 加的每键读数字段）也能把 PR 判红在
  「受影响用例」那一格 —— 红指向的那一行里没有任何 `spawn`，读的人要绕一圈才明白是误报。
  现在只判 `spawn` / `spawnSync` / `exec` / `execFile` / `execFileSync` / `fork` 调用
  **实参里的对象字面量顶层键**；字符串内容、嵌套对象里的同名键、`re.exec(...)` 这类
  成员调用都不判（`re.exec` 是正则，与起子进程的文本形状分不开）。
  两侧都有用例：真违规（含多行选项对象与临时树端到端）仍判得出来，同名数据字段 /
  字符串 / 嵌套对象一个都不判；`node scripts/spawn-shell-scan.mjs` 在真树上是绿的。
  代价写在文件头：**间接形态看不见**（选项对象先赋给变量再传进去），要追它就得回到
  「全文件任意 `shell:` 键」那一档，正是这条单要收掉的东西。
