## Added

- **等 CI 那一格不要空等：一轮改动的回顾清单**（ISSUE #2454）。规范新增
  §13.10.14（挨着 §13.10.13「CI 红了先诊断」：一个是红了怎么办，一个是还没红、
  在等的时候做什么），`.qoder/skills/ship/SKILL.md` 加一节指向它（清单只有一份出处，
  Skill 不抄）。十问：能总结成经验的工具 / 设计不合理 / 代码重复 / 不规范 /
  流程可优化，以及补进去的五条 —— 新写的判据有没有执行者、平台那一格有没有真的验过、
  触发面收窄面有没有跟着扩、有没有「只有自己知道」的口诀、写入类动作有没有独立回读。
  逐项给出口（立案 / 顺手修 / 做工具 / 写文档）；**这一格是读数与出口，不是闸**
  （做成闸只会收获一串随手勾完的勾）。
- `tests/helpers/strip-comments.ts` 加 `trailing` 模式（默认档行为一字未改）：
  连**行尾**注释一起剥，且逐字符跟过引号状态（不咬坏 `"http://a"` 里的 `//`）。
  给「源码里不许出现 X」那类判据用 —— 否则它会红在一段正在教人别这么写的注释上
  （#2453 的 `spawn-shell-scan.mjs` 就要这一档）。出口是那条台账判据自己写的：
  「它不满足你的形状就给它加一个模式，别再抄一份」。
