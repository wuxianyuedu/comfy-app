## Added

- 测试模型页执行日志新增「自动滚动」开关：默认开启（新日志到达即滚到底），关掉后视图停在用户翻到的位置，不再被拉回底部（#4743）。
- 测试模型页执行日志新增「大屏查看」入口：本地工作流任务入队后可打开与队列 / 历史记录同一份执行日志大屏（级别筛选 / 虚拟列表 / 加宽收窄 / 查看完整输出）；任务 id 按格登记在会话里，远端与对话通道不出现该入口（#4743）。
- 测试模型页新增「生成进度（分节点）」可视化区：解析执行日志里 comfy-cli 的 progress / executing / executed 事件，按节点渲染进度条（节点名 + 已完成/总量 + 百分比，运行中高亮、完成打勾，最多展开 6 行）；无进度事件（对话 / API 中继）时不渲染（#4743）。
