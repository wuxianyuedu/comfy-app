## Changed

- **接口格式从供应商下移到模型**（#3517）：同一供应商下文本 / 图片 / 视频模型
  可能各用一套协议（`/chat/completions` vs `/responses` vs `/v1/messages`），
  供应商级只有一个选择时必然有一条链探不通。现在「添加 / 编辑模型」弹窗里选
  接口格式，并把「供应商 Base URL + 该格式」拼出的最终请求地址直接显示出来；
  供应商详情与「新建供应商」弹窗不再有这一项。历史供应商上的格式只作为新建
  模型的默认值，生效值由 `resolveApiFormat(模型, 供应商)` 统一回落 —— 模型级
  为空（历史行）= 跟随供应商，都没有才按 OpenAI 兼容处理。
- **供应商详情去掉「保存」按钮**（#3517）：名称 / Base URL / API Key 失焦即落库，
  与库里那份无差异不写、字段不合法只报错不写（密钥写入后立刻清空输入框）。
  「测试连接」带上当前草稿，不再出现「改完地址忘了点保存、探测拿的是旧地址」
  的自相矛盾。
