## Fixed

- **子工作流里由暴露口接进去的线不再整条消失**：`bundle` 的边界连线（外层暴露口 → 内层节点某一参数行）此前按「`target_slot` = 内层节点 `inputs[]` 下标」去解析落点槽位名，而 ComfyUI 在部分导出路径上给的是**控件序号**（跳过模型/负面提示词这类纯连接口）。两种下标空间一错位，槽位名就解析成空串，连线落点退化成兜底字面量 `in` —— 画布上并没有这个 handle，React Flow 于是丢弃整条边并在控制台打 `Couldn't create edge for target handle id: "in"`（error#008），用户看到的是「这个暴露口从来没连上」。
  - 现在**只认哨兵边记下的事实**：`target_slot` 指向哪一行，落点就是哪一行，不再自己猜下标口径；判定与槽位名同源（`resolveInputSlots`），不会出现「解析到一行、实际渲染在另一行」。
  - 槽位名确实解析不出来时**不再产出这条边**（产出只会得到一条指向不存在 handle 的边），并在应用日志里点名上报是哪条边、哪个节点、哪个槽位 —— 「线没画出来」与「本来就没连」不再长得一模一样。
