## Changed

- **`executor-finalize.ts` 摘 server-only + 三条 lazy 依赖（P3 迁移第 1 期·第三步·收口批）**：`import "server-only"` 去掉；`../core/repository`（taskRepository）、`./client`（getView）、`~/lib/log/app-runtime-log`（createAppRuntimeLogger）三条 server-only 侧的**静态值 import** 全改成**首次调用时 dynamic import + 允许 `configureExecutorFinalize({ taskRepo?, getView?, runtimeLog? })` 显式注入**。`completeInner` / `finalizeFailure` 顶部各 resolve 一次、局部名保持 `taskRepository` / `getView` / `taskRuntimeLog`，其余 call site 一字未改（改动面小、review 友好）。
  - 关键路径 vs 诊断通道：`taskRepository` / `getView` 是**关键路径**（拿不到 → dynamic import 抛、async 函数直接 reject 让 caller 感知），`runtimeLog` 是**诊断通道**（拿不到 → 返回 `null`、call site 用 `?.` 静默 skip；与旧契约「日志挂不上不阻塞收口」同构，也与 #1060 trace 的模式对齐）。
  - 模块级 `const taskRuntimeLog = createAppRuntimeLogger("task")`（P3 之前是**加载即副作用**，纯 Node 下会立即撞 server-only throw）改成惰性 `resolveRuntimeLogger()` + 模块级缓存，只在函数被调时才解析。
  - 类型通过 `Awaited<ReturnType<typeof loadRealTaskRepo>>` 反推真实例结构，避开 eslint `consistent-type-imports` 对 `typeof import(...)` 型位的禁用；`Pick<>` 只锁 4 个方法（findExecutionMeta / finalizeSuccess / createImages / finalizeFailure），未来 host 不用背整个 taskRepository。
  - 登记进 `tests/lib-node-only-declarations.test.ts` 的 `PURE_NODE_HOSTS`。**诚实标注**：本模块**自身**的静态边已解，但**传递闭包**里 `./client`、`./executor-history`、`./executor-continuation` 各自还静态引 server-only 侧（logger → app-runtime-log → server-only、client → logger 同链），登记是「标方向 + 消化 unguarded」、**不是**「现在就能在纯 Node 里 import 本模块」；client / executor-history / executor-continuation 拆完后才真闭环。
  - 新增 `src/lib/comfyui/executor-finalize.test.ts` 2 条锁测：configure 不抛 + 两次调用合并语义。同目录 `.test.ts` 让 `configureExecutorFinalize` 通过 `check-dead-exports`（`TEST_CONSUMER_EXT`）。mock 只覆盖到 `~/lib/core/logger` 一层——`app-runtime-log` 由 logger 内部消费、被 logger mock 挡住，不再单独 mock 它（否则 executor-continuation 通过 logger 拽到 app-runtime-log 时会因缺 `appRuntimeLog` 具名导出崩在加载阶段）。
  - 验证：`tsc --noEmit` / `eslint --max-warnings 0` / `pnpm exec vitest run src/lib/comfyui` 531/531 全绿（含新增 2 条 + 既有 reaper / reaper-decisions / executor-cli / executor-scheduler / cli-procs-singleton / lifecycle 与 executor-finalize 自身的完整回归）/ `lib-node-only-scan.mjs` 显示 executor-finalize 进 unguarded 且被 PURE_NODE_HOSTS 登记消化 / `.githooks/pre-commit` 28 步全过。
