## Added

- `pnpm ship` 阶段 0 新增 **D0 预跑**（ISSUE #3200）：`git commit` 触发 pre-commit 之前，
  把钩子 D0 组的只读形态判据先跑一遍，**所有红一次报齐** ⇒ 落 `1` 停手，与「提交钩子会拦下它」
  同权 —— 钩子 D0 带 `set -e`，多处形态错原本要一处付一次提交往返。清单只有一份出处：
  从 `.githooks/pre-commit` 的 D0 组解析 `run "<标签>" <命令>` 步骤行（不抄第二份，钩子加一步
  预跑自动跟上）；每步按原样命令起子进程，红不红只看判据自己的退出码。清单取不到
  （文件不在 / 区间不闭合 / 零步）⇒ 念「取不到」跳过、不冒充结论，提交钩子照判；
  有步骤没跑起来（退出码取不到）落「没跑起来」家族（`2`），不念成红。跳过条件各念一行：
  `--dry-run` / 带 `--add`（暂存面要到提交那一刻才成形，预跑没有对象）/ 依赖没就绪 /
  `--no-preflight-d0` 旗标关；暂存面为空静默跳过。预跑是双付（提交钩子还会再付一遍），
  故给显式关闭旗标 `--no-preflight-d0`；跑了就报总耗时。依赖新鲜度那一步不双付
  （阶段 0 刚跑过同一判据的 `--json` 形态）。机制层 `scripts/ship-preflight-d0.mjs`，
  接线 `scripts/ship-preflight.mjs`；用例 `tests/ship-preflight-d0.test.ts` 对真钩子钉清单漂移。
