## Fixed

- **画布节点上的组合控件回到「带下拉的那块控件」，不再摊成逐行参数清单（ISSUE #355）**：上一轮把「比例 + 像素 + 倍数」拆成了一行一个参数 + 一张只报名称/类型的展示卡，用户口径是「组合参数不要现在这种样式」「改回之前的样式」「改成之前带有下拉菜单的样式」「让你减小宽度的也是这个控件」。现在画布节点 / 库内保留**那块带下拉的组合控件本体**（比例 / 像素 / 倍数由同一个下拉录入，值照旧可编辑），只是按内容收窄（`w-fit` + 触发器固定一档宽度），不再占满整行；宽版表单行为不变。

- **组合控件覆盖的每个端口各有一项自己的落点**：拖动映射线时落到哪一项就写哪个端口（比例 / 像素 / 倍数各一行），不再出现「落在整块控件上、实际写进第一个端口」的歧义。整块仍保留一个总锚点，供连线量到控件边界。

- **补上「倍数」端口的落点锚点**：此前该端口的 ioKey 没进组合控件的落点锚点，落到它上面的映射线在控件上找不到锚点，只能整条不画（表现为「线没连上」）。
