## Changed
- 任务产物目录改为三级分类：`generated/<mediaType>/<模型名>/<modeCode>/<taskId>/`，库里 `TaskImage.localPath` 同步写完整层级 URL（#5108）。分类从库里已有事实派生（媒体类型取产物首项、模型名取工作流标签回落工作流名、模式码取工作流默认模式 / 任务类型），每段安全化；`projectId` 不再单独占一层。删除 / 打开产物目录改为从 `localPath` 反推，避免与写侧各拼一遍；项目级联删除同时清新旧两种布局。新增一次性迁移脚本 `scripts/db/migrate-artifact-taxonomy.mts`（含 DB 备份与 `--rollback`），已把本机 538 个任务目录与 954 条产物地址迁到新结构。指南补上「DB 与 generated 必须一起搬」——此前只搬 DB 会让历史页显示「图片不可用」，而文件其实在原检出的产物目录里。同批补分类派生、路径往返、越界段、删除 / 打开与归属判据用例。
