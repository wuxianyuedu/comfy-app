## Fixed

- **工作流库「画布节点」里点节点也会拖动整个画布，导致连线根本落不上点**：平移面（`wflib-canvas-pan-surface`）是包住所有卡片的那一层，`onPointerDown` 无条件起手平移 —— 按住卡片上的端口圆点、参数行或输入框，画布都跟着平移；拖线时目标行随画布一起跑，于是「对外输出 → 工作流输出行」这类连线看着永远落不上点（手势根本没轮到连线层）。现在卡片内部的按下（表单控件、端口圆点 `data-port-dot`、连线端点 `data-wire-anchor`、参数行 `data-io-key` / 组合控件 `data-io-pins` / 落点锚点 `data-pin-anchor`）不再起手平移，空白处（卡片之间、卡片外）照旧可拖动画布。
