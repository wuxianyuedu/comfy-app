## Added

- **项目有了自己的主页**：进入项目（新建 / 从「项目」列表点开）不再直接怼上一张无限画布，而是先落在**项目主页**——项目内页签的第一项。主页回答「这个项目现在是什么状态」：一条总进度条 + 六个制作阶段（剧本 / 角色卡 / 场景分镜 / 镜头生图 / 视频生成 / 成片合成）逐行给状态与计数，旁边一栏给剧本 / 角色 / 镜头 / 镜头图 / 视频片段 / 成片的素材进度，再往下是四个「继续创作」入口（工坊 / 画布 / 产出 / 成片）。阶段完成判据由**内容派生**（不靠阶段游标），所以工坊里手动回退阶段不会让主页误报「还没做」。

## Changed

- **「AI 自主成片」挪到项目主页**：`RunControlBar`（启动 / 暂停 / 确认 / 取消、目标输入、确认粒度、执行日志）从画布顶部浮层改由项目主页承载，与工坊各留一份；画布回归纯画布。它读的仍是同一份 run、走同一份 `useAgentRun`，主页只是它的主要落点。
- 项目内顶部页签顺序改为 **主页 / 画布 / 工坊 / 产出 / 成片**（新增第一项）。
