## Added

- **同一项目检出多份可同时运行（多检出并行开发）**：启动链路三层按检出隔离——① 应用端口在 `.env` 未显式配置时按检出路径哈希稳定推导（FNV-1a-32 → 3200~3999，Node/PowerShell/Python/Rust 四侧同算法，Node 侧唯一事实源 `scripts/app-port.mjs`）；② 启动器互斥量与壳单实例的身份锚点从编译期全局 identifier 换成检出路径哈希——同检出二次启动照旧唤起已有窗口，不同检出各自独立运行；③ `dev-launcher.ps1` 的端口清理先核对占用进程是否属于本检出（exe 路径/命令行落在检出根内）才回收，外部进程绝不击杀，窗口识别同样按检出路径核对。此前启动第二份检出会杀掉/吞掉第一份检出的 dev server 与壳。
