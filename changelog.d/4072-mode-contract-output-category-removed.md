## Changed

- **「模式契约」编辑器里的「输出类别」那一格撤掉了**（ISSUE #4072）：模式本身
  已经按类别区分（契约编辑器左栏就按图像 / 视频 / 音频分组），再让用户为每个
  模式挑一次是重复选择，而且会与模式本身矛盾（把文生图挑成「视频」）。产物
  类别改由**模式码**唯一决定，不再是可配项 —— 契约类型、服务端入参校验与
  基线文件 `src/lib/workshop/mode-contract-defaults.json` 里都没有这一格了；
  存量文件 / 存量客户端仍带着 `output` 时，读侧与入参校验各自把它剥掉，
  不打回、也不落盘。
- **「模式契约」编辑器里的「必备」勾选框换成「必填 / 可选」徽标**（ISSUE #4072）：
  此前那一格是「勾选框 + 一句固定的『必备』」—— 勾上写「必备」、没勾也写
  「必备」，读的人看不出「没勾 = 可选」。现在徽标把两种状态都写在脸上，
  徽标本身就是开关（点一下改这一口必不必备）；形态与「工作流库 → 工坊封装」
  那一行同源（两处共用 `ContractRequiredBadge`，不各写一份胶囊类名）。
