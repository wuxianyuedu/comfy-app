## Added

- **工作流库的导入面板现在可以「选择文件」或「拖入文件」导入**（此前只能把 JSON 粘贴进文本框）：
  - 面板新增「选择文件…」按钮（隐藏的 `<input type="file">`，accept 限定 `.json` / `.workflow`）；选中后自动按文件名预填工作流名称、按内容预填 JSON 与格式，再由用户确认导入。
  - 拖放范围从「无」扩到**整片列表侧栏 + 导入面板**：把文件拖到任意位置都会高亮并提示「松开即可读取该工作流 JSON」，松开即走同一条读取链路。
  - 文件入口的失败不再静默：文件过大（>5 MB）、非 JSON、读不出来、格式识别不出，都会在列表与面板上显示具体原因（4 秒后自隐）。
