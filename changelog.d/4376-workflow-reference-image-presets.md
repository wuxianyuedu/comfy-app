## Added

- **工作流多参考图：装载预设与执行期动态建链（#4376）**：多参考图工作流
  （如 MiniMax H3 的 `image_0..image_4`）的参考图装载链不再需要逐张工作流手工连线。
  「工坊封装」页签的参考图槽位可配置**装载预设**与**追加端口**：装载预设描述
  「LoadImage 之后串哪些处理节点」（如 ResizeImageMaskNode ×2），在预设库里
  可视化编辑（节点类从 ComfyUI 节点目录搜索追加、控件值就地编辑）；追加端口
  让同一张参考图扇出喂到多个消费节点。执行时按选中预设为每张参考图动态生成
  `LoadImage → 处理链 → 端口` 子图（RAW 与 API 两种图格式都支持），类定义缺失、
  ComfyUI 离线或预设已删的端点自动回落裸 LoadImage 直连（#4355 行为）。
