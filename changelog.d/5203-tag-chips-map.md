## Changed

- **角色库标签筛选行派生计算改为索引命中，消除逐标签线性 `find`（ISSUE #5203）**：`tagChips` 的 `useMemo` 此前对每个展示标签调用 `tagFacets.find(...)`，生成态轮询每次刷新 facets 都会让这段重复扫描；当选中标签集合很大时（tag 已在前 N 中时 find 靠前命中，代价主要来自选中项）退化明显。本次把派生逻辑抽成纯函数 `buildTagChips`：先定展示集合（前 N facet ∪ 已选中），再**只扫一遍 facets、对命中的标签建 Map**，之后每枚 O(1) 取数，只剩 O(n log n) 排序。注意没有采用「全量 facets 建 Map」：microbenchmark 实测在 facets=2000 / 展示 27 枚的常见规模下全量建索引 47.8µs/次，反而比旧 find 的 2.4µs 慢一个数量级（只为几十枚展示标签扫了全部 facets），按展示集合建索引则是 2.0µs。回归用例对照旧实现输出逐字一致，并覆盖选中但计数为 0 仍保留、前 N + 选中边界与排序语义。
