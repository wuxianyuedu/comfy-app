## Added

- **启动耗时可视化（ISSUE #4185）**：回答「启动耗时都花费在了哪里」，编排器把
  启动过程逐阶段记进一份时间线（`scripts/launcher-core/timeline.mjs`，唯一实现），
  同一份读数进三处出口：
  - **启动页**：进度条下新增耗时条与逐段秒数行（每段一个阶段、宽度按耗时占比、
    悬停看段名 + 秒数；进行中的段实时补时长），随每次进度快照边等边刷新；
  - **日志**：`dev-launcher.log` 的「启动耗时分解」一行由三段粗粒度升级为逐阶段
    （预检 / 依赖对齐 / 备份恢复 / 端口解析与残留回收 / 桌面壳 / 编译缓存 / 服务拉起 /
    执行器宿主 / 后台建表 / 等待就绪），成功、超时、失败路径都会打；
  - **归档**：`run/launch-status.json` 与 `run.json` 新增 `timings` 字段，随运行包
    进 `log/runs/`，给后续启动优化留跨运行可比的基线。
  合计取墙钟（并行段不重复求和）；壳侧兜底快照的形状不变（不带该字段时启动页
  不画空条）。
