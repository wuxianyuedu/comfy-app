## Changed

- **「模型适配 → 模式契约」里的「尺寸」口改成与尺寸选择器同一套统一尺寸**：契约口名从「尺寸（宽高比 + 百万像素）」改为「尺寸（比例 + 分辨率 · 百万像素 + 倍数）」。工作流库详情「工坊封装」里那一行同步变化 —— 它现在从 `MODE_CONTRACT_INPUT_TYPES` 取同一份措辞（此前是两处各写一份字符串，改一处就会漂移）。
- **适配器侧的「尺寸」由两行变三行**：统一输入类型新增 `multiple`（倍数（宽高对齐）），契约的 `size` 口在适配器层展开成 `aspect-ratio` + `megapixels` + `multiple`；新建适配器时预填这三行。已存库的适配器不受影响 —— 老配置里没有 `multiple` 行就只发两行，需要倍数时在「模型适配」里加一行并填该接口实际用的字段名即可。
- **远端通道真的会收到倍数**：`POST /api/workshop-api/generate` 新增 `multiple` 入参（1~512 的整数），经 `generateImageViaApi` 按适配器字段映射落到请求体；工坊侧由 `shotSizeToRelay` 下发。选「分辨率」（1k/2k/4k）时同样按场景尺寸表换算成实际总像素与对齐倍数后再传，不把 `1k` 这种档位名丢给远端。
