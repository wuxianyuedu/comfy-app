## Changed

- 工坊模式整理（ISSUE #5003）：删除「图文混合条件生图」（TI2I）—— 它与
  「参考图生图」（R2I）同实异名（适配器里本就同一分支、同一份输入清单）；
  旧 code 经退役别名表（`RETIRED_CODE_ALIASES`）归一到 R2I，存量数据不丢模式端口。
- 「图生图」（I2I）中文名改为「图像编辑」，用户可见文案与测试断言同批更新。
- 模式契约默认基线（`mode-contract-defaults.json`）全量重排，派生口径
  （`exposedParamsForMode`）与基线同步：默认契约不再带角色 LoRA 两口（作者仍可在
  契约编辑器里加回）；参考图槽位收敛（P2I 默认两槽、其余图像编辑类一槽，编辑器里
  可继续追加）；I2V 补尾帧口；R2V / R2VA 的输入图走参考图口（不再占首帧口）；
  音频三档（T2A / T2M / T2S）去尺寸口；I2I 必备参考图、FLF2V / FMF2V 必备首尾帧、
  R2V / R2VA 必备参考图。
