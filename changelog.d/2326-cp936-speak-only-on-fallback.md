## Changed

- **CP936 转码层的读数改成「只在有人需要看时出声」**（ISSUE #2326，业主口径：能替的别显示，
  替换不了的打印出来才有意义）。原来那一行是「有替换发生就报」：
  `[cp936-glyph] 这一跑有 3 个字符在 CP936 里没有字形，已换成读得出来的写法：U+26A0 -> ※ x1、
  U+FE0F -> (删) x1、U+2713 -> √ x1` —— 三个**都在登记表里**，换完的结果在日志里本来就读得出来，
  于是这一行每跑都在、说的全是「按设计办完了」，而一行每次都出现、每次都无需行动的读数
  教给读者的是**忽略它**。
- 现在的判据是：**只有落到 `\uXXXX` 兜底**（登记表里没有它的替代写法，含 emoji —— 它们按
  §13.5.3.5 那条口径本来就走通用兜底）才念，且只点名这些：
  `[cp936-glyph] 这一批有 1 个字符在 CP936 里没有字形、也没有登记的替代写法，已如实记成 \uXXXX：
  U+1F427 -> \u1F427 x1；另有 2 处按登记表换成读得出来的写法（那些不再逐次报）`。
  总量仍在这句话里留一个数 —— 不是没发生，是不必逐次念（「不许静默」这条口径不因此让步）。
- 全批都在登记表里 ⇒ **整行不发**，两处调用点同判据（逐块一条 + 收尾「这一跑」一条）。
  只改一处会变成「逐块安静、收尾照吵」，那种半静默比原来更吵，所以由结构性用例钉住
  「两处各自守着一个 `if (said !== "")`」。
- **入口守卫一字未动**：`scripts/check-cp936-glyphs.cjs` 仍判「会进日志的面里有坏字符就必须登记」，
  命中即退 1；本单改的是转码层的出声条件，不是任何一条判定。登记表（替代 / 保留 / 删除三类）也
  一字未改 —— 加字条目要按「视觉几乎不变 + 替完自己在 CP936 里编得出来」那条口径挑，是另一件事。
- 用例 `tests/ci-cp936-glyphs.test.ts` 18 → 20 条：新增「全登记 ⇒ 整条不发」「只点名兜底并带
  总量那半句」「收尾那条同一判据」，并把「读数自己必须全是 CP936 编得出来的」那条的夹具换成
  含兜底字符的输入（否则它现在会拿到空串，断言就成了空转）。
  变异自证：把「有兜底才出声」那一判改回「有替换就报」（`spoken = replaced`）⇒ 三条新用例当场全红（3 failed / 17 passed），逐字节还原后 20 条复绿。
- 口径同步在规范 §13.5.3.5（那段后面新增一小节：这一层的读数只在需要人看时出声，
  以及为什么半改比不改更糟），生成态镜像同批。
