## Fixed

- 工作流执行日志的多行文本与后一行重叠（#4618，用户截图：comfy-cli 完整命令行那条与「启动 comfy-cli 进程」画在一起）。根因：任务日志面板的行盒是**固定 `height` = 估算行高**，而行高按「字符宽度系数 × 字符数」估算——系数只能取均值，临界长消息实际折行数比估算多一行，超出部分溢出行盒、与下一行画在一起。另一处叠加误差：任务日志侧估宽直接拿面板**整宽**，没扣时刻 / 级别徽标 / 来源等非正文列的固定开销（`LogPanel` 一直有扣，约 260px），进一步低估行数。
- 修法（`VirtualLogList`，执行日志 / 应用日志 / 子图日志共用）：① 行盒改 `min-height`，多行内容撑开行盒——结构上不再可能重叠；② 渲染后按消息实测高度回填位置表（`layoutRows` 的 `heightOf` 出口，键 = 消息原文），滚动长度与贴底定位随实测走；③ 估宽补上同一口径的非正文列开销。回归：`log-virtual.test.ts`（实测校正四条：向上修 / 只增不减 / 同文同高 / 展开行不受影响）、`VirtualLogList.test.tsx`（行盒 minHeight 契约 + `data-log-index`）。
