## Changed

- **`docs/api/**` 产物不再进 git —— 那一族漂移从「隐形」变成「不存在」**（ISSUE #2231）：
  - **现场**：master 上那份产物与源差 **9 处**（落后 5 / 缺失 4），而平台侧那一格**报绿**。
    差别只在于它**先把自己改了一遍** —— 那一格的形状是「`--autofix` 就地重生成、再判一次」，
    「修好了」与「本来就对」在读数上完全同形 ⇒「git 里那份是陈旧的」这件事在 CI 上
    **根本看不见**（ISSUE #2231 的现场读数与复算过程见单子正文）。
  - **处置**：`docs/api/` 进 `.gitignore`，2643 份产物从 git 索引里搬走（`git rm --cached`，
    工作区里保留）。**没有提交进 git 的产物，就没有「过期」这回事** ——「源与产物同不同步」
    这个问题**没有对象**了，比再补一道不受自动修影响的判据更省，也更不容易再漂。
  - **判据换了对象**（`scripts/check-docs-api.cjs`）：从「比对 git 那份 + 自动修写回」改成
    「**生成一份 + 判这份可不可用**」，三件：① **跑得通**（typedoc 按**产物**判成败，
    不按退出码）；② **骨架齐全**（默认主题每一页都引用的那几份 + 至少一个模块页）；
    ③ **可移植**（产物里没有本机绝对路径）。
  - **为什么没有第四条「覆盖面」**：模块页的**文件名由 doc tag 决定**（`@module`），不是由
    路径决定（实测 `src/lib/core/config.ts` 的页面叫 `core_config_—_配置的__类型契约…`，
    同一批产物里还有 `comfyui_*` / `collections_*` / `sqlite-pragmas.html` 这些与入口根
    不同名的页面）⇒「每个入口根至少一个落点」没有可机械判的形状，硬写一条就是判据在
    自己骗自己。要判覆盖面就得重做 typedoc 的命名推导 —— 那是第二份会漂的实现。
  - **「改了什么会让产物变」照旧管着**：输入面（三根 ∪ **闭包叶子集**，ISSUE #2223 的那笔）
    仍然是平台侧 `ifModify` 收窄的唯一出处；只是**产物面 `docs/api/**` 从收窄面里去掉**
    （产物既不在变更文件清单里、也不会被谁改坏）。
  - **`--autofix` 不再被接受**：产物不进 git ⇒ 没有「自动修完再提交」的对象 ⇒ 那一档在
    `scripts/ci-autofix-duties.mjs` 的登记表里**被删掉**（自动修名单只剩 `docs/generated/**`
    那一族）。撞上 `--autofix` 的调用直接退 1 并说明为什么 —— 静默忽略一个旗标正是本仓
    最恨的那族（脚自称与实际不一致）。
  - **stage 改名**：`API 文档生成物与源同步` → **`API 文档生成与自检`** —— 原名里的
    「与源同步」从这一版起没有对象了。
  - **本地不需要跑**：`pnpm run docs` 生成一份（只在本机），`pnpm docs:check` 生成 + 自检。
    两者都**不是任何一次提交的必经产物** —— 平台侧那一格自己会生成一份自己用（各跑各的，
    互不比对）。
  - **文档面**：AGENTS.md、规范 §13.5.5.1（整节重写）/ §13.5.17 / §13.5.18 / §13.5.19、
    `docs/README.md`、`docs/reference-facts.md`、附录命令速查、主规范 §9、tools 索引、
    控制台命令目录，全部改成「产物不在 git 里」的新口径。

## Removed

- **`docs/api/**` 的 2643 份 typedoc 产物**（`git rm --cached`，文件仍留在本地工作区）：
  它们进 git 就得有人守，而当时的守门（平台那一格带 `--autofix`）恰恰让漂移隐形。
