## Fixed

- **空提交不许否决「格式化器迁移」的声明**（ISSUE #3034）：「格式化提交分离」
  （`scripts/check-reformat-only.cjs`）的护栏 ① 要求区间里**每个**提交都带
  `format-migration:` 尾注，而 `pnpm ship --rerun-ci` 推的那笔空提交正文固定为
  `ci: rerun (ship --rerun-ci)`、不带任何尾注 —— 于是任何带迁移声明的 PR
  **只要重跑过一次 CI** 就掉出豁免。PR #2990 现场：三笔 rerun 让一个原本合规的迁移
  PR 报 `166 个源文件，其中纯格式化 118 个`（构建 `cnb-4ig-1k6csckqj`），
  同一区间摘掉那三笔就 `[ok] 按迁移放行`。
  护栏 ① 现在只数**有内容**的提交：空提交一份文件都没碰，对「这次重排有没有独占」
  不提供任何信息，不该拿一个恒真的读数去否掉别人（护栏 ② 那边空提交天然是 0/0、
  自动干净，两处口径由此一致）。sha 与文件清单一次 `git log --name-only` 取回，
  不按提交逐个起进程。
