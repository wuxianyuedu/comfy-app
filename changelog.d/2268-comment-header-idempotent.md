## Fixed

- **平台正文的署名那一行改成「有且只有一行」**（ISSUE #2268）。`--new-issue` 此前无条件在
  正文文件前插一行 `**[评论人：<短名>]**`，而这一行的约定本身就是「写在正文最前面」——
  人自己写了就撞出两遍：`#2258` 的正文头两行逐字相同（当场 `get-issue` 读数）。
  现在四处出口（建单 / PR 正文 / 领取评论 / 结束评论）共用 `ship-ticket.mjs` 的
  `withCommentHeader` 一处：开头已有署名行时**保留第一行原样**、去掉后面重复的那些、
  **不改写人名**（那一行是谁写的由写正文的人决定，工具只管形状）；只看开头，
  正文中间出现的同形文字（比如在讲这个格式本身）不算署名、不动。
- 用例：`withCommentHeader` 五格（缺 ⇒ 补本检出那一行 / 已有 ⇒ 原样 / 两行 ⇒ 收成一行 /
  不改写别人的名字 / 前导空行与正文中间同形不误伤 + 跑两遍逐字节相同的幂等断言），
  加建单一路一格（正文文件自带署名 ⇒ 平台正文只有一行）。
- 领取与结束评论的文案尾部多出一个换行（统一收口的形状）；状态判据走
  `handleCommentState` 的 `includes`，不依赖尾部形状。
