## Fixed

- **日志面板把每个请求行的 URL 都当成磁盘路径**（ISSUE #1695）：`GET /api/schema`、`○ Compiling /api/comfy/stats ...` 这一族行在面板里被画成紫色的可点入口，点开一律「找不到可在文件管理器里打开的路径」——它们出现得比真路径还密，于是整个面板看起来处处能点、处处点不通。
  - 根因：`findLogPathTokens` 的 POSIX 分支只问形状（`/` 起头且至少两段），而**服务端路由与磁盘绝对路径在形状上完全同构**。修法是在同一处补两条**形状判据**（不抄路径清单，新增路由不必改这里）：① 候选左侧紧挨着一个动词（HTTP 方法，或 Next 编译行的 `Compiling`）⇒ 这是 URL；② 候选落在框架自己的资源命名空间（`/_next/…`）。
  - 可点上色与可点定位共用 `findLogPathTokens` 一份判据（§7.32），所以两层同时修好；真磁盘路径（`/workspace/…`、`/usr/local/bin/pnpm`、`C:\…`、`\\server\…`）逐条回归无变化。以本机 564KB 的真实 `nextjs-panel` 转录复核：假阳性 **1 处 → 0 处**。
- **日志面板「错误」级别按钮的选中底盖住搜索框**（ISSUE #1695）：用户截图里「错误」的紫色选中框把搜索框左缘与放大镜一起盖住。
  - 根因是这一组的两条宽度约束**脱节**：容器挂 `min-w-56`（224px）允许被压到 224px，而每个按钮挂 `min-w-fit` 谁都压不到自己的内容宽（五个约 406px）——多出来的那截**溢出容器的盒子**（实测 16~174px），`overflow` 默认 `visible` 就画到紧邻右侧的搜索框上；而且 `flex-wrap` 判的是子项的 flex base size（`basis-0`）、不是溢出的内容，所以「放不下」永远不会触发换行。
  - 修法：容器改 `min-w-fit`，与按钮的 `min-w-fit` 同源 —— 容器不小于内容 ⇒ 不溢出、装不下时如实折行、窄到极致时标签仍不被切字（ISSUE #262 的诉求由按钮自己的 `min-w-fit` 保住）。
