## Fixed

- **降档收尾那句不再把「本地没跑哪些」写死成全集**（ISSUE #2154；口径见规范 §13.5.25）。
  当场读数（2026-10-22 一次 `COMFY_HEAVY_GATES=1` 的真提交）——三行 `[ok]` 之后紧跟一句当场为假的话：

  ```text
    [ok] ── 组 A：tsc --noEmit
    [ok] ── 组 B：eslint（零警告，范围见 package.json lint）
    [ok] ── 组 D：静态判据（结构/复用/棘轮/文档）
  [pre-commit] ⚠ 本次提交本地**没跑**：组 C（tsc / eslint / 受影响用例 / 静态判据全量）
  [precommit-timing] 已记录本次耗时：总 45.2s（4 组 / 52 步）
  ```

  那句括号是**写死的清单**，不随这一轮实际跳过了哪几组变化 ⇒ 它只在默认档成立，而在
  「有人主动把全套跑了一遍」的那一次必然说谎。同段两句同病：
  「本地要 A/B/D 全套：`COMFY_HEAVY_GATES=1` …」推荐的正是这一轮已经在做的事；
  收尾「入选档位全部通过 ✓（D0 形态档；重档见平台）」里的「D0 形态档」与「重档见平台」
  也都是写死的（最后一行自己写着「4 组」）。
  **一句在部分场景下必假的免责声明，教给读者的是「这类警告可以忽略」** ——
  下一次真只跑 D0 时，同一个人就会把它当噪音划掉，而这句话的全部功能就是阻止那种误读。
- **修法是把话术搬进有执行者的地方**：新增 `scripts/gate-tier-summary.cjs`（钩子收尾改成调它），
  按当场收到的三张名单念。**组说明不在脚本里另存一份表** —— 它实时从钩子那五行
  `run_group <id> "<说明>"` 取，取不到就明说「(钩子里读不到这一组的说明)」而不是省略
  （少一句免责声明会被读成「全套过了」）。同一个搬法的先例是 `ci-toolchain-selfcheck.mjs`
  与 `check-tsc-artifact-hint.cjs`：钩子/配置里就地的 echo 一条用例都测不到它。
- **顺带把两类「没跑」分开**：被档位降下来的（A/B/D）进「本地**没跑**」那句逐组点名；
  执行者挪去平台的那一组（C）**不是降档**，它单独念一句「本地不再执行、执行者是平台那一格」。
  旧形态把 C 混在「组 A B C D」里，读起来像「下一台机器上还会跑」，而事实是本地再也不跑它
  （`COMFY_HEAVY_GATES=1` 也换不回来）。
- 新用例五条（`tests/gate-tier-summary.test.ts`）：默认档逐组点名 / 重档全开时**不许**出现
  「本次提交本地**没跑**」「本地要 A/B/D 全套」「重档见平台」/ C 不混进降档名单 /
  未知组号说明读不到 + 「钩子改了名 ⇒ 跟着改口」的变异（这条反证表不许长在脚本里）/ 恒退 0。
  反向复算实测：让脚本忽略 `--hook` 之后第 4 条当场 `1 failed`，改回来 5/5 绿。
- `tests/commit-gate-tier.test.ts` 那条「收尾点名」的断言同批改**指向**：它原先直接在钩子文本上
  匹配那句话（等于把判据钉在一个随时该搬走的实现上），现在判的是**接线** —— 钩子必须点名那个脚本、
  那句话必须在那个脚本里，少一半就没有执行者。
- **两种档位的收尾现在各念各的事实**（同一次改动、同一棵树、本机跑的对照，改动前那份读数在
  本条第一段）：
  - 默认档：`⚠ 本次提交本地**没跑**：组 A：tsc --noEmit、组 B：eslint（零警告，范围见 package.json lint）、组 D：静态判据（结构/复用/棘轮/文档）`
    + 组 C 单独一句 + `入选档位全部通过 ✓（跑了：D0；重档见平台）`；
