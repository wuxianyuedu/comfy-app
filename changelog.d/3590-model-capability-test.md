## Added

- **工作区侧栏新增「测试模型」页签（测试模型能力，ISSUE #3590）**：用工坊同款通道
  （`/api/workshop-api/generate`）直接试已配置的远端模型。用途分图片 / 视频；
  候选是启用的远端条目按用途过滤；选中模型与模式后，输入行逐行来自「模型适配」
  里配的映射（通道未承接的类型显式标注并禁用，不静默丢弃），产物按同一条链提取
  并就地展示（视频任务制自动轮询，3s / 10 分钟上限）。
- **模式适配器新增「固定值」栏**：每次请求原样带上的请求体键值（如 Agnes 视频
  必填的 `mode:"text"` / `size:"720P"`）—— 17 种统一输入都是当次请求的值，
  表达不了接口必填的常量；合并顺序先常量后输入映射，同名字段输入赢。

## Fixed

- **视频中继此前不认 `remoteModel` 表**：`submitVideoViaApi` 只用全局通道设置，
  设置页配的视频模型根本不会被工坊 / 测试页的 API 通道选中。现在提交与轮询都按
  `model` 定向到该条目（端点 / 密钥 / 适配器映射 / 产物字段），未带 `model` 的
  工坊镜头链路保持既有行为与失败语义。
