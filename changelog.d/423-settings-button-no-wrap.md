## Fixed

- **设置页状态行的按钮文字不再因宽度不够折行、把按钮顶高（ISSUE #423）**：ComfyUI / Drizzle Studio / Ollama 三条「状态文字 + 右侧一排按钮」的行里，按钮此前既允许文字换行、又允许被 flex 压缩，窗口一窄就把「在浏览器打开」拆成两行、按钮高度翻倍，同一排按钮还高低不齐。现在按钮一律 `whitespace-nowrap` + `shrink-0`（不折行、不被压扁），宽度不足时由左侧状态文字截断、整排按钮落到第二行——退化的顺序是「先截可截断的文字，再换行」，绝不把控件压变形（规范 §3.8.1）。判据集中在 `src/app/(main)/settings/settings-status-row-config.ts`，三条状态行与本地 `Btn` 共用同一份，改一处即全线生效。
