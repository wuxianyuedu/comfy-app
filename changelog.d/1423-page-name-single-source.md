## Changed

- **主页各屏不再同时出现两个名字，标题区不再吃掉首屏上沿**（ISSUE #1423）。用户反馈「页签很多都有 2 套名字，一个简称一个全称」，截图里那一屏同时说了四遍：侧栏项「队列」→ 页签「队列」→ 屏内 `h1`「队列与运行」→ 副标题再解释一遍怎么轮转。
  - **根因是「名字有四个家」**：侧栏项 / 页签 / 顶栏都从 `NavItems.tsx` 的注册表反查，唯独**屏内页头是各视图里自己的字面量** —— `<h1>队列与运行</h1>` 与注册表那一份没有任何判据把它们连起来，于是分叉只需要一次「这里写全名更清楚吧」。
  - 收口：`NavItem` 新增 `viewLabel`（屏内页头口径，**缺省 = `label`**）+ 唯一出口 `pageHeaderTitle(view)`；侧栏 / 页签沿用 `label`（导航要短名）。「队列与运行」「历史记录」两处同义扩写删掉 —— 页头与侧栏统一叫「队列」「历史」。
  - 结构也收进 `~/components/ui/page-header` 的 `PageHeader`（`h1` 字阶档 + 一行副说明 + 右侧动作组，`shrink-0` 在动作组上）；`description` 的口径写死为「答案在别处拿不到的那句话」（时间口径 / 数据来源 / 能做什么），**写不出同义反复就不传 —— 不传就不渲染那一行**。七屏迁入：控制台 / 模型库 / 资源库 / 历史 / 队列 / 所有项目 / 产出。
  - 工具条形态的三处**不动结构**但同样删掉第二个名字：工坊顶栏的「工坊 · 全链路项目管线」（左边图标块已经说明是工坊）、成片顶栏的「· 视频成片工作室」（与页签那项指同一件事）。产出屏与项目主页的标题是**项目名（数据）**，屏名不进标题（它已经在页签上了）。
