## Added

- **工坊「镜头胶片带」**（`src/components/workshop/ShotFilmStrip.tsx`，接在镜头生图段的列表上方）。`ShotStudio` 是一列纵向的镜头卡，逐镜看很合适，但回答不了「16 镜跑到哪了、哪几镜挂了」—— 列表要滚动才能数完全局，胶片带一眼扫完，而失败帧在带上是一个**看得见的缺口**。
  - 一帧 = 镜号（补到两位，宽度齐才扫得动）+ 成图封面（没有成图时显示镜号本身，不留一个说不出话的灰块）+ 底部一根状态条（只表达状态，不表达进度）。
  - 标题行给「N/M 镜成图」，有失败时点名失败数；没有失败就不提。
  - 点一帧把对应那张镜头卡滚到视野中间。**刻意不造「当前镜头」这个状态**：这一屏没有选中态，凭空挂 `aria-selected` 会让读屏念出界面里不存在的事实 —— 这里的语义是「跳到第 N 镜」，是一个导航动作。
  - **刻意不显示假进度**：生成中的百分比在下面的镜头卡里给，那里有真实回报的数。

## Changed

- **镜头状态文案表从 `ShotStudio.tsx` 搬到 `shot-status-config.ts`**（并新增一份「状态 → 状态条配色」表，只用语义 token）。搬动的原因很具体：胶片带要用同一份文案，而胶片带会被 `ShotStudio` import —— 反向去 `ShotStudio` 取就成了一组循环依赖（`check-circular-deps` 判得住）。三个既有消费点（`ShotStudio` / `StoryboardPlanner.parts` / `VideoStudio.parts`）的 import 一起改到新路径，**不留一份 re-export 当第二个名字**。
  - 文案与配色是两张表而不是同一件事写两遍：文案给读屏与徽标（徽标色调由 `ui/status-badge` 自己管），配色给那根没有徽标容器的 1px 状态条。两张都按 `Shot["status"]` 穷举，新增一档会当场在类型上红。
