## Known

- 这一批照出一条**没修**的产品缺陷：两条退避（`error` 的 ENOENT 一支与 `close` 的 127 一支）
  都在**最后一个候选**上就地收敛 —— `i < pyCandidates.length - 1` 让 `i` 最大只到 2，
  于是 `tryRun()` 顶上那句「未找到 Python 解释器」**不可达**。后果是真机上没装 Python 时，
  界面显示「0 个节点」而不给任何原因。127 那一档的用例只钉「三个候选都起过 + 流收尾 + 空列表」，
  **没有**把「今天不给原因」写成期望（§11.2.1 第九条：期望值来自语义而不是实现）——
  修好那句可达性时这条用例会自然要求补上「必须有一句 ⚠️」。
