## Changed

- **每日档自动立案的单子标题带上构建号 / 事件 / 时刻**（ISSUE #2399）：
  ```
  ci(daily): 构建 cnb-6m4-1k5mrbthe · 事件 api_trigger_daily · 时刻 2026-10-24T11:40:05.000Z · 红在「每日全量E2E」
  ```
  过去标题只有格名（`ci(daily): 每日档红在「<格名>」—— 自动立案…`），同一格红五六次之后
  列表里五张标题逐字相同 —— 想回答「这张是哪一跑的」只能点进去看正文第一行。
- **去重键跟着拆开**：`titleKey()` 收成 `红在「<格名>」` 那一段，构建号 / 事件 / 时刻
  **只进标题、不进键**。进键就等于「同一格每天都是新的一张」，那正是去重那道坎要挡的形状；
  人工按旧形状写的那张单（`#2273`）照样带同一段，仍然自动进这一族。
- 用例：`tests/ci-daily-failure-issue.test.ts` +2（换了构建号仍认得出同一张单 +
  标题里真的带着那三件原值；键里不含 `cnb-` / `crontab` / 时刻）。
