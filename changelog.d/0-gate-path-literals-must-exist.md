## Added

- **门禁脚本里的路径字面量必须存在**（`tests/gate-hint-targets-exist.test.ts`，规范
  §12.16 新增一段）：扫 `scripts/check-*.cjs`（**自动发现，不维护清单**——手写清单本身
  就是会漂的那类东西）里作为字符串字面量出现的 `src|tests|scripts|docs|tools|e2e/…`
  路径，逐条要求磁盘上存在。口径两条：
  - **只看字面量、剥掉注释**：注释里出现旧路径常常是**有意叙述历史**（如「自某次拆分起
    `src/lib/app-settings.ts` 拆成目录」），把它算进来判据就会误响；而写成字符串的路径
    是要拿去比对 / 豁免 / 提示的，指错就是静默失效。
  - **自带反向保护**：命中总数（实测 111 条）必须 > 50，否则说明提取形态变了而不是
    「变干净了」；另有一条用例喂假路径必须判为不存在 —— 第一版判据就是靠这条自证暴露出
    它只认 `~/` 别名、对 5 个脚本**完全空转**（那些脚本一律写 `src/...`），门槛也因此
    从猜的 40 改成按实测 26 个脚本定的 20。
- 顺带把 `check-ui-primitives.cjs` 改法提示里的占位写法 `` `src/components/ui/<名字>.tsx` ``
  改成目录描述 —— 它长得像路径，会被上面的判据当死路径（这条判据连自己的文案都管住了，
  正是想要的效果）。
