## Changed

- **工坊不再把尺寸折成「832x1216」这种像素值给工作流，改给「宽高比 + 像素基准」，并去掉「倍数」（ISSUE #355）**：工作流库里的工作流多数用 `aspect_ratio`（COMBO，值形如 `16:9 (Widescreen)`）与 `megapixels`（FLOAT，1 ≈ 1M 总像素）声明尺寸，工坊却只给一串 WxH —— 这两个端口只能吃默认值，用户拖出来的线在运行期收不到值。现在工坊侧把「比例 + 像素基准」原样交给工作流：比例按端口自己声明的候选逐字命中（命不中退回默认值，绝不写非法选项让 ComfyUI 静默回落），像素档按 1k/2k/4k 折长边、百万像素档按 1M/2M/4M 直接落总像素量。内置 txt2img / 内置视频 / 定妆照这些接 WxH 的通路保持原样。
- **「对齐倍数」不再出现在工坊尺寸选择器**：倍数只影响 W/H 吸附到哪个网格（ComfyUI 常用 64），不是用户要决策的东西 —— 工坊侧固定用 64，弹层里那一格去掉。`size-multiple` 类别从对外参数分类中移除（倍数端口归回内部参数，走工作流默认值）；画布表单里的那一格不受影响。

## Fixed

- **尺寸口只有宽 / 高的判定漏掉「比例 + 像素」端口**：工坊给的尺寸此前只按 `size-width` / `size-height` 找落点，工作流只暴露 `aspect_ratio` / `megapixels` 时一律报 `unmatched`，用户看到「尺寸给了却没生效」。现在宽 / 高 / 比例 / 像素量任一类端口接住就不算没落下去。
