## Fixed

- **工作流库「画布节点」预览全屏时下方不再留一块非画布的空白（ISSUE #596）**：用户反馈「画布区域视频有问题，全屏时下方区域有空白却不是画布」。根因是高度链条断在容器上（画布被钉死 `h-[460px]`，外面还套了一层按内容高度收边的滚动层），而 React Flow 的 `fitView` 只按三列节点的包围盒缩放 —— 卡片比面板矮时它只放大到内容高度，画布底边以下就落回面板底色。现画布容器改为吃满可用高度，并在三列之下垫一层透明的背景板（尺寸由「面板可视尺寸与三列包围盒取大」给出），`fitView` 因此只会落在「等比铺满面板」的缩放上，画布一直铺到面板底部。
