## Fixed

- **浅色主题：卡片在白底上几乎没有轮廓（ISSUE #3520，采用「候选 B」）**
  - 浅色档的描边 `--color-border` 从 `#ececf1` 加深到 **`#e2e4ec`**：此前它落在白色页面上只有 ≈1.05:1 —— 卡片、输入框、行、chip 的边**全都看不见**（深色档 `#26262e` 对卡片 1.19:1，本来就看得见）。现在对卡片 1.20:1、对页面 1.27:1。
  - **设置页卡片的外缘**从 `border-border-subtle`（6% 黑的半透明发丝线）改成实线那档 `border-border` —— 半透明发丝线在浅色白底上同样只有 ≈1.05:1，卡片是「浮」在页面上的。
  - 强描边 `--color-border-strong`（浅色）从 `#d6d8dd` 加深到 **`#d2d5df`**：普通描边加深后两档会**倒挂**（强档反而更浅），这一档保证「强档更重」的次序（对卡片 1.39:1）。
  - **三档表面底色一个都没动**（卡片 / 行 / 控件仍是 `#f7f8fa` / `#eceef4` / `#e2e5ee`）：浅色色板的总落差只有 0.19，把阶梯重排会撞上「行上的弱文字不过 AA 4.5:1」那条（见 #3520 里两个候选的取舍），所以走「加深刻画边、不动底色」这一条。
  - 新增判据（`tests/surface-ladder-contrast.test.ts`）：浅色档的描边对卡片与对页面都要 ≥1.10；强描边不许比普通描边更浅（两档倒挂）；设置页卡片的外缘 class 走实线那档。
