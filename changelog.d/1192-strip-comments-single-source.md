## Added

- **一条判据：`stripComments` 只许有一份实现，台账双向都拦**（ISSUE #1192 的硬闸，先止住增长）。`tests/strip-comments-single-source.test.ts` 扫 `src` / `tests` / `scripts` 三层的源码文件，把「本地又抄了一份去注释实现」按台账核两个方向：
  - **新增一份 = 红**（错误信息直接指向 `./helpers/strip-comments`，并写明「它不满足你的形状就给它加一个模式，别再抄一份」）；
  - **收敛掉一份却没收紧台账 = 红**（留着已失效的条目等于让这张表失去记账能力 —— 本仓反复吃过「写着但没人核」那一类亏）。
- 顺带钉住一条**实测出来的缺陷形状**：两份视图层守卫用例用的是「裸的全局去行尾注释」（没有 `^` 锚也没有 `:` 护栏）。它对 `const url = "http://a"; wfParam(); // 收尾` 这样一行会把 `//` 之后整段吞掉 ⇒ `wfParam` 消失 ⇒ 「源码里不许出现 X」这类断言**假绿**（helper 只去整行注释，同一行它留得住）。这条不改变任何判据的行为，只让「再多一处」当场变红；两处分明列在台账里等那条线自己收。
  判据第一版只查那个子串，把两份**带护栏**（`(^|[^:\\])…`，语义安全）的实现误报进来了 —— 按「误报一片时精确化判据而不是放宽基线」的口径改成「有这个形状且没有任何护栏」。
