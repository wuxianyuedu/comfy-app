## Removed

- **剧本工具去掉三处没有信息量的界面元素**（ISSUE #1288）。三处去掉的都是「用户
  已经能看见、或根本用不上」的东西：

  ① 区块标题右侧的模型状态章（`本地 LLM · qwen3:14b` / `远端 API · <model>`）——
     同一屏的下拉里就写着当前生效的模型，状态章只是把同一件事说第二遍；未配置时
     它还退化成一个「未配置 LLM」按钮，而 AI 生成被点时会自己打开设置弹窗。
     `LLMStatusChip` 随之删除（零消费导出，规范 §12.16）。

  ② 「模板生成（离线）」按钮与它背后的固定模板（`buildScriptTemplate`）——
     产出的是带占位符的空骨架（「## 场景1 · 未命名地点」+「V1 角色名:（在此填写
     台词或旁白）」），用户填完仍是自己写，发布方反馈「这个产出的内容是用不了的」。
     剧本阶段的入口收敛为：AI 生成 / 手写 Markdown / 外部导入 `.md` 三条
     （与 `docs/guides/feature-workshop-flow.md` §3 的流向一致）。

  ③ 模型下拉下方的说明段落（「未手动选择模型时，沿用全局配置（当前：…）」）——
     下拉的选中态本身就跟随全局配置，点选哪个就用哪个，说明文字只是把选中态
     复述一遍。同款文案在「用一句话生成角色」区块一并去掉（同一件事不两处讲）。

## Changed

- **模型下拉的占位文案随用途切换**：`ExtractModelSelect` 在 `allowTool={false}`
  的生成场景（剧本生成 / 一句话生成角色）显示「选择模型」，不再沿用提取场景的
  「选择提取方式」——后者在这些位置描述的是另一件事。

- **「用一句话生成角色」的 `genSel` 退出 hook 返回值**：视图不再消费它（只消费
  `genSelectValue` / `setGenSel`），留着就是规范 §12.16 指的零消费导出。
