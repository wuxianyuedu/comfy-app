## Changed

- **`API 文档生成物与源同步` 这一档红了不再直接收场：CI 里就地重生成 `docs/api/`、再判一次**
  （ISSUE #2001 / 规范 §13.5.19）：
  `scripts/check-docs-api.cjs` 新增 `--check --autofix` 档，`.cnb.yml` 那一步改用它。
  先判一次，绿 ⇒ 立刻返回（一次都不多写）；红 ⇒ 按三个方向写入（落后覆盖、缺失补上、
  多余删孤儿）、**再判一次**，结论永远来自第二轮比对。
  收它的两条前提与 `生成态文档与源同步` 同源：typedoc 对同一份源产出逐字节相同（`verifyDeterminism`
  每次都在复核这件事），三个方向都只说明「`docs/api/**` 与源不一致」—— 源码写错由 `类型检查` /
  单测 / 生产构建各自去红，所以重生成不会把任何真回归改写成一次通过。
  登记在 `scripts/ci-autofix-duties.mjs` 的 `AUTOFIX_DUTIES`（`tests/ci-autofix-duties.test.ts` 双向核对）。
  ⚠️ 边界没变：**它不动 git** —— 修好的是工作区，提交与重跑仍由人 / 代理那一侧做
  （平台侧能否回写分支是另一条决策，见 §13.5.4 与 `ci-autofix-duties.mjs` 头注第 1 条）。
  修不好时仍然红，并说明它不是「忘了重新生成」（孤儿产物要手工删、两份源映射到同一个产物名它修不明白）。
