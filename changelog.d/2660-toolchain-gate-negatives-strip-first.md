## Fixed

- **`dev-launcher-toolchain-gate` 那 8 条反向断言的接收者改成先剥注释再判**（ISSUE #2660 第七批，
  落在它自己点名的候选文件上）。这一族的缺陷方向与批 1~6 相反：不是「字面量落在别处 ⇒ 假绿」，
  而是**「旧写法」作为反面举例写在注释里 ⇒ 判据红在那句解释上**。本仓这些 `.mjs` / `.rs` 文件的
  注释里正当写着这种举例（§12.4.2 禁的是日期/编号式流水，不是「为什么改」），所以 `not.toContain`
  拿着原文判就是自打自 —— #1192 当年收的是「整行注释」那一档，这一批补的是**行尾**与
  **切片之后**那两处（同一族的另外两形）。

  做法：文件内一处 `judgedCode()`（转调唯一实现 `./helpers/strip-comments`，`{trailing:true}`），
  只套在**反向**断言的接收者上；**正向断言刻意没动** —— 它们此刻还带着「字面量只住在注释里也算过」
  的假绿面，那一半要逐针脚判「这个字面量现在到底住在哪」，不是同一个改动，留作下一批。
  切片类接收者（`skipBody` / `gate`）在**切完之后**再剥，锚点与落空前置断言一个字没动。

  **双向变异证明**（打真实接收者上，`sha1sum` 核对还原）：往 `scripts/check-pnpm-available.mjs`
  末尾加一句反例注释——

  ```js
  // 别再在这里写 function checkNodeModules（判据只有 worktree.mjs 那一份）
  ```

  旧判据（原文）：`Tests 1 failed`（红在这句解释上，而代码里根本没有那份实现）；
  换 `judgedCode` 之后：`1 passed`。判决面不变的另一半：整份文件改前改后同为
  `Tests 57 passed | 13 skipped (70)`，`eslint` 退 0。
