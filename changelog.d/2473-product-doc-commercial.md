## Added

- **产品需求文档按商业化骨架补齐（ISSUE #2473）—— 北极星与验收基准**：
  - 新增 `docs/product/pipeline-stages.md`：**创作流水线六阶段规格**，每阶段统一写
    「目标 / 输入输出契约 / 人的用法 / AI 的用法 / 质量验收口径 / 当前状态 / 已知缺口 /
    代码落点」，六阶段口径一致，可直接当验收表用（通用口径一节写死双操作者、产物可追溯、
    推荐流不是闸门、失败有出口）。
  - `feature-catalog.md` / `feature-specs.md` 新增三个需求域（14 → 17 域）：
    `FR-SR` 系列与剧集结构（系列 / 季 / 集 / 跨集资产复用 / 整季排期 / 剧集元数据与交付清单）、
    `FR-QA` 成片质量与一致性（六阶段各一条质量口径）、
    `FR-AG` AI 操作者（双操作者同一能力面 / 自主编排含独立视频阶段与审批停点 /
    skill 驱动 / MCP 覆盖与一键跑完 / 机器面可观测与干预）。除 `FR-AG-05`（灰度）外一律
    `计划中`，每条「行为与验收」写成能跑命令 / 能指路径的形态。
  - 新文档登记进 `scripts/doc-facts.cjs` 的 `SCOPED_DOCS`（`docs/product` 默认全量纳入
    `doc:check`，未登记会被守卫判红），`docs/generated/` 镜像同批带上。

## Changed

- `docs/product/overview.md`：定位从「ComfyUI 的桌面创作工作台」改为
  **「AI 多剧集影视动漫制作工作台」**，并补三件此前缺失的东西 ——
  ① **北极星**（用 AI 稳定产出多剧集影视动漫：成片 > 一致性 > 单张素材惊艳度）与
  **成果定义**（系列 / 集 / 镜头 / 一致性四层各自的可核验判定）；

  共用同一份状态与产物，且**能全自动执行但质量停点由人拍板**；
  ③ **领域模型**（系列 → 季 → 集 → 剧本 → 角色 → 分镜 → 镜图 → 镜视频 → 成片）
  逐层标注「当前是不是独立实体」，并点名**角色 / 分镜是 JSON 列**是跨集复用与版本管理
  上不去的根因。非功能总表补「成片质量」一类。
- 文档索引同步：`docs/product/README.md`（文档清单 + 分工表）、
  `docs/README.md`（产品需求文档四篇 → 五篇）。
