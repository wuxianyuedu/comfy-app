## Changed

- **Tailwind 的源扫描面改成显式两棵根、默认拒绝**（规范 03 §3.11）：`src/app/globals.css` 现在写
  `@import "tailwindcss" source(none)` + `@source "../../src"` + `@source "../../.storybook"`。
  从前不写 `source()` 时 Tailwind 从项目根**自动发现**源文件，唯一的减法是「被 git 跟踪」——
  于是规范正文与它的生成物镜像、typedoc 的 HTML、`changelog.d/**` 的账本碎片、门禁与 codemod
  脚本里的样本串、根 `CHANGELOG.md`、用例目录全都进了产物。
- 实测（同一份 `globals.css`，只换扫描面）：**自动全扫 2796 条选择器片段 / 382452 字节，
  两棵根 2558 条 / 349887 字节 ⇒ 238 条规则没有任何调用点**；反向为空（新根 − 旧根 = 0 条），
  这一步只做减法。真实流水线也复核过：本轮 `next build` 出 4 份 CSS / 312121 字节 / 3621 条规则，
  探针点名的活类（`text-2xs` / `bg-card` / `rounded-node` / `z-canvas-ui` / `u-title-page`）全在，
  从前靠正文供给的死类（`text-[ 12px ]` 那族、`z-[99]`、`w-[360px]`、`min-h-[ 300px ]`、
  `duration-[0-9]`、`h-[ 43px ]`）一条都不在。
- **`.storybook` 是一棵必须的根**，不是顺手加的：`.storybook/preview.tsx` 引的就是同一份
  `globals.css`，而工作台外壳自己写了两枚任意值高度 —— 实测「只认 src」与「两棵根」的差集
  正好是这两条。摘掉这棵不省什么，只会让工作台的取景高度静默消失。

## Added

- **新判据 `tests/tailwind-source-roots.test.ts`（四格，全是形状判据）**：① 名单与登记表互为正反
  （多一棵 / 少一棵 / 登记了却不在磁盘上 / 把正文·账本·门禁脚本放进根，四种都红）；② 逐棵摘根复量
  —— 摘掉任何一根必须真丢样式，且丢的那些必须逐字写在那一棵里；③ **不看名单**的正面格：共用同一份
  CSS 入口的面，它写的数值型任意值必须在产物里（②判差集，而把一根从声明与登记里**同时**摘掉时
  差集会一起消失，样式消失却是静默的）；④ 判据自己的两个编译入口真的剥掉了生产根。
  四格各做过变异复演：换成 `docs` → ①红；helper 停止剥根 → ④红；同时摘掉 `.storybook` → ②③各红一条。
- `tests/helpers/theme-tokens.ts` 多一个出口 `stripSourceDirectives`，两个入口都先过它。
  不剥的话「钉成 `docs` 的那一遍」会连 `src` 一起扫，第 9 刀那条差集判据就在对一个混合面下结论；
  而 #1336 那份「固定输入源」会顺带扫全 src（判据第三格与 ④ 各认一件事）。
  `disableAutoScan` 同时改口：文件**已经**写着 `source(none)` 时不再假抛——过去的守卫是
  「替换后与原串相同 = 找不到那行」，而那行现在天生就带 `source(none)`，守卫会把正常形态判成故障。

## Docs

- `docs/DESIGN.md` 的扫描边界那一整块按现实重写：第 9 刀那套写作口径**从「生产必须」降级为
  「纵深防御」但没作废**（放宽根恰恰是最贵的动作，那条判据判的正是「假如放宽，代价是什么」）；
  并订正两条因此过期的主张 —— #1480 / #1536 账本碎片与「讲 12px 禁令必须点名被禁写法」这两笔
  「已接受的代价」现在**不再发生**，账本照旧不改写，但别再拿那笔交易当决策依据。
