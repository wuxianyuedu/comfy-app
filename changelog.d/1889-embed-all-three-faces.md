## Changed

- **正文与等宽两档也改为内嵌字面，三档一律不做 subset（ISSUE #1889）**：`--font-sans` 的 CJK 段与 `--font-mono` 的 CJK 此前整段落回系统字体 —— Mac 上一种字面、Windows 上另一种、Linux 上大概率一种都没有，而**绝大多数系统 mono 不含 CJK**，于是日志与路径里的中文按比例字面画出来（等宽外观当场失效）。现在三档都内嵌：标题 `Sarasa Gothic SC Bold`（既有）、正文 `Sarasa UI SC Regular`、等宽 `Sarasa Mono SC Regular`，各约 8.3~8.7 MB（TTF 的 35%），`public/` 合计约 25 MB 随桌包内嵌。**刻意不做 subset**：subset 能把 8.6 MB 砍到 1.45 MB（GB2312 那 6763 字），代价是生僻字静默掉回系统字体，而正文是用户输入（工作流名、项目名、提示词），生僻字是常态 —— 这条链的全部价值是「观感在任何机器上都一致」。实测真正贵的是汉字本身一字一份（2 万个字形占 `glyf` 的 95%），不是某一档用不到的字符块（排掉全部谚文只回收 1 MB）。判据从「一个文件名写死」改成**逐档核四者同名**（扩展名 / `format()` / 磁盘文件 / LFS 属性）+ 每档权重与落点相符 + 每档 family 排在它服务的那条栈的首选位（新增一档必须同批在 `EMBEDDED_FACES` 加一行、接线、给 CSS 与文件名对齐）。
