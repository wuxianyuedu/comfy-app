## Fixed

- **输入框底色看不出来 / 卡片内一行里的数字框「消失」（ISSUE #3519）**：设置页的文本输入框底色与卡片只差 1.04:1（深）/ 1.08:1（浅），而「按任务类型配置温度」那几行右侧的数字框**未选中时与行底逐像素相同**（框直接不见了）。
  - 根因一：**变体规则静默压掉调用点的底色** —— `ui/input.tsx` 基类上的 `dark:bg-input/30` 在产物里排在基础 utility 之后、特异性又相同（`:where()` 不计权），于是**深色主题下所有输入框的底色都是「30% 描边色叠在容器上」**，调用点写的 `bg-surface-2` 从未生效。修法：基类不再带常态的主题变体底色，**底色归调用点所有**。
  - 根因二：色板里「控件」这一档没有台阶 —— `--color-surface-2` 与卡片只差 1.04:1（深）/ 1.08:1（浅）。修法：改到阶梯第三级「卡片 → 行 → 控件」：浅 `#e2e5ee`（对卡片 1.20:1、对行 1.09:1）、深 `#2e2e3a`（对卡片 1.35:1、对行 1.15:1）。
  - 顺带修掉全应用同一族：**悬停底 `--color-subtle` 此前浅色档与卡片同值、深色档只差 1.02:1**（指针划过时看不出任何变化）→ 浅 `#eceef4` / 深 `#1f1f2b`（对卡片 1.10:1 / 1.11:1）。
  - 新增判据 `tests/surface-ladder-contrast.test.ts`：从**编译产物**真量「卡片 / 行 / 控件 / 悬停底」每一档与下面那档的对比度（深色下限 1.10、浅色 1.08）与压在上面的正文 AA，并钉住「`ui/input.tsx` 基类不许带 `dark:bg-*` / `light:bg-*` 底色」（这族失效是「类名写了、却没生效」，tsc / lint / 色值扫描都看不见）。
