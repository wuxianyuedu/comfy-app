## Added

- **工坊「API 通道」替换为「模型适配」**：不再配置一个全局端点，而是为每条远端模型（生图 / 视频类）配置**工坊各模式下的输入 / 输出适配器**——模式即工作流库定义的模式（文生图 T2I 的输入 = 提示词 + 宽高比 + 百万像素，输出 = 图片；图生图 = 图片 + 提示词；深度 / 姿态 / 线稿 / 掩码 / 局部重绘 / 首尾帧视频各有默认输入清单，可选类型共 13 种）。每个模式配置端点路径、统一输入 → 请求体字段名的映射、产物字段路径；工坊发起生成（定妆照 / 镜头生图远端）按适配器翻译统一输入，产物按路径提取。适配器随模型条目存库（remoteModel 新列，drizzle push 自动迁移），设置页整表保存不会清掉已配适配器。未配置适配器的模型回落 OpenAI 兼容 images/generations 默认映射（旧行为）。工坊顶栏按钮与「生成资源」状态改口为「模型适配 / 远端模型已适配 / 未适配」，旧 API 通道设置弹窗移除（视频直连通道暂由原服务端配置继续生效，适配器化随后续迭代）。
