## Changed

- **「关闭应用时连带关闭 ComfyUI」默认改为不勾选**（设置 → 退出与后台服务）。此前默认随应用退出连杀 ComfyUI，而 ComfyUI 冷启动与加载模型是分钟级成本，等于每次打开应用都要重付一遍，且被强杀时正在跑的任务没有收尾机会。现在默认保活（脱离进程树，退出应用后继续运行，下次打开直接复用），需要「退出即关」的用户在设置里勾选即可；开关语义不变，仍只在「拉起那一刻」生效，改动下次拉起生效。Ollama 的同类开关默认保持不变（仍是勾选）。**存量安装**：旧默认值早已被写进各自的设置文件，只改默认对它无效，故做了一次性迁移把该值落成新的默认（只此一次，之后手动勾选不会再被覆盖）。
