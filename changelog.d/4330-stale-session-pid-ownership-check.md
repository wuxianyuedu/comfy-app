## Fixed

- **启动期孤儿回收先验归属，防 Windows PID 复用误杀（#4330，P1）**：
  `reapStaleSession` 此前对会话锚点里的 `child_pids` 只做 signal-0 探活就
  `taskkill /T /F` 整树强杀——而壳正常退出**必然**留下锚点（编排器收不到信号、
  没机会 `clearSession`），某个已死子进程的 PID 被系统复用给无关进程时，下次
  双击启动会把那个无关进程连同它的子树一起杀掉。现在动手前逐个读命令行
  （`processCommandLine`），只回收「命令行落在本检出根内」的 PID（编排器拉起的
  子进程都以检出内绝对路径为入参；被复用的无关进程几乎必然不含）；读不到或
  验不出归属的一律保守跳过、锚点保留（下次启动再验），跳过会落一行 WARN 不静默。
