## Fixed

- **悬停提示不再被窗口标题行吃掉半个身子（ISSUE #1377）**：桌面壳里窗口顶部是自绘的标题行（页签 + 拖拽区 + 窗口按钮，层级 `z-chrome`），而 TopBar 那排按钮上的气泡默认往上摆 —— Base UI 的 `flip` 只对**视口**判溢出，气泡顶部落在视口内它就不翻转；标题行比气泡高一个数量级，于是气泡上半截被盖掉，只剩一条白边加一个箭头。实测 TopBar 上四个入口（搜索 / 深浅色 / 系统消息 / 应用菜单）全中招。修法不是抬气泡层级（那会吃掉页签与窗口按钮的可点区域），而是把「可用区域 = 视口减去标题行」交给定位引擎（新增出口 `useOverlayBoundary` + `anchoredOverlayBoundary`），气泡据此改从下方展开。同一份边界一并接到**所有**锚定浮层：下拉 / 选择器 / 气泡卡 / 右键菜单 / 导航菜单。
