## Fixed

- **dev 壳自动更新的「本地壳未过期 ⇒ 不取壳」用例不再依赖检出环境状态**（ISSUE #4784）。
  它此前拿 `root: process.cwd()` + 默认壳路径当前提，而纯 master 检出上壳常落后于
  src-tauri 源码、且本机可能配有 CNB 令牌 —— 用例会误入「远端检查 → 取壳建基线」分支，
  甚至向 nightly Release 发真网络请求，断言「本地壳未过期」随之稳定红。现改为在临时目录
  显式构造「壳（2030）比 src-tauri 源码（2020）新」的未过期前提，并同批补上
  「不取壳（`fetchShell` 零调用）」的防回归断言。
