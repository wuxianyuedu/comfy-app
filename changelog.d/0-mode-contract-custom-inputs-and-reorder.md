## Added

- **模式契约：参数可以调序、可以自定义新增、并且能浏览全部可用参数**（「模式契约」弹窗的「统一对外参数」区块）。三件事一起补上，是因为它们指向同一个缺口 —— 此前契约口只有内置那几类、顺序也只能是代码里定的那一份：
  - **调序**：每个输入口行右侧新增 ↑ / ↓（首尾自动置灰）。顺序**就是**工坊对外的参数顺序（数组下标即界面上的序号），所以调序改的是契约本身，顺序随契约一起落库，工坊 / 工作流库两端读的还是同一份。
  - **自定义参数**：新增「＋ 新增自定义参数」—— 作者自己起名 + 选一个**简单类型**（文本 / 图片 / 数字）。口 id 由系统生成并把类型编进去（`custom-<类型>-<序号>`），于是类型是结构信息、纯函数层（映射 / 封装 / 适配器）直接从 id 就能读出来：自定义口无需在契约口清单之外再带一张类型表，在落点画布、封装视图、流程测试表单里的行为与预制口完全一致（能连线、能填值、能下发）。名字单独存在契约的 `customInputs` 里，删除口时定义一并回收。
  - **浏览全部参数**：原来的「可添加口」虚线按钮只列**还没加**的那几个，读起来像「这套系统只支持这些».现在换成一张完整的参数表（预制口全列出，已加入的标 ✓ 不可重复添加），自定义参数单列一块（可删、可改名）。
- 自定义参数的值随契约口 id 走 `WorkshopExposedValues.custom`（数字口下发的是数字，不是字符串）；`buildEncapsulatedInputs` 新增可选的 `contractIds` 入参 —— 客户端流程测试与服务端编排各自把该模式生效的契约口清单传进来，没传时回落内置默认契约（作者给自定义口填的值会如实进 `unmatched`，不静默丢）。
- 工坊控件形态新增 `number`（自定义「数字」口的数值输入框）；`EncapsulationControl` / `ContractEntryDisplay.control` 与 `modeContractsSave` 的 zod 校验同步支持 `customInputs`。

## Changed

- 工坊封装的对外口标签对**自定义口**改读契约里作者填的名字（预制口仍取统一的那一份措辞，见 `exposedParamDisplayLabel`）：自定义口没有统一措辞，按「类」取会显示成「提示词」这类张冠李戴的名字。工作流库「画布节点」的连线闸门（`isValidConnection`）与卡片列现在读**同一份**契约口清单，自定义口的圆点不再被判成「这一行不收这个口子」。
- `lib/workflow/workflow-exposed-params` 新增自定义口 id 的解析（`exposedCustomKindOf`）与「自定义口类型 → 已有关」的映射：自定义口复用现有端口族与类型展示，不在 `ParamClass` / `ExposedParamClass` 上新增成员 —— 映射层因此**一行未改**。
