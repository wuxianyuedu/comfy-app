## Fixed

- **模式契约 / 测试模型页的五处口径修正（ISSUE #3778）**：诉求单现场逐条 ——
  - **统一输入行改按模式契约渲染**（不再来自适配器映射）：行序 = 契约口序，
    每行带**必填 / 可选**标识（随契约 `required` 生效集）；契约里配了 4 个参数
    就显示 4 行 —— `seed` 不再因为适配器没映射它而消失。必备且通道承接得住的行
    空着会在本地拦下（逐行点名），适配器映射了但通道承接不住的照旧显式标
    「未承接」禁用；通道承接得住但适配器没映射的行明示「本次生成不会带上它」，
    不静默丢。
  - **模型下拉按所选模式收窄**：只列配了该模式适配器的模型 —— 模式页签徽标说
    「0 模型」时，下拉里不再出现不支持该模式的模型；切换模式时选中项若不支持
    新模式自动清空；该模式没有候选时给可读空态并指向「模型适配」。
  - **尺寸选择器与工作流库换成同一个 `ShotSizePicker`**：比例 / 像素（分辨率 ·
    百万像素）/ 倍数一段不缺，另有百万像素步进器与尺寸表入口；**倍数段只在选中
    百万像素档时出现**（分辨率 1k/2k/4k 的宽高由场景尺寸表给定，倍数没有意义
    —— 此前两处各一份实现，文生图 / 图生图长得还不一样）。
  - **远端模型按名解析补上供应商链**：#3501 起 Base URL / 密钥以供应商为单位，
    模型行自己的两格为空是常态 —— 此前按名解析只认模型行自己那格，这类模型
    被误判成「未配置」回落全局通道，测试页报「远端 API 生图通道未配置」而
    远端模型明明配了（诉求单第 5 条的现场）。现在连接参数按「条目自己的 →
    所属供应商的」折算（生图 / 生视频 / 轮询三路同源）；模型在但两处都没填
    地址时报**定向**文案（点名模型），不再套通用文案。
  - **模式契约编辑器的口类型说明分两行**：类型一行、描述另起一行，类型值用
    英文（`text` / `number` / `image` / `size`，与口 id 同一语言）。
  - 通道层同批：生图 relay 承接 `seed`（请求体 / 统一输入 / 默认映射 /
    `RELAY_INPUT_TYPES` 镜像四处同步）；`ASPECT_RATIO_PRESETS` /
    `clarityOptionsFor` / `relayInputCount` 这三个只服务旧尺寸实现的出口随
    统一移除。
  - 用例：`model-test-config.test.ts`（契约行 / 尺寸桥 / seed 组装）、
    新增 `api-channel.server.test.ts`（供应商链折算 + 定向报错，fetch 打桩
    断言实际打到哪、带谁的密钥）。
