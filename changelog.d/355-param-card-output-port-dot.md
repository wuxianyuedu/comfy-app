- **工作流库的对外参数卡片右侧补上小圆点端口，并与工作流节点上的参数行画线相连（ISSUE #355 复审）**：卡片上虽然已经写好「STRING positive_prompt」，但右侧那颗圆点此前**根本没有渲染**——库里那列是只读消费，端点被整体关掉，作者看到的是「一个口连到哪一行」得靠对照两处文字去猜。现在每张卡片在它的输出端口行右沿画一颗小圆点（12px，与项目画布同款视觉、同款配色：STRING/INT 灰、IMAGE 紫、VIDEO 粉…），并叠一层只读 SVG 连线，从圆点画到宿主卡片上**被落到的那一行**——自动判定的落点画虚线、作者改过的画实线，与编辑器画布同一套语义。线是量出来的：卡片高度随端口行数变化、宿主行高度随控件类型变化，量不到锚点就整条不画，不留悬空线头。库内仍是只读消费（拖线 / 断开 / 恢复默认都在编辑器画布上做），卡片列自身不碰 React Flow。另把圆点的定位基准从「整张卡片」改到「输出端口行」，并抽出共享常量 `PARAM_NODE_DOT_OFFSET` / `PARAM_NODE_DOT_SIZE` 供编辑器画布与工作流库共用——两处圆点从此都骑跨卡片右缘，不会一边贴边、一边内缩。
