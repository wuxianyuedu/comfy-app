## Added

- **视图页签条**（`ViewTabStrip`）：一条常驻、可单独关闭、带项目名后缀的页签栏。
  - **桌面壳内**并入窗口标题行（与 ComfyUI 等 iframe 页签同一条横条，视图页签代表「主应用」那一格）—— 不另起第二条，避免「同一窗口里两套相似但规则不同的页签」。
  - **浏览器 / dev** 渲染在内容列里（`AppShell` 之内）。放这一层不是随意：`ShellTabs` 那一层是整窗宽度，而侧栏是 `fixed` 定位，栏放在那儿会被侧栏压住 —— 实测页签的关闭按钮报 `subtree intercepts pointer events`。
  - 页签身份 = **(视图, 项目)** 二元组：同一个「工坊」在两个项目里是两页，标题写成「工坊·雾中来信」以便分辨；全局视图（首页/模型/队列…）各至多一页。
  - 首页那一页**不给关闭按钮**；关掉当前页落到**左邻**；只剩首页时栏仍然在（不塌成另一种布局）。
  - 「+」菜单开新页签。这一颗不是装饰：侧栏刻意不列项目内那六个视图（主页/画布/工坊/资源库/产出/成片），它们此前唯一的入口就是被退役的那条切换器。

## Changed

- **`ProjectTabBar` 退役**：项目内那六个视图现在就是普通视图页签，入口是页签条的「+」与侧栏/首页的导航动作。原先那条切换器与新的页签栏表达同一件事，留两份迟早出现高亮态不一致。
- **壳探测收成一处**（`useTitleBarTabsActive`）：这条栏该放标题行还是内容列，`ShellTabs` 与 `AppShell` 现在问同一个 hook。两处各写一遍会产生「壳里两条栏、浏览器里零条栏」这种各自看都自洽的错。
- **`ShellTabs` 头部注释收窄**：原文写「浏览器 / dev 不渲染任何应用内页签栏」，实际决策针对的是 **iframe** 页签栏（ComfyUI 在浏览器里用真实标签页打开）。视图页签切的是应用内视图，与浏览器自己的标签页不是同一件事，不构成重复 —— 原话留着会让下一个读代码的人以为视图页签也不该有。
- **`WorkspacePage` 抽出 `useWorkspaceTabs`**：页签状态、恢复/落盘、打开/选中/关闭都在 hook 里。组件此前顶到 411 行、越过 §12.13 的 400 行阈值，而判据要的是按职责拆，不是在一个函数里加注释分段。
- 顺带删掉一处**只写不读**的状态：`viewHistory` 的注释写着「用于智能返回导航」，但组件里从来没有读过它。移除不改变行为（返回导航实际由别的东西承担），留着会让下一个人在它上面继续盖逻辑。

## Tests

- 回归：`critical-flows` 整份 26 条、其余各套合计 **35 条通过**；单元侧 `src/components/studio` + `src/app` 共 138 文件 1579 条全绿。
- 写用例过程中自己踩到并修好的一条：Playwright 的 `getByRole(name)` 默认**非精确**匹配，`{name:"模型"}` 会先命中页签上的关闭按钮（可访问名「关闭 模型」）。定位一律加 `exact: true`，并把这条坑写进 spec 注释。
- 另修一条**主干既有红**：`nav-items.test.ts` 的「恰好两项：模型适配 / 模式契约」在 `aa3ee904` 加入「控制台」浮层入口后没回头更新，确定性红（实测多收一项 `console`）。按现实补成三项、保留「恰好 + 按序」的强度，不降判据。
- 一处未复现的观察：整份跑 `critical-flows` 时见过一次「每条日志末尾的复制按钮」红，单跑与整份重跑均绿。**只观测到一次，不给成因**，也不据此改任何判据。
