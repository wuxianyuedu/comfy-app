## Changed

- **`@types/node` 从 22 对齐到当前运行时（Node 24）**：`^22.0.0` → `^24.13.6`。此前类型
  面向的是 Node 22 的 API 面，而 `.nvmrc` 与开发机跑的**都是 Node 24** —— 运行时新加的
  接口在 `tsc` 里会报「不存在」，只能靠 `as` / `@ts-expect-error` 绕开，等于让类型层
  对「本仓库跑在哪个 Node 上」说谎。对齐后这件事只有一个出处。

  `@types/node` 只含类型声明、**不带任何运行时代码**，所以这次升级对产物与运行时行为
  零影响；`tsc --noEmit` 在 24 的类型下**零报错**，没有需要跟进修的类型问题。因此
  对齐口径也一并定下来：**`@types/node` 的大版本跟随 `.nvmrc`，不跟 npm 上的 `latest`**
  （`latest` 现为 26.6.2，对应 Node 26 = current 线，而本仓库跑的是 24 = LTS 线）。
