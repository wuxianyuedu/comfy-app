## Added

- 侧栏项的页签行为可按项配置（#3623）：主界面侧栏的每一项点开后是**独立标签页**
  （常驻，切走不关）还是**共享标签页**（切走即关，不在页签条上留位置），落在 JSON
  里（`src/lib/shell/sidebar-tab-defaults.json`），并在「设置 → 侧边栏」可改：
  - 配置面 = 侧栏的九个全局项（首页是固定页签，不在配置面内）；当前生效值在界面上
    看得出来，改动即时生效（已开着的页签按新规则在下次切换时生效）。
  - 两种保存方式与「模式契约」同一套口径：「保存」只落本机（`data/` 下的本机覆盖，
    开发版与正式包都能用），「保存为项目默认（跟代码走）」写进入库那份 JSON、只在
    开发检出出现；「还原默认」只在真有本机覆盖时出现。
- 「是不是开发检出」这条判据收成一处（`src/lib/shell/dev-checkout.server.ts`）：
  「模式契约」与「侧栏页签行为」两处配置面共用它，不再各写一份。
