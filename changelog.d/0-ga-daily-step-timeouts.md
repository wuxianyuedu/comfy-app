## Changed

**GA `daily.yml` 每个 step 补上与 CNB 对应 stage 同值的 `timeout-minutes`**（GA 侧适配清单 G-3）

此前只有 job 级 300m 兜底：任何一格挂死都只能等到顶层墙钟，报错也不带「是哪一格」。
现在按 CNB 每日档各 stage 的 `timeout` 逐格对齐：

| step | 预算 | 对位 CNB stage |

| 安装依赖 | 20m | `每日安装依赖` 20m |
| 同步数据库表结构 | 30m | 平台默认 30m |
| 新鲜度账 | 5m | `每日新鲜度账` 5m |
| 生产构建 | 30m | `每日生产构建` 30m |
| ESLint 零警告 | 30m | `每日 ESLint 零警告` 30m |
| 浏览器安装 | 20m | `每日浏览器安装` 20m |
| 全量E2E | 45m | `每日全量E2E` 45m |
| API 文档生成与自检 | 30m | 平台默认 30m |
| 单元测试 | 45m | `每日单元测试` 45m |
| 覆盖率报告（产物上传） | 5m | 只做上传，不是 CNB 的报告生成 |

合计 244m < 顶层 300m。CNB 侧完全不动（任务 3 并行期纪律，§13.5.34）。
