## Changed

- **工作流编辑器画布上的「对外参数卡片」只在「编辑 IO」模式下显示**：这些卡片（左列 =「对外要什么、落到哪一行」，右列 =「对外给什么、从哪一行读」）表达的是**映射**这一层关系，属于编辑态工具，却一直画在常态画布上 —— 它们 `zIndex: 20` 压在图节点之上、贴着宿主节点左右各排一列，常态查看工作流时会把图本身挡掉一片（用户口径：「工作流编辑器画布中，不应该显示对外暴露的参数节点」）。现在由 `ioEditMode` 门控：退出编辑模式 → 卡片与映射线一并撤掉，画布只剩工作流图；重新进入编辑模式即原样回来。落点数据仍在 `paramMap` 里，隐藏不会丢已连的线（映射线同批撤掉，避免留下指向不存在卡片的线头）。
