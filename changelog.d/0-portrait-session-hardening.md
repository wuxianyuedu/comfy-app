## Fixed

- **角色定妆照的生成 / 导入不再会「跑完却什么都没落上」**，四处静默失败一并收口：
  - **并发连点不再起两次任务**。原先靠会话里的 `busy` 判断是否已在生成，而它是渲染态：同一帧内连点两次（或程序化调用）两次读到的都是旧值，会放过第二次，两条任务并发写同一份会话，先完成的那条把 `busy` 提前抹掉（按钮提前解锁、进度跳回）。现在生成与导入共用一把原子锁（`taskRunningRef`），第二次调用直接返回。
  - **生成期间切换项目不再白跑一次**。换项目会用目标项目的草稿替换 `characters`，发起时那张角色卡已不在列表里，在途结果无处可写：图片进了素材库、界面上却没有候选。现在切换 / 新建项目、以及删除当前项目在定妆照任务期间会被拦下并给出提示条（「定妆照正在生成，请等这一次跑完再切换项目」）；若归属真的变了（例如 API 直调），则保留素材库文件并把原因如实写在提示条与执行日志里，不再静默丢弃。
  - **导入失败现在会进执行日志与 `log/workshop/` 落盘历史**（此前只写会话里的错误提示，日志面板与历史里完全看不到这次失败）。
  - **每次生成的「开始」一行也会落盘**。首行（通道 · 模型 · 尺寸）此前只进界面、不写历史，回看 `log/workshop/` 时只有「完成」没有「开始」，看不出这一张是用什么参数跑的。
- **补齐选择后过期的门禁提示会消失**：改通道 / 尺寸 / 模型这一动作本身会清掉上一轮的错误提示。此前「本地通道需要先选模型」在选好模型之后仍挂在界面上，看起来像还没配置好；生成失败的详情另有执行日志兜底，清提示条不会丢信息。
