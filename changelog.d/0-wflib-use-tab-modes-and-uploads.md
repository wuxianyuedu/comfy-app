## Fixed

- **工作流库「画布节点 → 实际使用」现在能切换工作流模式**：多模式工作流（文生视频 / 图生视频…）在「实际使用」里此前只有一个**只读的模式名**，想换模式只能切回「编辑对外参数」页签去点宿主卡片上的下拉；而那个只读名字被压成两行（「单图生」/「视频」）。现在同一个位置就是模式下拉，与「编辑对外参数」页签的宿主卡片逐字同款，切换只改查看 / 运行语境、不动默认模式。

- **图片口不再把工作流图内的默认值当成「用户已选」，选中后能看到图**：图片参数的「默认值」其实是 ComfyUI 服务器上的一个文件名（常见的就是 `image` 这类占位名），此前被 `defaultInputValues` 播种进表单，于是表单一打开就写着「已选：image」——用户以为已经选好了一张图（实测反馈）。现在图片口播种**空值**（键仍在，免得默认值刷新把用户上传过的那张图当成「被摘掉的 pin」删掉），运行时不下发该字段，仍由 ComfyUI 按图内默认值兜底，语义不变。同时「画布节点」表单与「工坊封装」流程测试两处都在选完之后渲染**缩略图预览**（地址走 `~/lib/media/media-url` 出口），此前只有一行文件名，选完看不到图。

- **详情头部「类型 / 来源 / 模型标签」一行等高对齐**：三枚胶囊各自继承不同祖先的 `line-height` —— 类型胶囊在 `Button` 里继承到 `text-sm` 的 20px 行高，另两枚继承父级的 15px；模型标签还多一道 1px `border`（把盒子撑高 2px）。三块底色因此高矮不一，看着就是「上下没对齐」。现在行高统一到 1（由各自 10px 字号决定），那圈描边改走不占布局的 `ring`。

- **两个页签的运行进度与产物在切页签后不再丢失**：`ui/tabs` 的 Panel 切换即卸载组件，而运行视角（进度 / 产物 / 终态）只活在各自的 `useState` 里 —— 登记表里明明有，没人去读。实测现场是「在画布节点点了生成 → 切到工坊封装 → 再切回来」看到一片空白，两个同时跑时一边看不到进度、生成结束后两边都看不到产出。现在进度也写进运行登记表（`WorkflowRunMeta.progress`），两个入口共用一份恢复逻辑（`use-workflow-run-resume`）：还在跑就重订阅 SSE（服务端回放补齐历史帧，日志按 `(t, msg)` 去重）、已完成直接恢复产物、已失败直接恢复原因；订阅出口 `watchWorkflowRun` 同时是「进度 / 产物 / 终态写登记表」的唯一入口，两条路径写的是同一份状态。
