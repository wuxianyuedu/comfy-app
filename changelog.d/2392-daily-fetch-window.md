## Fixed

- **每日档的取数从「条数窗」改成「时间窗」——「红了一晚而机制安静失明」那一格补掉**
  （ISSUE #2392）。当场读数（今晚 00:00 那一跑 `cnb-gc2-1k5psl88r`，`每日失败立案` 9.0s
  **成功**，而它一个字都没写）：
  ```
  [daily-failure-issue] 每日类派发有 1 条，但没有一条拿得到**终态**的逐格读数
      （在跑的那一跑排除在外；取不到 ≠ 没红，也 ≠ 绿） → 这一格没有可立的案，一次都不写。
  [daily-failure-issue] ※ 这一格本该以退码 2 结束（…），但平台那一跳带 `--no-block`：**不拦路**。
  ```
  而账上事实相反：上一条每日派发就是真红（`每日单元测试 :: error :: 1096.7s`，ISSUE #2344
  连续第三次复现），且开着的单 #2344 带着机制自己的去重键。根因只有一句：
  **判据声明的是时间窗（36h），取数拿的是条数窗（60 条）** —— 60 条折算多久由当天多忙决定，
  不由判据决定。实测（同一份取数入口，按 `--page` 逐页取回）：
  ```
  pageSize=60  60 条 · 每日类 1 条 · 最早一条 2026-10-25T08:59:27Z   ← 只回到约 7.5 小时
  pageSize=100 100 条 · 每日类 3 条（含两条 error 的每日派发）
  page1 08:59→16:31Z / page2 03:06→08:36Z / page3 10-24 09:36→03:01Z / page4 10-23 10:27→09:25Z
  ```
  ⇒ 那一页里唯一的每日类派发恰好是**正在跑的这一跑**，按设计被排除，于是「上一跑」为空。
- **两个消费点各修各的失效形态**（同一份取数，两种坏法，都不许继续）：
  - `每日失败立案`：被 `--no-block` 按成退 0 ⇒ **安静失明**，正是 #2274 立这条机制要消灭的那一型。
    现在盖不住窗口就明说「没有依据 ⇒ 一次都不写」，并念出覆盖自证（翻了几页、最早一条的时刻）。
  - `check:daily-attendance`：`latestDailyDispatch()` 拿到空 ⇒ 直接报**缺勤（退 1）**，
    而那一跑其实出勤了 —— 把「我没取到」写成「它没跑」。现在这一格落 **2**（没结论），
    因为 `1` 的主语必须是「它没跑」。
- **新增唯一口径 `fetchBuildsCoveringWindow()`**（`scripts/check-daily-attendance.mjs`）：按
  `--page` 翻页往回取，直到最早一条早于 `now - 窗口` / 翻到列表末尾（不满一页 = 后面确实没有
  历史，算盖住）/ 撞到页数上界（不算盖住）。返回 `{list, covered, pages, oldestMs, note}`，
  `list=null` 与 `covered=false` 是两件事（前者是第一页就没取到）。**窗口只有
  `DEFAULT_WINDOW_HOURS` 那一把尺子**，两个消费点共用，不各写一份小时数；`FETCH_PAGE_SIZE`
  明确写成「翻页单位，不是窗口」。逐格的详情仍只取最近三跑（`fetchBuildsCoveringWindow`
  不改变那一层），所以这一改动多付的是**列表**那几页往返。生产入口当场复算（本地、真平台、
  `--dry-run` 一条不写）：
  ```
  [daily-failure-issue] 取数覆盖自证：取满窗口（36h）：4 页 / 240 条 · 最早 2026-10-23T10:38:47.000Z
  [daily-failure-issue] 上一跑 cnb-gc2-1k5psl88r · 事件 crontab: 0 0 * * * · 2026-10-25T16:00:22.000Z · 判定 failed · 红格 1 个（每日单元测试） · 被带下去 0 格
  [daily-failure-issue] --dry-run：「每日单元测试」→ 在 #2344 下追加一条读数（不新建） · 一条都没写
  ```
  同一条链的墙钟从 9.0s（失明那一跑）涨到 16.8s（4 页列表 + 3 跑详情 + 逐格日志摘录），
  而它前面是 5m 的 `timeout` 声明 —— 代价与这条链上别的格（`每日安装依赖` 189.5s）同量级。
- 离线档（`--from`）不假装证明覆盖：它念的是「离线档不证明覆盖 —— 这份列表谁取的谁负责」。
  在线档每次多打一行 `取数覆盖自证：N 页 / M 条 · 最早 <ISO 时刻>`，`--json` 里同名键。
- **顺带修掉一本账里的假读数**：`scripts/.gate-thresholds.json` 里 `STAGE_WALL_CLOCK_MS` 那条
  （`report` 档）记的是换算后的 `1500000`，而判据按**源码字面**取值（源码写 `25 * 60 * 1000`
  ⇒ 取到 `25`），于是每次跑都念一条假的「源码 ≠ 账」。改成按字面入账并把单位写明

  整体入账（3 条），它过去不在那本账的覆盖面里。
