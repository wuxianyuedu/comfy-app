## Fixed

- **判据从「三个条件」收成两个**：上一轮泛化幽灵 token 判据时写的是「字面量 + **无兜底** +
  `--color-` 前缀」，那个「无兜底」正是本条要收回的豁免 —— 现在只认「字面量 + 带 `--color-`
  前缀」，带不带兜底都判。
- **顺手钉住这条判据为什么可以收得这么窄**（写进规范，免得下一个人以为能抓所有未定义变量）：
  `--color-` 命名空间是干净的 —— 实测全仓 `setProperty` 与 style 对象键里**都不出现**
  `--color-` 名字，即该前缀内没有「运行期注入、CSS 里查无此名」的正当用法；而 Tailwind
  裸变量 `text-(--x)` / `w-(--x)` 那一类里这种注入是**常态**（310 处引用 43 处如此），
  所以那些仍然不判。**如果哪天有人开始运行期注入 `--color-*`，这条判据要跟着改。**
