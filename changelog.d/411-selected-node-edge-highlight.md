## Added

- **画布上选中节点时，与它相连的连线会加粗提亮，其余连线压暗（ISSUE #411）**：节点一多，「这个节点连到了哪里」就得靠人眼沿线一根根追。现在选中节点后，指向它的上游连线和从它流出的下游连线一起加粗（画布前景线由 2.5px → 4px）并提亮到满不透明，外发光同步增强，曲线上代表连接的圆点也放大；画布上其余与它无关的连线压暗降噪，视线自然聚焦到相关的那几条上。连线颜色只提亮、不换色——连线的色相承载着数据类型的语义（IMAGE / MODEL / LATENT…），换成品牌色反而会把「这条线上流的是什么」抹掉。取消选中后画布恢复原样（未选中任何节点时全图不做任何压暗，避免一次误点就让整张图发灰）。工作流编辑器画布与项目画布两处一致；工作流编辑器里「对外参数卡片 → 宿主节点端口」的映射线不参与高亮——它表达的是「参数落到哪一行」，不是图上的数据流。
