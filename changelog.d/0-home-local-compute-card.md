## Added

- **首页新增「本机算力」卡**（`src/components/studio/LocalComputeCard.tsx`，落在快捷入口与最近项目之间）。此前这些读数只在底部状态栏那一格里以三个百分比出现，而状态栏说的是**结果**；用户在「现在能不能开跑一条镜头」这个判断上问的是**原因**。卡片把三种「看不见数」的情形分开说：
  - **未运行** → 显存/内存整档不画（画 0% 等于把「读不到」谎报成「没用」），正文给「ComfyUI 未运行，显存/内存暂不可用」；
  - **连着但首帧采样未到** → 徽标仍是「在线」，正文给「已连接，占用数据首帧读取中」，不报未运行；
  - **迟滞容忍期** → 保留上一次的条、整组变暗，并把「显示的是上一次数据」写成正文而不只是 `title`。
  - 数据来源只有 `useComfyReadiness()`（它已经吃 `src/lib/comfy/comfy-stats-store.ts` 那条**单点轮询**），首页多挂一处不多一路请求；视图层零新增 IO（规范 §17）。单位沿用 `~/lib/format-bytes` 的十进制 GB，不另造一套口径。

## Changed

- **显存/内存的口径命名收成一处**（新增 `src/components/studio/comfy-resource-metrics.ts`）。三档的标签、口径说明与「缺值整档隐藏」的判据此前只在 `BrowserStatusBar.tsx` 里各写一遍字面量；首页卡要说同一件事，再抄一份就是两个名字指同一件事（§12.12 / §12.14）。状态栏改成遍历同一份描述符，**文案一字未改**，渲染次序不变（物理显存 → ComfyUI 显存 → 内存）。两条显存口径继续分开命名（nvidia-smi 物理专用显存 vs ComfyUI 上报的 CUDA 逻辑口径），不合并。

## Tests

- 新模块 8 条（次序、两档显存各自有名且 title 点名来源、缺值隐藏、`0%` 是真读数不许当没数据、两条文案不许复用同一条）；卡片 10 条（三根条的 `aria-valuenow`、可访问名带百分比、设备名有则渲染无则不占行、在线/离线徽标、三种读不到数的情形、只有一档读数时只画那一档、「去设置」指向 `/settings`）。
- 负向验证：把共享描述符里的「显存」改成别的字 → 卡片、状态栏、描述符三个用例文件同时红，复原复绿。这一条就是「口径只命名一次」的判据本身。
- 状态栏既有用例（8 条）未改断言仍全绿，说明这次重构对它是透明的。
