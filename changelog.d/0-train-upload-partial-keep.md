## Fixed

- **训练工作室批量上传时，中途失败会把已经传成功的几张一起丢掉**（`src/components/studio/hooks/use-training-studio.ts`）。图已经在服务端了，丢掉等于让用户白传一遍、还在服务端留下孤儿文件。
  成因：为省重渲染（P2）把「逐张 `setDataset`」改成「串行传完一次性并入」时，并入那一步写在了循环**之后且不在收尾位置** —— 任一张失败就整个批次不落地。省渲染次数与失败语义本来是两件不相干的事。
  修法：把一次性并入放进 `try { … } finally { … }` —— 失败即停不变、错误照旧上报，但已成功的几张照样保留；仍然只在收尾时 `setState` 一次，P2 的收益没丢。
  这条是 `use-training-studio.test.ts`「上传失败即停：错误可见，已成功的那张保留」一直在报的红 —— **断言是对的，改的代码**。
