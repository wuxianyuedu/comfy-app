## Changed

- **「模式契约」的模式清单从平铺的 chip 带收成左侧的树形页签（ISSUE #1870）**。用户反馈「模式契约设计成树形页签，现在散放一堆占空间」。
  - 改版前所有生成模式（22 条）按输出类别**平铺成三排 chip**：纵向吃掉三四行、窗口一窄还反复折行，正文被它整块推下去。现在收成**左右两栏** —— 左栏是分类树（父行 = 输出类别「图像 / 视频 / 音频」，子行 = 模式），右栏是当前模式的编辑区；两栏各自滚动，模式不再和正文抢纵向空间。形态与设置页分区导航同一套（ISSUE #1694 的结论）。
  - 层级由**缩进 + 引导线**表达，走 `~/components/ui/tree-rows` 的 `TreeChildren`（唯一实现，P36 硬闸），不手写 `ml-* / border-l-*`。
  - 单选语义保留：整棵树是 `role="radiogroup"`，每一行是 `role="radio"` + `aria-checked`，点一枚即把该模式码上抛（与「模型适配」的模型清单同一条契约）。
  - 外壳从文档型（`DocumentFrame`：整屏一条滚动条 + 居中窄栏）换成工作区型（`WorkspaceFrame`：吃满父级、不产生页面级滚动）—— 两栏要各自独立滚动，就需要容器不吃页面级滚动、把高度交给内部两栏。底色仍跟文档型那一档（`bg-canvas text-ink`），换外壳是布局决定、不改这一屏的颜色。
