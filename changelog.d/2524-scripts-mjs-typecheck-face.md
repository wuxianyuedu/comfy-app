## Added

- **脚本档（未被 import 的 `**/*.mjs`）从此在 tsc 的判决面上（ISSUE #2524 / 规范 §13.5.14.1）**：
  新增 `tsconfig.scripts.json`（`include` = 全量 `**/*.mjs`，`compilerOptions` 一律 `extends`
  主配置 —— 脚本档与应用档必须是同一把尺）+ 执行者 `scripts/check-scripts-typecheck.cjs`
  （入口 `pnpm check:scripts-types`），三态退码 0 / 1 / 2 = 过 / 阻断 / 没结论。

  先答**范围**那一句：**脚本档的判决面 = 配置展开的 `**/*.mjs` 全量，不是「被 import 可达
  的那一部分」**；可达性只是主 `tsconfig.json` 那一档的顺带结果，从来不是谁作出的决定。
  当场读数（本机 `--listFiles` 与磁盘枚举对账）：磁盘上非点目录的 `.mjs` 共 **210** 份，
  主 program 里在场的 **169** 份 ⇒ **41 份从来不在面上**（`scripts/**` 40 + `e2e/**` 1）；
  把这一格收进来之后量出 **320 处存量红 / 31 份文件**（登记时的读数），最大一类 168 处
  `TS7006` 隐式 any 参数；**合并并行那批 #2585（scripts 的 84 条死代码逐条清零）之后重测
  310 处 / 29 份**，而 `TS6133`（声明了没用到）**账上归零** —— 本单点名的那一类死代码，
  落地当天就没有存量，这一档从一开始就不给它留额度。主配置的 `include` 里有 `**/*.cjs` 与 `**/*.js` 而**没有 `**/*.mjs`** ——
  这就是「`ci-daily-build.mjs` 那两处死声明躺在主干上、`tsc` 一个字不报」的唯一根因：
  入口脚本是被 `package.json` / 钩子 / 平台直接 `node` 起来的，没有任何人会 import 它。

  判三件事，每件都对应一种「看着在守其实没守」：
  ① **判决面自证** —— 盘上独立枚举 ⊆ 配置展开 ⊆ tsc 报回的 `--listFiles`，且展开非空
  （空面 / 漏件 ⇒ 红，「0 处 ⇒ 绿」这条路被关掉）；② **存量按 `(文件, TS 码)` 只降不升**
  （不是按总量比较 —— 总量降了也能夹带一份新文件的红；新脚本零容忍，基线里没有的格子就是新增）；
  ③ **被截断的一跑不算绿** —— 把这条判据自己 dogfood 出来的一条 tsc 事实钉住：一份 `.mjs`
  里写了类型注解（`TS8010`）之后**整跑只打那一行**、其余一格都不报（基线有多少格就少读多少格，
  语义检查根本没发生），
  所以那一跑必须红，且 `--update` 拒绝照它重写基线（照它写等于把棘轮清空）。

  存量为什么**登记而不是当场清零**：这 310 处里约一半是 `TS2339` / `TS18048` / `TS2532` 那一族，
  要在启动链与构建链的脚本里加守卫；把「面收口」与「改动面最大的一次脚本重写」押进同一张单，
  改动跑挂了会被读成「扩面这件事不该做」。清账另开 **#2589**（按文件的读数由
  `pnpm check:scripts-types -- --report` 现算，不抄进文档）。

  扩面立刻读到**两例真故障**，各开一张：**#2588** —— `scripts/quality-gate.mjs` 有四条
  `fail(...)` 调用而那个名字在本文件既没定义也没 import（`TS2304`），那四条失败路径运行期抛的是
  `ReferenceError`，不是它想打的那句中文；**#2609** —— 合并 #2585 那批时读出来的：`value()`
  的形参被删、两处调用点没改（`TS2554` ×2，而 JS 里多传实参**没有运行期症状**）。
  两例合起来才是本条存在的理由：面不收口，这类东西不是「偶尔漏掉」，是**永远**读不到。

  执行者两处同名：`.githooks/pre-commit` 的 D 组那一步 `脚本档类型检查(tsc 的 .mjs 全量面)`
  与平台「重档静态判据」的 `HEAVY_GATES` 条目（名称与 argv 逐字一致，`heavyGateRegistryProblems()`
  开跑前先自证）。与 A 组那条 `tsc --noEmit` **同档**（重档，不进默认那次提交）：本档自己起一次
  tsc，本机同一份基线连跑四次 **12.5 / 15.3 / 17.6 / 17.9 秒**（跨度来自冷 / 暖盘，跨天别引用
  绝对数）；`--no-run` 只做面对账、不起 tsc（实测 1.4s），它明说那一跑**不构成**「类型层过了」。
  同批：§13.1 清单补一格、`§13.5.14` 那句「扫描面含 `.mjs`」订正为「只对**被 import 到的** `.mjs`
  成立」、`tsconfig.scripts.json` 进 `affected-tests.mjs` 的放弃收窄触发面、自测
  `tests/scripts-typecheck-ratchet.test.ts`（9 条，全在临时夹具里跑真 tsc，一次也不写回仓库基线）
  进固定结构守护清单。`scripts/.gate-thresholds.json` 里给 `RULE_VERSION` 入账一条 `report`。
