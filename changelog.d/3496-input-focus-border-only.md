## Fixed

- **输入框聚焦从「边框 + 外发光双线」收敛为「只换边框的单线」（ISSUE #3496）**：聚焦时紫色同时来自边框变色和外圈 ring 发光，二者同为强调色、位置又贴在一起，视觉上像两条线、显脏。根因是全站文本输入框在 focus 态同时挂了 `border-*`（边框变色）和 `focus-visible:ring-*`（外发光），两道紫色叠在一起。现已统一按 `docs/DESIGN.md`「输入」行的签字口径——focus 只换 `border`、不出 `ring`：`ui/input.tsx` 与 `ui/textarea.tsx` 两个基础组件移除 `focus-visible:ring-ring/50` 与 `focus-visible:ring-3`；所有自带 className 覆写焦点样式的文本输入（设置页 `LlmLocalSection` / `RemoteModelDialog` / `SettingsPrimitives`、工坊 `AgentOverlay` / `FinalComposer` / `ShotStudio` / `StoryboardPlanner.parts` / `VideoStudio.parts`、工作室 `LogFilterBar` / `ContentAssetNode` / `WorkflowLibraryList` 共 13 处）同步移除 `focus-visible:ring-primary/30`；节点画布上的 `editable-label`（重命名标签的 `<input>`）此前自带 `focus-visible:ring-ring/50 focus-visible:ring-3`，也与基础组件对齐、只留 `focus-visible:border-ring`。`aria-invalid` 的错误红环保留不动（它是错误信号，不是聚焦装饰）。按钮、下拉、开关、徽章等控件不在「输入框」范围内，其 focus ring 原样保留。
