## Removed

- **生成态文档镜像 `docs/generated/**` 退出入库产物，同批三格判据与配对门禁一并退役（ISSUE #3586）**：诉求原话是「能不能只维护文档源，`docs/generated/` 自己需要生成自己生成自己看」—— 此前改一份文档源，自动合并后仍要 `pnpm run doc:render -- --check` 确认 39 份镜像一致，是最容易漏的一环。落地形状与 #2231 对 `docs/api/` 的处置同族：`.gitignore` 加 `/docs/generated/`、删掉 39 份入库镜像；**没有入库的产物，既没有内容可比、也没有「同批带上」这个动作**。
  - 退役：本地 D0 的「文档源 ⇄ 生成态镜像同批」（`scripts/check-doc-mirror-pairing.cjs` 与自测）、GA `.github/workflows/master-gate.yml` 的 `render-doc-placeholders.cjs --check --autofix` step、`scripts/ci-autofix-duties.mjs` 与 `scripts/ci-incremental-gates.mjs` 两条登记。两张登记表**为空是合法终态**（刻意不造占位条目）：`checkAutofixDuties` / `checkIncrementalGates` 的反向半此刻等价于「谁把自动修 / 收窄加回来谁当场红」，由两份自测的正负控守住。
  - 保留：`pnpm doc:check`（编辑态引用与权威源一致，GA 每笔 master push 跑）与 `pnpm doc:render` 本地生成入口（含 `--only` / `--check` / `--autofix`，供本地与 `tests/check-doc-references.test.ts` 回归用例）。`render-doc-placeholders.cjs` 不再被任何提交门禁调用。
  - 登记面同批：钩子 D 组步骤计数 61 → 60、D0 成员名单、`scripts/gates-which.mjs` 的收窄面反查改为可注入（机制用例拿假登记表做正负控，不绑真表是否为空）、`scripts/qoder-ignore.mjs` 把镜像从「入库只出索引」挪到「生成物与工具缓存」并刷新 `.qoderignore`；`AGENTS.md` 硬规则 7、`docs/README.md`、`docs/reference-facts.md`、13 章 §13.5.5 退役块与 §13.1 清单、`README.md`、`docs/product/README.md`、两份功能流程图、tools 文档与脚本头注逐处订正。
  - 口径收尾（同批）：`scripts/base-check/declared-hook-steps.mjs` 的 D0 名单摘掉退役步骤（钩子 ⇄ 注册表双向对账随之恢复一致）、GA `master-gate.yml` 与钩子里的过期 `--autofix` / 配对注释、13 章平台对照表与逐笔对账边界、11 章生成物叙述、`check-tracked-secrets.cjs`、两份 `generate-docs.ps1` 头注；另订正 7 处「退出发下产物」笔误为「退出入库产物」。`tests/check-doc-references.test.ts` 两条「读生成态真实值」的用例改为**在一次性夹具里本地跑一次 `doc:render` 再读**（与 #3586 的读者动作同一条路径），不再依赖干净检出上根本不存在的入库镜像。
  - 验证时拦下的一处存量红（与镜像无关，不修则本单固定清单不绿）：`tests/git-path-quoting.test.ts` 对 #3602 引入的 `scripts/ship-local.mjs` 那处 `git status --porcelain -- <路径>` 报「缺守卫」。按判据自己规定的方式在 `EXEMPT` 登记 1 处、写明理由（该处只看输出空不空，从不解析路径，理由原本就写在源码注释里），**不给生产代码硬加旗标换绿**；`ship-local.mjs` 里提到已退役配对判据的那句历史因果也补了时点说明。
  - 验证：`pnpm gates:which --changed <79 路径>` → 模式 all、141 份用例（固定清单 106 + 受影响 35）；首轮 `vitest run --no-file-parallelism` 2952 条里 5 红（新 helper 的 oxlint 清零规则命中、上面那处存量豁免、一处 30s 超时），逐条归因修完后复跑 4 份文件 131/131 全绿；`pnpm doc:check`、`pnpm qoder:ignore:check`、`node scripts/check-changelog-fragments.cjs` 均绿。
  - 验证（第二轮 · pre-push 复算）：`check:premerge` 另拦下 `tsc --noEmit` / `eslint` 三处 —— `tests/ci-heavy-gates.test.ts` 里半成品留下的未用 `INCREMENTAL_GATES` import，以及新 helper 重抛异常没带 `cause`。两处修完后 `tsc` 退 0、oxlint 0 warning / 0 error，两份对应用例 92/92 全绿；这两格不是「干净快照上的存量红」，归因落在本单改动面。
  - 验证（第三轮 · 平台 `affected-tests`）：PR #3609 首跑红在 `tests/doc-toc.test.ts` 的 `--rendered` —— 本机那 39 份产物把「干净检出上根本没有 `docs/generated/**`」掩盖了（本机退 0、CI 退 2）。修法给 `scripts/doc-toc.mjs` 加与 `DOC_RENDER_ROOT` 同族的 `DOC_TOC_ROOT` 夹具注入缝，用例改为自己造一份本机镜像再读，并补一条「没生成过 ⇒ 退 2 且提示先 `pnpm doc:render`」的反向判据；把本机产物临时移出仓库模拟干净检出后复跑 9 份关键用例 323 passed / 5 skipped、`pnpm doc:check` 绿。
