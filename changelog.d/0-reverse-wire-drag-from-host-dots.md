## Added

- **工作流库「画布节点」支持反向拖线：从工作流节点的行圆点起手，落到对外参数卡片上**（原来只能「卡片圆点 → 工作流行」）。两列都支持，按行自己声明的方向分流：从**输入行**圆点拖到左侧对外参数卡片 = 让这张口落到该行；从**输出行**圆点拖到右侧对外输出参数卡片 = 让这张输出口从该行取值。落点集合与「拖到行上」互为镜像（输入行 ↛ 输出卡片、输出行 ↛ 输入卡片），只读预览（对应方向没给回调）时行圆点不起手。上抛仍走原来那对回调 `onConnect(entryId, 行 ioKey)` / `onConnectOutput(entryId, 行 ioKey)`，父组件无需改动。
