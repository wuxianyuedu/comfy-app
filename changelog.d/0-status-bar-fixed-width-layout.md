## Changed

- **底部状态栏改为固定宽度分区**：此前地址栏、显存/内存、消息中心/日志/应用服务状态挤在一条 `justify-between` 里，各段宽度随内容浮动，任务名一长就把右侧指标推得忽左忽右。现拆成四段：最左地址栏固定 170px、中间 ComfyUI 排队信息弹性左对齐、资源指标（显存/内存）固定 500px、最右（FPS + 消息中心 + 日志 + 应用服务状态）固定 280px 且不换行。各段位置稳定，不再互相挤动。
- **排队信息改为点击弹出详情**：ComfyUI 排队/当前执行那一格默认只显示截断后的简短文本，点击弹出浮层展示完整信息（工作流名、模型、已运行时长、进度、当前节点、运行/排队数）。此前长任务名会和右侧资源指标重叠。
