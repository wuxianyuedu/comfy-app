## Fixed

- **图片查看器点「适应窗口」后不停抖动、滚动条反复出现又消失，拖拽明显卡顿**：
  「适应窗口」的倍数此前用可视区的 `clientWidth` / `clientHeight` 算，而这两个读数
  **不含滚动条**、会随「内容有没有溢出」而变 —— 于是「按适应尺寸渲染 → 差一点点
  溢出 → 出现滚动条 → 可视区变小 → 重算更小的适应尺寸 → 滚动条消失 → 可视区变
  大 → ……」构成逐帧互推的闭环：插值出的就是那条不停抖动的边，而逐帧重排正是拖拽
  发卡的来源。

  现在改取**矩形**（`box.width` / `box.height`，布局尺寸、滚动条出现与否都不改
  它），适应尺寸因此是矩形的纯函数，收敛到「无滚动条」这个不动点。图片解码中
  （自然尺寸未知）时的既有兜底与各档倍数夹取口径不变。

  回归护栏：`src/components/ui/image-viewer.test.tsx` 新增一条 —— 把矩形钉成
  800×600、`clientWidth` / `clientHeight` 钉成 785×585（模拟滚动条占位），断言
  适应后的像素尺寸按矩形算（757×568），而不是按 client 的 737×553。
