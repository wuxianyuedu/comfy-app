## Added

- **测试模型页支持本地模型，本地 / 远端分两类显示**（ISSUE #4080）。
  此前候选只解析 extraModels 里的远端对象条目，本地 Ollama 候选（字符串条目）
  被直接跳过 —— 页面上选不了本地模型。
  - 模型下拉按**本地模型 / 远端模型**两类分组显示（SelectMenu 新增可选
    `groups` 分组渲染，既有调用点零改动）；
  - 新增「对话」测试用途：向被测模型发一条提示词、展示回复与耗时 —— 本地
    Ollama 模型走设置里配置的本地服务（生效 LLM 配置 + 被测模型名），远端
    chat 模型按名解析连接参数（`llm.chatTest`）；
  - 本地候选只出现在对话用途（Ollama 不做生图 / 生视频）；图片 / 视频的
    候选与测试流程不变。
