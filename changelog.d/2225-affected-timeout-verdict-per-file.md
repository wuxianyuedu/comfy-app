## Fixed

- **「受影响用例」那一格的超时指纹改按文件判 —— 同块里的真断言红不再被一起降级成「未校验」
  并退 0**（ISSUE #2225，`scripts/run-affected-tests.mjs` 的 `runChunk`）。
  症状是**假绿**，不是红：第 2 遍（`--no-file-parallelism` 的隔离复跑）仍红时，旧代码问的是
  `isTimeoutShaped(retry.output)` —— 那一句读的是**整块输出**。于是「A 文件超时 + B 文件真断言红」
  被整块读成「只是超时形态」⇒ 退 0 ⇒ `scripts/ci-affected-tests.mjs` 把这个 0 原样透传成
  平台 stage 的 **success**，B 那次真红没有任何一格会看见。它自己的话术写着「这不是绿」，
  屏幕下方也确实逐条点名了 —— 但**平台只读退出码**。
- **根因是粒度不一致，不是判断错**：复跑面早就按文件收窄了（`retryScope` 只重跑第 1 遍里失败
  的那几份），判决却还停在块级 —— 判定粒度比取数粒度粗，粗的那一份就把细的那一份吞了。
- **三档结论，各有一个码**（新增的是第三档）：
  · `1` 真红 —— 任一份文件的失败文本**不带**调度指纹（断言红 / 真挂死），逐份点名；
  · `0` 未校验 —— **每份**都带指纹（这是「已确认失败的是调度，不是断言」，不再是从整块文本猜的）
    ⇒ 沿用 ISSUE #1747 那条「拿不到测量 ≠ 测量结果是红的」，放行 + 逐条点名；
  · `2` 未判定 —— 有文件在第 2 遍的读数里**认不出自己**（junit 缺 / 形状不认识）。
    这一档是这次新增的正身：**「我分不出哪份是超时」不等于「整块都只是超时」**，
    所以它**不许**再并进 `0`。先做**有界逐文件补跑**（一份一次，那份退出码就是它的结论）把粒度拿回来；
    补跑里自己通过的那些不进「未校验」名单（点名一份已经绿的文件就是谎报覆盖面）；
    超过上限仍拿不到就退 2 并把名单点出来。
- **这一档的落点在平台，不在钩子**：`run_group C` 里那句 `return 0` 在档位开关**之前**
  （2026-10-20 起本地不跑受影响用例，`COMFY_HEAVY_GATES=1` 也换不回来 —— §13.5.25），
  所以钩子这一侧**没有**这一档的分支，也不在那里写一段永远跑不到的处理。平台那一格
  `scripts/ci-affected-tests.mjs` 原值透传 ⇒ stage 非零 ⇒ **不再被算进「绿」**；而它也不是红，
  话术点名的是「哪几份拿不到自己的读数」。本地手工那一跳（`node scripts/run-affected-tests.mjs`
  或 `pnpm check:all`）读到 2 时同样按「未判定」念。这与 `base-check` 的 `inconclusive`、
  出勤判据的退 2、`ci-build-readout` 的「没有结论」是同一个三态口径 ——
  **只认 0/1 两档的系统读不出它**，而那正是这次假绿的形状。
- **新落点**：判决粒度住在 `scripts/affected-launch-retry-verdict.mjs`
  （`classifyRetry` / `mergePerFileReads` 两份纯函数，假 spawn 就能整条跑）；
  逐 suite 的失败文本由 `scripts/precommit-timing.mjs` 新增的 `failingSuiteTextsFromJunit` 提供
  （与既有 `failingSuitesFromJunit` 同源于同一份 XML 布局，只多带一份 `body`）。
  新增的补跑上限 `PER_FILE_RERUN_MAX` 与既有的 `SCOPE_ADVICE_MIN` 一起进了
  `scripts/.gate-thresholds.json`（`report` 档）—— 顺手把这本账对该文件的覆盖面补上。
- **用例 58 → 65 条**（`tests/hook-affected-launch.test.ts`）：负控制那份最关键 ——
  一份超时 + 一份断言红 ⇒ **退 1** 并点名那一份（旧实现这里退 0）；其余是每份都超时 ⇒ 退 0 且
  名单只含超时那两份、认不出自己 ⇒ 逐文件补跑后按各自结论定、补跑绿的那份不进名单、
  超过上限 ⇒ 退 2、纯函数三档互不合并、junit 形状假设钉住。
  原「复跑最多一次」那条断言随之**收窄成更准的一句**：整块只许跑两遍（并行一遍 + 串行复跑一遍），
  第三遍起的是「一份一次」的补跑 —— 它不是把整块再测一遍，而是把块级红拆回文件级的那一步。
- **文档同批**：规范 §13.6.4.1 那张判决表加一档并写清粒度口径；`AGENTS.md` 快速排障那段
  跟着改。另修两处早已失效的旧话术：那里还写着复跑「同一份清单」，而复跑面早在收窄之后
  就是「第 1 遍里失败的那几份」。
