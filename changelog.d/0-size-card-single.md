## Changed

- 尺寸在卡片列里**只有一张卡**了：六行形态（宽 / 高 / 宽高比 / 像素量 / 分辨率档 /
  倍数）挤在一张卡内、每行一颗圆点，不再并排六张卡（用户口径：「尺寸这里不要显示
  这么多节点，尺寸只显示一个节点」）。
- 行上的圆点 handle 就是**子口 id**（`size-width`…），连线层按它反查条目 —— 卡片与
  边同一份算式；卡片头的 ↺ 一键撤掉这六个子口的线（新增 `sizeGroupIds`：卡片 id
  `size` ↔ 六个映射键）。
- 映射表、运行期取名与落库形状完全不变：六个子口仍是六个键，形态仍由作者连哪一行
  声明（没有退回「按端口名猜形态」）。
