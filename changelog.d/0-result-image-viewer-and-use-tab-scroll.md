## Added

- **通用图片查看器（`~/components/ui/image-viewer`）**：此前全库的图只能「渲染出来」，没有「查看」这一档 —— 缩略图盒子只有几百像素宽，想看画出来的细节时既不能按原始像素看，也不能缩放到某个局部。新增两个出口：`ViewableImage`（缩略图 + 点开，调用处一行替换掉原来的 `MediaThumbnail`）与 `ImageViewer`（受控弹窗）。交互给全了「适应窗口」与「原始大小（1:1）」两个档位、按 1.25 倍的放大 / 缩小、**以光标为锚点**的滚轮缩放、按住拖拽平移、双击在两档之间切换；Esc / 点遮罩 / 关闭按钮走 `ui/dialog`（焦点锁与归还、遮罩让位标题行都在基元里）。倍数与百分比由 `~/components/ui/use-image-zoom` 算：适应窗口**不放大超过 100%**，量不到尺寸时按 100% 而不是 0，倍数一律夹到 `[0.1, 8]`。失败兜底复用 `MediaThumbnail`，键盘可达（缩略图是按钮）。

## Fixed

- **工作流库「画布节点」预览的「实际使用」页签可以上下滚动，产出内容不再被裁**：该页签的产出（参数表单 + 进度条 + 运行结果图 + 提示）比可视区高是常态，而它所在的父级是 `overflow-y-hidden`（edit 模式的 React Flow 画布靠它兜住撑高），于是超出部分既看不到也滚不到。纵向滚动改由本层自己出（`overflow-y-auto` + `custom-scrollbar`），并给运行结果图接上上面那个查看器 —— 380px 的缩略图看不全时点开即可按原始大小或缩放细看。
