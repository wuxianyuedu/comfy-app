## Changed

- **设置页去掉「返回」按钮、导航从竖栏改成分段 chip 行，正文层级与按钮主次一并收拾（ISSUE #1423 的后续）**。用户反馈「设置页的界面不好看」并点名「后退按钮去掉」。
  - **删掉的是一条不该存在的退出路径**：设置在本应用里是**一页页签**（页签自带关闭按钮、侧栏也永远在），而左上的「← 返回」走 `router.back()` —— 同一个动作在两个入口下含义不同（页签里是「第二条退出路径」、独立路由 `/settings` 下是「回到上一页」），且它唯一确定的作用是把标题推离左边缘。`SettingsShell` 的 `onClose` prop 随之删掉（两个挂载点此前都不传它，那条分支永远进不去 —— 按 §12.16 删除）。
  - **192px 的竖栏换成一条单行 chip 带**：竖栏是「很多层级的设置」长出来的形状（分组的父项常年只有一个子项），分组层级没换来导航价值却吃掉四分之一屏宽，内容列常年在 `--container-medium` 里被挤窄。现在导航收在标题下一行、按「模型 / 后端 / 数据 / 应用」分段，**溢出横向滚、不换行不压扁 chip**（§3.8.1）；项本身仍只来自 `SETTINGS_SECTIONS`（视图不重抄分区表）。
  - **「本分区是什么」从卡片正文搬进导航**：各分区此前在正文开头写一段解释性段落，而它回答的是**导航问题**（「我现在在哪、这一节管什么」），读一遍就不再需要 —— 却常年占着正文最靠上的位置，把第一个控件推到折叠线以下。收成标题右侧那一行（`settings-section-summary.ts`，纯常量 + 纯派生），卡片正文只留「答案在别处拿不到的那句」。
  - **卡片标题不再靠「字更大」表达层级**：标题从 `text-base`(16px) 落到 `.u-title` 档（14px semibold），层级改由字重 + 标题下的分隔线承担 —— 16px vs 14px 的差距在同一屏里读不出来，而它此前是设置页唯一的层级手段。段内说明段落统一 `text-xs`（`text-sm` 是表单标签与控件值那一档，正文用它会让两档字分不开）。
  - **状态行不再「三颗都是主按钮」**：`StatusButton` 的缺省档从 `primary-solid` 改成软底 `primary` —— ComfyUI / Drizzle Studio 各有三个动作，缺省实心时三颗同款品牌紫实心、用户看不出该点哪个，且**置灰的实心只是 50% 不透明度（仍是饱和紫），读起来像「可点但浅一点」而不是「现在不能点」**。现在「当前这一态该按的那一颗」才是实心（未运行时的「启动」/ 运行时的「关闭」），「看」走软底、并列出口走 `outline`，卡片级主行动（保存 / 立即备份 / 检测更新）由调用处显式传 `primary-solid`。**缺省值必须是「不需要强调的那一档」**。
  - **远程模型的三个空分组不再各画一圈边框**：空分组此前是一个带边框 + 16px 内距的盒子，只为装一行「还没有…」，一屏三个几乎全空的盒子在视觉上比「这里面有什么」更响。改成「一行轻量区头（标题 + 计数 + 右端动作）+ 一组行」，边框留给真正的条目；「＋ 添加模型」从实心 `lg` 降到 `outline xs`。
  - **修掉一处渲染成字面的 Markdown**：备份分区正文里的 `**单文件**` / `**最近 3 份**` / `**分两步**` 等处从来不是加粗，而是把星号原样显示给了用户 —— 改成 `<strong>`（与文件里其它几处早已这么写的地方对齐）。
