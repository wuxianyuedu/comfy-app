## Added

- **设置 → 远程模型改为「供应商 + 模型」两级配置**（#3501）。每个供应商各带一套
  Base URL / 接口格式 / API Key，模型挂在供应商下，不再共用全局 API Key：
  - 接口格式三选一：Chat Completions（`/chat/completions`）、Anthropic Messages
    （`/v1/messages`）、Responses（`/responses`）；设置页直接显示拼出来的最终请求地址；
  - 模型列表支持新增 / 编辑 / 删除 / 启停 / 测试生成；模型配置含「智能配置」
    （按模型 id 预填上下文窗口与输出上限）、上下文窗口、最大输出 Token，
    以及输入类型（文本 / 图片 / 视频 / PDF）、模型能力（结构化输出 / 原生联网搜索 /
    系统消息）、推理等级与推理参数映射；
  - 供应商密钥三态：留空不改、显式清除、写入新值；浏览器只拿得到「有没有配」，
    明文不进下发面；连通性测试由服务端取保存的地址与密钥发起；
  - 历史遗留的远端模型在首次打开时自动迁入「默认供应商」，原有密钥与模型名不变。
