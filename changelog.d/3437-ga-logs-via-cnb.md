## Changed

- **GA 判红日志正文改从 CNB 侧获取**（ISSUE #3437，#3378 后续指令）：`pnpm ship --gh-logs <PR号>` 与判红自动回读（`runGhLogsOnRed`）此前只能从 `api.github.com` 出站拉失败 job 的日志，本地 / 自托管机出网不稳时判红想看「哪一步、哪一行」就卡住。结论早在 §13.5.33.1 改成「GA 入站送回 + CNB 站内读」，日志正文这一半没跟上。
- GA 侧（`pr-gate.yml` 收尾 `ga-verdict-callback` job 末尾）：新增 `ci-ga-logs-relay.mjs`，用内置 `github.token`（顶层补 `permissions.actions: read`）读本 run 的失败 job 日志 → `redactSecrets` 脱敏（硬规则 17）→ gzip + base64 编成纯文本 → `POST /-/upload/files` 拿链接 → PUT 正文 → `POST /-/pulls/{n}/comments` 发一条带 `GA_LOG_RELAY_V1` marker 的 PR 评论（附 run / sha / pr / jobs / bytes 身份读数 + 附件链）。写 CNB 用已配好的 `CNB_ISSUE_TOKEN`（`repo-notes:rw`，code-scanning-triage.yml 同一枚），**不新增 secret**。
- 本地侧新增 `ship-ga-logs-cnb.mjs`：`cnb pulls list-comments`（列表旧→新、不支持 `--sort` ⇒ 倒着扫第一条 marker）→ `cnb assets get-files` 读 base64 → decode + gunzip。`ship-gh-logs.mjs` 把这条 CNB 站内读放在 GitHub 令牌闸**之前**（注入 `cnbIo={run,slug}`）：CNB 命中时**不需要任何 GitHub 凭据、零 `api.github.com` 请求**，复用既有 `extractFailureWindow` / `shipFailureWindow` / `renderFailureWindow` 呈现，run / job / 注解 / 窗口 / 一行结论 / 全量落盘口径与旧链路同形；CNB 缺席（旧 PR 没跑过 relay / 评论被清 / 平台读不到）如实念一行，退回原 GitHub 出站链路（快速回退完整留盘）。`ship-standalone.mjs` / `ship.mjs` 两处调用点同步注入 `cnbIo`。
- 载体选**附件 + PR 评论**而非二进制附件 / build stage：探针逐格坐实「上传返回 `asset_link` 即成功；未发布 `GET /-/files/<path>` 恒 404，链进评论发布后逐字读回」，且 PR 与 Issue 是两套独立编号，用 `pulls` 那组端点；base64 纯文本绕开 `cnb -v` 的 JSON 信封把二进制转坏的问题（端到端探针验过 decode/gunzip 还原）。
- **不碰承重**：`.cnb.yml` 的 `质量门禁` / `GA 回调结论回读` / `COMFYAPP_CI_GATES` / 停用清单 / `GATE_TIER_LEDGER` / 流水线 `name`（commit-status context 含它）/ `GA_VERDICT` 折叠一字未改；relay step `if: always()` + step 级 `continue-on-error`，日志搬不到绝不改本 run 的 conclusion；「取不到 ≠ 判红」三态语义不变。
- 逐笔对账同批：`pr-gate.yml` / 两份新脚本 / 三份 ga-logs 用例（GA 搬运 10 条、本地读回 9 条、`--gh-logs` CNB 优先 4 条）/ `tests/no-platform-ci-config.test.ts`（钉住接线在场 + 不改名 + step 不承重）/ `ship.mjs` 头注 / §13.5.33.4 续节 + 生成态镜像 / `ga-migration-checklist.md` + 镜像。
- **边界**（写进配置注释，没假装已验）：`actions: read` 能不能读到同 run 的 job logs、`CNB_ISSUE_TOKEN` 在 PR 事件上带不带 `repo-notes:rw`，看首跑那条 relay step 的 stage 读数（`[ga-logs-relay] 已搬到 CNB` / 「前提不成立」）。没坐实前不改承重；坐实不了也只是退回旧链路，不拦合。
