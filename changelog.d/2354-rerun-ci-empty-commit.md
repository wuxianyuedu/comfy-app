## Fixed

- **`pnpm ship --rerun-ci` 从「写了但走不通」变成走得通的那一条**（ISSUE #2354）。
  它的机制就是在 PR 分支上推一笔**空提交**重新派生一条流水线 —— 平台侧没有 PR 重跑入口
  （`cnb build` 那 11 个工具只有 `start-build` / `stop-build`，`--event` 只认 `api_trigger` 前缀，
  打不开 PR 那一跑）。但 D0 里有两步读**当场暂存区**，空索引被它们写成「取不到判决面 ⇒ 退 2」，
  钩子把退 2 当失败 ⇒ 那笔空提交**根本做不出来**。当场读数（本单复现，探针分支 + `--allow-empty`）：
  ```
  [pre-commit] ✗ 组 D0（形态前置档）失败（退出码 2）—— 其余四组未跑
  [doc-mirror-pairing] 这一条**没判**：暂存区是空的 —— 没有判决面（本地这一跳的暂存集永远非空；
      空的那一档只出现在平台上，而平台上没有暂存区） —— 没有判决面不等于「已通过」，按「没跑起来」收（退 2）。
  [ship] 空提交失败（exit 1）。
  ```
  根因里还有一句写错的话：那两步的注释都写着「`git commit` 不许空提交 ⇒ 本地这一跳的暂存集永远非空」——
  `--allow-empty` 存在，而 `ship` 正是用它。今天这条把它兑现成一次能走的动作。
- **不靠猜索引，只靠说出来的意图**：新增唯一口径 `scripts/intentional-empty-commit.mjs`
  （`COMFY_INTENTIONAL_EMPTY_COMMIT`，**唯一生产者**是 `ship --rerun-ci` 那一格）。三条形状：
  旗标 + 空索引 ⇒ 两条判据的问题没有对象，按 `0` 收，判据自己把理由说出口；而**钩子成功时只留一行**，
  所以那句由发起方转述：`ship` 的回执多打一行「这一跳带了这枚旗标、两步按『没有对象』收」；
  旗标 + 索引非空 ⇒ **当场念「旗标作废」**并照正常判决面判（所以它不是 `--no-verify` 的第二形态，
  也不给「改了源没带镜像」开口子）；旗标不在场 ⇒ 与改动之前**逐字同形**。
  两个消费者各接一处：`check-doc-mirror-pairing.cjs`（空索引那一支）与
  `known-failed-selftest-gate.mjs`（走既有的「没碰到机制 ⇒ 说一句话」那一档，退 `0`）。
- **`makeRunner` 现在能叠加环境变量**（第三个入参，`{env}`，**叠加而不是替换** ——
  换掉整个环境会把 PATH 一起带走，那类故障的表现为 ENOENT，看不出关系）。此前所有调用点
  不传，行为不变。
- 为什么现在它承重（不是「顺手修个不方便」）：ISSUE #2364 那一笔给 `受影响用例` 加了墙钟界，
  界用完那一档落**未判定退 2** ⇒ 平台那一格会红。红了的 PR 唯一的出口就是这一条；
  没有它，一次负载就会把这条 PR 卡住一整天，而当时能想到的绕行只有 `--no-verify`（禁）。
- 用例：`tests/ship.test.ts` +3（那一调**带没带上旗标**、`--dry-run` 一个字不执行但把旗标念出来、
  在 `master` 上不做这件事）、`tests/check-doc-mirror-pairing.test.ts` +2（意图成立 ⇒ 0、
  旗标与索引不一致 ⇒ 作废并照拦）、`tests/known-failed-stale.test.ts` +2（同一枚旗标在第二个
  消费者上的两个方向，含两个出口都要接住：警告走 stderr、结论走 stdout）。
  既有的「空索引 ⇒ 没判（退 2）」一条**一字未改**并保持绿 —— 它测的是不设旗标那一档。
- 变异自证：把那个判点改成恒「不成立」（`applies: false`）⇒ **两个消费者各一条当场红**
  （「空索引 + 说出来的意图 ⇒ 正面按 0 收」与「… ⇒ 走『没碰到机制』那一档」），
  按备份逐字节还原（sha1 `57615fa8…` 一致）后复绿 —— 证明「旗标 → 两个消费者」这条接线是承重的，
  不是各写一份话术。
- 现场复算：`COMFY_INTENTIONAL_EMPTY_COMMIT=1 git commit --allow-empty` 在探针分支上
  **入选档位全部通过**（跑了：D0；17 步），探针分支随后删除、没有推送；
  真判据三条形状逐一验过（无旗标空索引仍退 2）。
