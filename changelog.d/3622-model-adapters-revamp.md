## Changed

- **「模型适配」页按反馈改版**（#3622）：
  - **端点路径升成模型级配置**：端点与模式无关 —— 同一模型的几个模式用的是
    同一条端点路径，不再每个模式各配一份。选中模型后页面上只有一格
    「端点路径」（拼在该模型 Base URL 后），留空时请求侧按图片 / 视频
    （images/generations 与 videos 惯例、按 Base URL 形态补全）自动推导；
    存档升成「模型级 envelope」（端点 + 各模式字段映射），旧版裸数组存档
    兼容读取（其中 per-mode 的端点值被丢弃，走推导）。
  - **模型清单收成左侧分组树**：按 图像 / 视频 分组、可折叠，已配置过适配的
    模型标「已配」，模型多了不再糊成一片。
  - **同一时刻只显示一个模式的编辑卡**：模式 chip 即切换页签，点哪枚改哪张卡，
    多模式不再一条条堆在下面。
  - **删除模式加二次确认**：chip 上的 ✕ 先弹确认，防误删。
  - **输入映射新增「分辨率」统一输入**：接口原生认 1k/2k/4k 档位的可以直接
    映射（工坊选「分辨率」表达时档位名随请求下发，与百万像素换算值并存，
    适配器映射了哪个就下发哪个）；「测试模型」页同步给分辨率档位选择。
  - **「留空走通用提取」说清楚找什么**：产物字段路径留空时按
    url / image_url / video_url / download_url 等常见字段名自动搜索
    （b64_json 等载荷转 data URL；视频响应还认 id / task_id / video_id 等
    任务键），提示文案里写明。
  - **修**：保存后此前只写库不失效查询缓存，切到「测试模型」页签再切回来时
    刚配的模式会「消失」一轮（要再往返一次才出现）—— 现在保存成功即失效
    存档与概览两个查询，页签往返读到的一律是已存档内容。
