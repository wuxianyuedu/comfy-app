## Changed

- **尺寸统一成「比例 + 分辨率」/「比例 + 百万像素 + 倍数」两类可互算的表达**：以前「像素」大类下的两个档位（1k/2k/4k 与 1M/2M/4M）混在一行、且 1k/2k/4k 是按长边现算的，同一档位在图片与视频场景下算出不同的值也没人能改。现在 `src/lib/size-presets.ts` 是唯一事实：`1k/2k/4k` 按**场景**查表（图片 = AI 出图口径，视频 = 显示器 / 视频行业标准口径），`1M/2M/4M` 走总像素预算 + 对齐倍数。子类显示名从「像素」改为「分辨率」，与「百万像素」并列。工坊镜头尺寸、画布 / 库里的组合参数控件共用同一套口径。
- **「倍数」回到尺寸选择器（撤销 ISSUE #355 里「工坊不再显示对齐倍数」的那一条）**：选择「百万像素」档时，具体宽高由总像素预算 **和** 对齐倍数共同决定（8/16/32/64），藏起来用户既看不到宽高从哪来、也没法决定它；工坊封装因此重新支持 `size-multiple` 端口（`multiple` / `alignment` / 标签「倍数」），按当前选择派值。选「分辨率」档时不显示倍数 —— 那一档的宽高由尺寸表给定。
- **分辨率档下发到「比例 + 百万像素 + 倍数」的工作流时按实际像素换算**：用户选「16:9 + 2k」而目标工作流要 `aspect_ratio` + `megapixels` (+ `multiple`) 时，工坊与镜头生图不再传 "1k" 这种对远端无意义的档位名，而是换成该档宽高的实际总像素（图片场景 16:9 2k → 2.359M）与能同时整除两侧的最大候选倍数（→ 64）。远端 API 通道同样改成传换算后的百万像素。

## Added

- **尺寸表配置界面**：尺寸选择器弹层脚注新增「尺寸表（图片/视频场景）…」入口，打开后按场景页签展示「比例 × 1k/2k/4k → 宽高」表格，逐格可直接改（也可整场景恢复默认）。改动即时生效并记住（localStorage），同页面上已经挂载的多个尺寸控件通过订阅同步换值。
