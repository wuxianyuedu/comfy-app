## Fixed

- **设置页卡片内的「行」与卡片底色分不开（ISSUE #3510）**：设置页各分区卡片里的列表行 / 状态行 / 说明行，此前要么透明、要么写 `bg-surface-1`（= 卡片同色），于是子项与卡片逐像素同底（深色主题下都是 `#16161c`），一屏里读不出「一格一格」（ISSUE #3495 的第二条评论）。
  - 新增语义 token `--color-surface-row`（浅色 `#eceef4` / 深色 `#24242f`）：**离页面底再远一档**的方向，与卡片表面的对比度浅色 1.09:1 / 深色 1.17:1 —— 此前唯一高于卡片的 `--color-surface-2` 只差 1.07:1（深色 1.04:1），肉眼读不出来。
  - 「卡片内的一行」收成一处出口 `SETTINGS_ROW_CLASS`（`~/components/ui/settings-card`）：日志分类开关、远程模型清单、备份清单、按任务类型配置温度、各条状态行（ComfyUI / Drizzle Studio / Ollama / 应用更新）、说明框、主题卡与同款状态行（侧栏「ComfyUI」页）统一走它；温度分组的折叠面板外壳改为与卡片同底（它是分组框，不是行）。
  - 新增判据 `tests/settings-surface-contrast.test.ts`：从**编译产物**真量「行表面 vs 卡片表面」的对比度（两态下限 1.08 / 1.15）与「行上弱文字仍过 WCAG AA（4.5:1）」，并钉住「设置页分区里不再出现第二处 `bg-surface-1`」。
  - 不改全局表面阶梯（`--color-surface-1/2` 的取值与全仓调用点不动）—— 本次只补「卡片内的那一层」，改动面不扩散到全应用。
