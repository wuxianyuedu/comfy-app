## Changed

- **项目导航重构（ISSUE #4765）**：
  - **新建项目先命名**：点「新建项目」先弹命名对话框，名称必填、确认后再创建
    （重名自动加 `_2/_3` 后缀）；不再直接产生「未命名_N」项目，本地不再留草稿项目
    （`createDraftProject` 移除，画布水合不再隐式建项目，改为可行动的错误出口）。
  - **项目列表只显示服务端已有的项目**：「所有项目」屏与侧栏项目分组不再列出
    「本地还没同步上去」的行（`未同步` 标撤掉）；新项目由「首次推送服务端成功」
    的广播事件带回列表。
  - **一个项目只占一个页签**：项目级视图（主页 / 画布 / 工坊 / 资源库 / 产出 /
    成片）折叠到该项目唯一的页签（键 `project:<id>`）；旧版「一项目多行页签」
    的存量 sessionStorage 解析时折叠为一条，不整份作废。切到某项目页签时
    活跃项目同步跟随。
  - **项目页内左侧列表切换**：项目页改为「左侧列表 + 内容区」，左列表条目 =
    概览 / 画布 / 工坊六阶段（剧本 · 角色卡 · 场景分镜 · 镜头生图 · 视频生成 ·
    成片合成，编号 1~6，状态与项目主页同一份 production 派生）/ 资源库 / 产出 /
    成片；已到访分区保持挂载（切走不卸载），工坊六段共用一个受控
    `WorkshopPipeline` 实例（内部阶段轨道在项目页内隐藏）。
  - **项目页内可删除项目**：左列表底部新增「删除项目」入口，确认后本地与服务端
    一并删除、该项目页签关闭并回落首页。
