## Changed

- **首页不再显示「画布 / 工坊」页签，进入项目后才在左侧出现**：这两个视图是对「当前项目」的操作投影，没有打开项目时不该出现在主页导航里。给 `NavItem` 加 `projectScoped` 标记（画布 / 工坊），新增纯规则 `visibleNavItems(active)`（首页过滤掉项目作用域项，其它视图恢复），侧栏（`AppShell`）与命令面板（`CommandPalette`）共用这一份规则，避免两处漂移。首页其余导航（首页 / 项目 / 模型 / 成片 / 流程…）不变。

## 说明

进入项目（打开某个作品 → 切到画布/工坊等视图）后，`active≠home`，画布与工坊即出现在左侧栏。命令面板同步该规则（首页 ⌘K 也不列这两项）。配 `visibleNavItems` 规则单测（首页隐藏、进项目恢复、差集恰为两项）。
