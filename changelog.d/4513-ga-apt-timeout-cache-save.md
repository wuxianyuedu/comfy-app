## Fixed

- GA `heavy-gates` 的「装 Tauri 的 Linux 系统依赖」被慢镜像拥塞反复击穿：PR #4508 两条流水线同一步连续两次 15 分钟超时（apt 单包 1~2 分钟、成片 Ign 重试；同一步当天更早还是全绿，属时段性拥塞，#4513）。根因两段：① #4294 的两次 apt 尝试没有各自的时长上限，慢镜像是「连接活着、传输极慢」，连接级空闲超时（`Acquire::*::Timeout`）不触发，第一次尝试就能烧满 15 分钟步级预算，重试根本没机会发生；② #4480 的 deb 缓存 save 恒失败——chown 只在 restore 前跑一次，apt 以 root 落包后把 `partial/` 重建为 root:root 0700，runner 身份的 save 打包时 Permission denied（`##[warning]Failed to save`），缓存永远存不进去 ⇒ 每个碰壳的 PR 都从零下载。修法：两条 apt 命令各加 `timeout` 上限（update 180s / install 480s），步级超时 15 → 25 分钟罩住两次有界尝试；重试前 `dpkg --configure -a || true` 收尾（timeout 掐在解包段时不留脏 dpkg）；save 之前新增一步把 `/var/cache/apt/archives` 重新 chown 回 runner 用户（条件与 save 同一条 `!cancelled()`）——装挂了也落档，缓存从「永远空」变成「逐跑累积」，拥塞时段只有缓存未命中的第一跑付全量下载。判据与包清单一字不改。回归在 `tests/shell-gate-linux-sysdeps.test.ts`（新增 4 条）与 `tests/no-platform-ci-config.test.ts`（前提设施豁免名单 +1）。
