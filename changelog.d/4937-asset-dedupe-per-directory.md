## Fixed

- **同一张产物不能再重复加入资产库的同一目录**（#4937）：`asset.createFromTask`
  此前只做「复制文件 → 插行」，同一任务产物反复加入会在同分类同归属下堆出
  多张相同卡片（实测同一图出现 3 次）。现在入库前按「目录（分类 + 归属）+
  来源任务 + 产物名」查重：全部重复返回 `created: 0, duplicated: N`，前端提示
  「该资产已在此目录中」（不算失败，弹窗照常关闭、列表照常刷新）；多张产物
  部分重复只收缺的那张，`created / duplicated / skipped` 如实回报；跨分类 /
  跨归属再收仍允许。重复判定放在复制之前，重复加入不再产生多余的资产文件。
  顺手把 `asset.list` 测试里 `beforeEach` 的 `void` 入库改成 `await`——
  去重的那次额外查询放大了原有时序竞态，让它偶发查空；显式等待后稳定。
