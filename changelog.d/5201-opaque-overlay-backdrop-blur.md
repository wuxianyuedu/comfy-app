## Fixed

- **工坊 Agent 浮层等三处高不透明表面撤掉 backdrop-filter 背景模糊，消除画布上的常驻合成税（#5201，承接 #5195）**。
  症状：Agent 对话浮层（`bg-panel-deep/95` + `backdrop-blur-xl`）、底部状态栏（`bg-panel/95` + `backdrop-blur-sm`）、执行日志触发按钮（`bg-panel/90` + `backdrop-blur-sm`）都是 90~95% 不透明的表面叠背景模糊 —— 模糊透出的背景只有 5~10%，读不出「下面有活内容流过」，却把整块表面拖进一个 backdrop-filter 图层。工坊画布上背后 @xyflow 节点频繁移动时，这是每帧都在付的合成开销（#5195「界面操作掉帧」的一条常驻来源）。
  根因与裁决：这三个浮层此前靠同行 `fixed` 钻过 P87（规范 03 §3.13）的「贴边条放行」锚点，但它们既不是贴边条（Agent 浮层/日志按钮是浮件、状态栏虽贴边却叠了 95% 半透），也不满足「下面是活内容」的模糊前提。按 §3.13 裁决——撤模糊、把 `bg-*/90~95` 还原成不透明 token，层次交给已有的分层阴影 + 描边（浮层叠放语义保留）。三处都不改布局与交互，仅换承载面外观。
  用例：`tests/opaque-floating-surfaces.test.ts` 6 条，逐处锁定「不带 backdrop-blur + 底色为不透明 token（无 /NN 半透档）」；视觉在明暗两态截图核对（§13.12）。
