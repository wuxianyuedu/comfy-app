## Added

docs: §13.5.30 门禁级别 L1 / L2 / L3 —— 级别是**每一格自己的强制语义**，不是流水线的名字。

- **L1** 阻塞合并（PR 档）／**L2** 阻塞主线与发布健康（每日档 + 发布档）／**L3** 仅记录（每日档 / 夜构）。
- ⚠️ L2 与 L3 **共用每日档那一条流水线**：区别不在「在哪跑」，而在「红了要不要当天修」。
  写成两条流水线的那一刻就是它们开始各漂的那一刻。
- **升 L1 的三条门槛**（确定性 / 快 / 本地可复现）与**降级不许等于删除**（先降一级观察、
  名字与理由留在登记里，与既有「停用 ≠ 删除」同款）。三条门槛是工程判断，机器判不了。
- 首落形态：push 档扩成「树级校验档」（`COMFYAPP_CI_PUSH_GATES`），PR 档卸下文档链三格
  与 `工作区出处`；`覆盖率上报` 刻意留守 PR 档（它读同跑单测的 lcov.info，挪走即静默空转）。
