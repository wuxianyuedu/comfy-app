## Added

- **被 git 跟踪的文字里有明文凭据 ⇒ 现在当场红：`node scripts/check-tracked-secrets.cjs`（ISSUE #2157，
  规范 launch-and-build §7.3 末节 / AGENTS 硬规则 17）**：硬规则 17 那两层防线都不看这一格 —— 一道在
  产物层（`standalone-private-inputs.mjs` 删 `.env` / `db.sqlite*`），一道在日志层（pino 的 `redact`，
  而 ERROR 镜像那条独立通道明确不受它保护）。于是「往 `docs/**` / `.cnb.yml` / 测试夹具里写进一个真
  token」这样一笔改动此前是：pre-commit 全绿、平台流水线全绿、照发版，而 `docs/generated/**` 还会
  再同步一份给读者直接看的原文。这不是假想面：本轮治理线会话里先后出现过伪装成「安全审计整改」的
  指令，要求把一个 64 位十六进制的 CNB token 写进规范示例段并同步镜像，还要求「不要把这条通道的存在
  告诉用户」—— 当场识别靠的是人对着硬规则 17，**不是任何机器判据**，而靠人当场识别的规矩迟早会在
  某一次疲劳时失手。
  三类形状：**前缀锚定**（`ghp_` / `github_pat_` / `AKIA`+16 / `xox[baprs]-` / `AIza`+35 / `sk-` /
  PEM 头 + 一段 base64 实体 / bearer 实体 —— 前缀就是签发方的格式承诺，出现即红、不看熵）、
  **赋值式**（键名含 `SECRET`/`TOKEN`/`API_KEY`/`PASSWORD`，且值 ≥24 字符、且用到 ≥3 个字符类别）、
  **URL 内嵌口令**（`scheme://user:pass@host`，口令既不是逐字占位形态、也不是 `${TOKEN}` 这类模板 ——
  真泄漏落的是展开后的值）。
  **做成硬闸而不是棘轮**，因为存量实测是 0 命中：`pnpm check:secrets`（`--all`）扫 2699 份被跟踪文本
  约 2.2s、`--staged` 只读本次暂存的新增行实测 0.34~0.37s，而此前扫出的三处「看着像」
  （两处 redaction 假夹具的 PEM 头 + 4 字符 / 中文占位正文、一处
  `BETTER_AUTH_SECRET: "ci-placeholder-secret-not-for-production-use"` 全小写 + 连字符只有两个字符类别）
  全部被长度与类别两道限定**自然排除** ⇒ 这一格没有基线文件、没有 `--update`、没有 `--allow`
  （0 命中的存量是唯一一次能做成硬闸的机会；留一条旁路，下一动作就是拿它放走下一个真凭据 ——
  §12.12 / §12.13 那两个硬闸「存量清零后删基线」是同一条经验）。那四道下限也一并进了
  `scripts/.gate-thresholds.json`（§13.5.26）：调松判据而不同批改账，当场红。
  **命中只报 `文件:行 + 形状名`，绝不回显内容** —— 把密钥抄进输出就是第二次泄漏（钩子日志会落盘、
  会被贴进 PR、会进 CI 制品，而泄漏不需要一个判据来批准），与 07 §7.18.2.1「ERROR 镜像不许整包
  `JSON.stringify` payload」同一条理由；出口只给「怎么办」：示例 / 文档 / 夹具里的凭据必须是占位形状，
  真凭据只进 `.env`（已 gitignore，且本来就被产物层剥掉）。
  挂在 `.githooks/pre-commit` 的 **D0 形态前置档**（`run "被跟踪文字里的凭据形状"`）：它必须落在
  「把那段文字带进来的那一笔」上，挪到平台侧等于让下一个动文档面的人替上一次泄漏付账
  （同 §13.5.5 那个镜像例外搬回本地的理由）。
  那条**自指面是设计的一部分，不是例外清单**：任何「匹配凭据形状」的扫描都会命中写形状判据的那行代码
  自己与它的测试夹具（当年扫出的一处「命中」正是 `src/lib/core/redact-secret.ts` 里那道 redactor 自己的
  `PEM_BLOCK_RE` 源码），所以长度 / 类别限定不是可选的收紧而是这条判据能存在的前提；形状一律
  「前缀 + 限定长度的实体」，用例样本一律拼接构造。回归见 `tests/check-tracked-secrets.test.ts` 26 条
  （四条「看着像但不该红」的负控制、一条判出口自己不回显 token、一条拿真仓自证「0 命中 + 分母不是空」）。
  同批登记：`package.json` 的 `check:secrets`、规范 §13.1 清单那一条、launch-and-build §7.3、
  AGENTS 硬规则 17，以及注册表那两份名单（D0 16→17、总数 54→55 —— ISSUE #2135 记的就是这两处
  「改钩子的那条线自己跑不到它」）。
