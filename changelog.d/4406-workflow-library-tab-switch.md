## Fixed

- **工作流库切换工作流后详情空白 + 源文件页签 Hooks 顺序报错（#4406）**：
  ①「编辑对外参数 / 实际使用」两份画布视图共用一份常驻实例，但挂载判据只看
  「本工作流是否访问过画布页签」。切换工作流时页签不重置（仍停在画布页），新
  工作流的 id 与记录不符 → 常驻容器被卸载、其它页签又不匹配当前页签 → 整块内容
  空白，只有切回被记住的那条才显示。现在当前停在画布页签就直接挂载，另保留
  「访问过则切回工坊封装也不卸载」的保态语义（判据收进纯函数并加复现用例）。
  ② 源文件页签的 `LazyJsonViewer` 缺 `key={workflow.id}`：切工作流时复用同一
  `JsonViewer` 实例，而 `react18-json-view` 的 `JsonNode` 按节点值类型条件式调
  `useState`，同一位置节点类型一变就撞 React「change in the order of Hooks」。
  现在与画布预览等重型内容一样按工作流重建整棵 JSON 树。
