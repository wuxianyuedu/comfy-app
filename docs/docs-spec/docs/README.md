## 使用方式

- **日常开发**：遇到具体问题时，按目录定位对应章节（如"列表卡顿"→ 第 2 章）。
- **Code Review**：对照 [第 14 章反模式速查表](14-反模式速查表.md) 逐项检查。
- **提交前**：按 [13.1 提交前自查清单](13-提交与-code-review.md#131-提交前自查清单) 逐项核对。
- **新成员入门**：按 [15.5 新成员 10 分钟速读路径](15-附录.md#155-新成员-10-分钟速读路径) 顺序阅读。
