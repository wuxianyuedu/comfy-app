# 前端工程规范文档

> **适用范围**：T3 Stack 项目（Next.js 16.3 + TypeScript 7 + tRPC 11 + Drizzle ORM（better-sqlite3）+ better-auth + Tailwind v4 + Zustand 5 + @xyflow/react 12 + Tauri）
>
> **版本**：v1.2 | 2026-08-27（审核修订）
>
> **目标**：将已验证的架构决策与代码质量问题固化为团队规范，避免重复踩坑；达到商业级覆盖。
>
> **与项目开发规范的关系**：本套文档是前端工程细则，总纲以 `Comfy-APP-T3-项目开发规范.md` 为准；两处冲突时以主规范最新版本为准。统一索引（章节映射、分工与冲突处理）：[docs/README.md](../README.md)。

## 使用方式

- **日常开发**：遇到具体问题时，按目录定位对应章节（如"列表卡顿"→ 第 2 章）。
- **Code Review**：对照 [第 14 章反模式速查表](14-反模式速查表.md) 逐项检查。
- **提交前**：按 [13.1 提交前自查清单](13-提交与-code-review.md#131-提交前自查清单) 逐项核对。
- **新成员入门**：按 [15.5 新成员 10 分钟速读路径](15-附录.md#155-新成员-10-分钟速读路径) 顺序阅读。
- **拆分 UI 与逻辑**：范式见 [16.2.1](16-shadcn-ui与表单校验.md#1621-落地范式controller-hook--纯展示视图)，
  全库推进顺序与护栏见 [第 17 章](17-UI与逻辑分离.md)。
