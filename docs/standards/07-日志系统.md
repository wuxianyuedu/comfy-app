## 7. 日志系统

> 本项目含客户端日志面板（`LogProvider`）+ Tauri 后端日志事件 + 文件归档。本章给出日志系统的设计、降级与规范。

### 7.1 分层存储

```
内存 (最近 2000 条) ←→ 文件 (完整历史)
     ↑                        ↑
  实时展示/搜索            按需加载/全局搜索
```

### 7.2 搜索范围选择

| 范围 | 速度 | 完整性 | 适用场景 |
|------|------|--------|---------|
| 内存 | 快 | 可能不全 | 日常调试 |
| 全部（含文件） | 慢 | 完整 | 排查历史问题 |

### 7.3 日志面板开关快捷键

```tsx
// ✅ 统一快捷键规范
// Ctrl+Shift+L → 日志面板
// Ctrl+F       → 搜索框聚焦（JsonViewer/日志面板内）
```

### 7.4 日志状态用 Zustand，不用 Context

日志每秒可能数十条更新，Context 会导致所有消费组件 re-render。

```tsx
// ✅ Zustand：组件只订阅自己需要的字段
const errorCount = useLogStore((state) =>
  state.logs.reduce((n, l) => (l.level === "error" ? n + 1 : n), 0)
);
```

### 7.5 内存上限 + 环形缓冲

```tsx
// ✅ 默认保留最近 2000 条
const MAX = 2000;
setLogs((prev) => {
  const next = [...prev, ...entries];
  return next.length > MAX ? next.slice(-MAX) : next;
});
```

详见 [2.1 列表/日志必须有上限](02-性能规范.md#21-列表日志必须有上限) 与 [2.1.1 无限历史与虚拟滚动](02-性能规范.md#211-无限历史与虚拟滚动无上限场景兜底)。

### 7.6 console 拦截规范

`LogProvider` 拦截 `console.log/info/warn/error/debug` 把日志同时写入面板：

```tsx
// ✅ 拦截 + cleanup（StrictMode 下不永久污染）
useEffect(() => {
  const originals = { log: console.log, error: console.error, ... };
  console.log = makeLogger("info");
  console.error = makeLogger("error");
  return () => {
    console.log = originals.log;
    console.error = originals.error;
    // ...
  };
}, [addEntry]);
```

**规则**：
- 拦截只在 `LogProvider` 挂载期间生效，卸载后恢复原始方法（防 StrictMode 双调用问题）。
- 调用原始方法保留浏览器控制台输出（`originals.log(...args)`）。
- 序列化参数时处理 `Error` 对象（`stack`）、循环引用（`JSON.stringify` 加 try/catch）。

### 7.7 Tauri 后端日志事件

```tsx
// ✅ 动态 import + try/catch，浏览器环境静默跳过
try {
  const { listen } = await import("@tauri-apps/api/event");
  unlisten = await listen<{ level: string; message: string }>("log:emit", (e) => {
    addEntry({ level: mapLevel(e.payload.level), message: e.payload.message, source: "tauri" });
  });
} catch {
  // 非 Tauri 环境（浏览器开发），忽略
}
```

### 7.8 历史日志加载

- 启动时加载最近 N 个归档文件（`/api/logs/list` + `/api/logs/history`），带大小上限（如 5MB）防止一次加载过多。
- 轮询当前日志文件（`/api/logs/current?offset=...`）增量追加；文件被重置（新运行）时 offset 回零、完整重读。
- 加载失败不应阻塞实时日志轮询（try/catch + 静默忽略）。

### 7.9 导出与复制

```tsx
// ✅ 复制：Clipboard API + execCommand 兜底
async function copyAll() {
  try {
    await navigator.clipboard.writeText(formatForClipboard(logs));
  } catch {
    const ta = document.createElement("textarea");
    ta.value = formatForClipboard(logs);
    document.body.appendChild(ta);
    ta.select();
    document.execCommand("copy");
    document.body.removeChild(ta);
  }
}

// ✅ 下载：Blob + 临时 <a download>
function download() {
  const blob = new Blob([formatForClipboard(logs)], { type: "text/plain;charset=utf-8" });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = `logs-${new Date().toISOString().slice(0,19).replace(/:/g,"-")}.txt`;
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);
  URL.revokeObjectURL(url); // 及时释放
}
```

### 7.10 日志序列化健壮性

```tsx
// ✅ 处理各类输入，避免序列化抛错
function serializeOne(a: unknown): string {
  if (typeof a === "string") return a;
  if (a instanceof Error) return `${a.name}: ${a.message}\n${a.stack ?? ""}`;
  try { return JSON.stringify(a, null, 2); }
  catch { return String(a); } // 循环引用/BigInt 等兜底
}
```
