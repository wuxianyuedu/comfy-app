## 5. 类型安全

> 本项目使用 TypeScript 7（strict）+ Zod 4。类型安全的目标是：编译期捕获数据结构变更、避免 `any` 静默吞错。

### 5.1 禁止 `any` 和 `as Record<string, any>`

```tsx
// ❌ 错误
const data = response as Record<string, any>;

// ✅ 正确：Zod schema 校验
import { z } from "zod";
const ResponseSchema = z.object({
  files: z.array(z.object({
    name: z.string(),
    size: z.number(),
  })),
});
const parsed = ResponseSchema.parse(response);
```

**例外**：与第三方库交互、渐进迁移阶段可局部用 `unknown` + 类型守卫，`unknown` 比 `any` 安全（必须窄化后才能用）。

### 5.2 禁止 eslint-disable 堆砌

```tsx
// ❌ 错误：12 个 eslint-disable 说明类型系统已经在尖叫
/* eslint-disable @typescript-eslint/no-explicit-any */
/* eslint-disable @typescript-eslint/no-unsafe-assignment */

// ✅ 正确：修复类型问题，而不是静音
```

**允许的局部禁用**：仅在调用第三方无类型 API 时，用行内 `// eslint-disable-next-line` 单行禁用 + 必须附注释说明原因，禁止文件顶部批量禁用。

### 5.3 用 ReturnType 推导组合 hook 的返回类型

```tsx
// ✅ 正确：实现改了类型自动跟
export type IOEditContextValue = ReturnType<typeof useIOEditContext>;
```

### 5.4 枚举用 union type（字符串字面量），不用 enum

```tsx
// ❌ 错误：enum 生成反向映射，包体积/ tree-shaking 不友好
enum Status { Pending = "pending", Running = "running" }

// ✅ 正确：union type + as const 派生（单点维护）
const STATUS_LIST = ["pending", "running", "done", "error"] as const;
type Status = typeof STATUS_LIST[number]; // 派生，单点维护
```

### 5.5 API 响应一律 Zod 校验

```tsx
// ✅ tRPC 已内置 Zod input/output schema；REST 端点手动校验
const TaskListSchema = z.object({
  tasks: z.array(TaskSchema),
});
type TaskList = z.infer<typeof TaskListSchema>;

// 在 fetcher 边界校验一次，内部全链路类型安全
async function fetchTasks(): Promise<TaskList> {
  const res = await fetch("/api/tasks");
  return TaskListSchema.parse(await res.json());
}
```

**收益**：后端字段增删/改名时，前端在**数据入口**就报错，而不是在某个深层组件里 `undefined` 崩溃。

### 5.6 类型守卫与窄化

```tsx
// ✅ 自定义类型守卫
function isTask(item: unknown): item is Task {
  return typeof item === "object" && item !== null && "id" in item && "status" in item;
}

// 使用
const tasks = rawList.filter(isTask); // 类型自动窄化为 Task[]
```

### 5.7 避免 `as` 断言绕过检查

```tsx
// ❌ 错误：as 断言把类型问题推迟到运行时
const view = card.id as WorkspaceView;

// ✅ 正确：用类型约束让编译器帮你校验
const QUICK_ACTIONS: Array<{ id: WorkspaceView; ... }> = [ ... ];
// 或运行时校验
function isWorkspaceView(v: string): v is WorkspaceView { ... }
```

### 5.8 `unknown` vs `any` 选择

| 场景 | 用 |
|------|---|
| 外部输入（fetch/JSON.parse/event） | `unknown`，然后 Zod 校验或类型守卫窄化 |
| 确实任意结构（如动态 className 合并） | `any` 仅在工具函数内部，对外仍返回具体类型 |
| 第三方无类型 API | `// @ts-expect-error` 单行 + 注释，或用 `unknown` 包裹 |
