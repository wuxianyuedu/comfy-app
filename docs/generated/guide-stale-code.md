# 页面还跑着上一版代码：为什么会白屏，以及怎么一次修好

> 适用对象：所有在本机运行本项目的人（开发人员 / 非开发人员通用）。
> 这条指南回答一个高频现象：**应用一直开着，中间拉到了新代码，打开某个功能却
> 整块白屏 / 报错**——以及遇到它时该做什么。
>
> 想了解背后的机制与实现，见
> [`standards/launch-and-build.md` §4.3](standards/launch-and-build.md#43-陈旧实例运行图落后于源码时的可观测性issue-389)。


---

## 1. 你会看到什么

典型表现（都是同一件事的不同样子）：

- 打开**工作流编辑器 / 画布**，整块变成错误页或一片白，只有「返回」可点；
- 浏览器控制台 / 日志里出现 `xxx is not a function`，例如
  `ioApi.getState().purgeMachineNames is not a function`；
- 某个功能「点了没反应」——不报错，但就是不起作用；
- 重启应用之后，什么问题都没了。

## 2. 为什么会这样

本项目的**前端源码是热更新的**：改了 `src/` 下的代码，dev server 会让界面自动
换成新代码，不需要你手动做什么。

但有一条边界：**已经打开的界面不会因为代码变了就重建自己**。界面里有些对象是在
它第一次打开时创建的，创建的那一刻就带上了「当时那份代码里的能力清单」；代码后来
变了，这份清单不会跟着更新。于是——

```
应用一直开着 + 期间拿到了新代码 → 页面里还是旧那份代码造出来的对象
                                → 用到只有新代码才有的能力时就直接报错
```

这和你的工作流没有关系，文件也没坏。**它属于「界面比代码旧」**，不是数据问题。

> 顺带说明：并不是每次拉到新代码都会这样。绝大多数改动由热更新平滑替换，你能
> 直接看到新效果；只有「改动发生在界面已经打开之后、且这条路径依赖新代码」时才会
> 露出来，所以它看起来时有时无。

## 3. 怎么做（按顺序试，通常第一步就好）

1. **重载一次页面**：在应用窗口里按 `Ctrl+R`。
   这是标准解法，绝大多数情况一步到位。
2. **仍然报同样的错** → 关掉当前那个全屏视图（如工作流编辑器）再重新打开一次。
   它会重新创建这些对象，等于局部重载。
3. **还是不行** → 说明应用服务（dev server）自身也是旧的：
   **关掉应用窗口，重新双击一次启动入口**。
4. 仍不恢复：按 [`guide-non-developer.md`](guide-non-developer.md) 第 8 节把
   `log\` 目录发给团队，并说明「重载后仍报同一个 `is not a function`」。

### 重载会不会丢东西？

**不会丢已保存的工作流与画布数据**——它们都在服务端，重载只是让界面重新取一份
新代码。

唯一要注意的是：**正在执行中的生成任务**会随页面重载断开与执行日志的实时连接
（任务本身仍在服务端继续跑，可在执行记录里回看结果）。如果你正在等一个任务出图，
就先让它跑完再重载。

## 4. 应用会主动告诉你

为了不让你在「白屏 + 一堆报错」里自己猜，应用现在会**主动提示**：

- 它持续比对「当前页面跑的代码」与「本机源码 / 应用服务」，一旦发现页面已经落后、
  且真的因此跳过了某个功能，就弹出应用内提示；
- 提示里直接写了「怎么做」（即上面第 3 节的三步）与「不会丢工作」的说明；
- 提示同时会**留一条在消息中心**（底部状态栏的铃铛图标，未读有数字），
  一闪而过的那条没看清可以随时翻回来。

因此：**看到这条提示就照做**，不要继续在旧页面上操作——那样只会碰到更多
「点了没反应」。

## 5. 给开发人员的两条约定

改 store（`src/components/studio/workflow-editor/WorkflowStores.tsx` 等）时：

1. 新动作**必须**经 `callStoreAction` 调用（或在调用点自行判存在性）。
   直接 `getState().newAction(...)` 就是把这个白屏重新放回去。
2. 新增**会被已挂载实例调用到的模块**时，把它的路径加进
   `src/app/api/dev/build-id/route.ts` 的 `WATCHED_MODULES`，
   让「页面是否还跑着旧代码」的判定覆盖到它。

详细的机制、判据与回归测试清单见
[`standards/launch-and-build.md` §4.3](standards/launch-and-build.md#43-陈旧实例运行图落后于源码时的可观测性issue-389)。
