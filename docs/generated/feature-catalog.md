## 1. 编号与状态词表

**编号**：`FR-<域>-<序号>`。域缩写与本文 §2 的分节一一对应。编号一经分配
不回收、不改义；退役不删行（改状态 + 注明去向）。

**状态四态**：

| 状态     | 词义                                                         |
| -------- | ------------------------------------------------------------ |
| 已上线   | 用户可用，行为即 specs 所写                                   |
| 灰度     | 已在场但默认不承重 / 只服务部分路径（开关或特定入口才生效）   |
| 计划中   | 已立案未实现，或只落了配置层（运行时未接）                    |
| 已退役   | 曾存在、已撤；保留编号供历史追溯                              |

**已知问题不占状态**：实现与需求的偏差（缺陷 / 双实现 / 文档漂移）走 Issue，
索引见 §3；它们不是需求的「状态」。
