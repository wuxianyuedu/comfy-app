    Class WorkflowModelTagRepository

    模型标签仓储。标签是「用户级全局库」，按 (userId, name) 唯一；一个标签 可被多张工作流（隐式多对多 WorkflowTemplate.modelTags）引用。本类集中 实现列表 / 幂等 upsert / 重命名（保留关联）/ 删除，并把越权校验 （必须归属当前用户）收敛在仓储内，调用方不再手写 where: { userId }。
