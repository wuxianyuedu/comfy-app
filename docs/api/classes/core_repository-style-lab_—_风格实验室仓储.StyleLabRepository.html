      批量落格子（一次试验展开出的整批），并返回落下来的行。

      行形状取 schema 的 $inferInsert：在这里重抄一遍列名，将来加一列就会 静默不写（对象少字段运行时没人报警），而类型能替我们拦住。

      返回行而不是条数：扇出要把 taskId 记回新格子，而 id 是库里生成的 —— 只回一个数就得再读一次表（多一次往返，且两次读之间库可能已被改写）。 空入参不发 SQL，直接回空数组。

    setCellTask

    • setCellTask(cellId: string, taskId: string): Promise<void>

      把入队得到的任务 id 记回某一格（扇出的最后一笔）。

      只 update 这一列而不是整行替换：格子行的其它字段（风格 / 特征键 / 提示词）是 入队之前算好并落库的，替换写法会按调用方手里的内存副本再写一遍 —— 同一行 就有了两个写入者，而这里的意图只是补上「这一格由哪条任务跑出」这一个事实。

      归属不在这条 SQL 上判：调用方（路由）取格子时已经按 userId 过了一遍试验行， 这里的 cellId 只能来自那份清单。

      Parameters

      • cellId: string
      • taskId: string

      Returns Promise<void>
