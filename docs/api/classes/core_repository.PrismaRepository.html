    Class PrismaRepository<T, TCreate, TUpdate, TWhereUnique>

    基于 Prisma delegate 的泛型 CRUD 基类。子类只需传入 prisma.xxx 委托与 主键字段名，即可获得一套标准、可单测的持久化能力。
