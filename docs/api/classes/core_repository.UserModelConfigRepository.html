    Class UserModelConfigRepository

    模型目录配置仓储。每行以 (userId, folder) 唯一，记录用户对某个 ComfyUI 目录的启用 / 别名覆盖。所有方法按 userId 隔离，upsert/delete 的 userId_folder 复合主键收口在此，路由不再手写 prisma.userModelConfig。
