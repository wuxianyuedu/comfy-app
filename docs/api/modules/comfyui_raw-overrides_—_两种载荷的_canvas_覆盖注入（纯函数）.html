    Module comfyui/raw-overrides — 两种载荷的 canvas 覆盖注入（纯函数）

    raw-overrides.ts — 两种载荷的 canvas 覆盖注入（纯函数）

    「把 canvas workflowInputs 注入执行载荷」的纯逻辑模块：不依赖数据库 / 网络，可独立单测。

    供 executor-cli 的 comfy-cli 提交路径在写临时工作流文件前调用，把前端下发的 (nodeId, name, value) 覆盖项写进载荷。两种格式走同一套语义，只是落点 不同（这是「api 也要注入画布覆盖」的落地处）：

    • RAW UI-format → applyRawOverrides：值躺在 widgets_values 下标里， 要按控件名反查到下标（并跳过 seed 的 control_after_generate 哨兵槽）；
    • API 图 → applyApiOverrides：inputs 是命名 map，按名字直接写。

    raw 侧的子图（subgraph）wrapper 覆盖项会额外同步到内层节点：wrapper 只是把 内层控件「提升」出来的宿主，真正参与 UI→API 转换的是内层节点的 widgets_values（comfy-cli 展开子图后读的是内层值），只改 wrapper 不改内层 会让覆盖在转换阶段被内层默认值覆盖回去。
