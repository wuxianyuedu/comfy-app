    raw-view-graph.ts — RAW 工作流 → 画布视图图（纯离线派生，不发网络）

    唯一用途：给「RAW 视图」的画布（以及 detail.nodes / detail.graph 这两个 下发字段）提供一份保留 subgraph wrapper 的节点 + 连线视图。直接从 rawJson 现派生 —— 它带坐标与控件值，是唯一的存库原件。

    这不是「格式转换」，也不是可执行图的来源（别把它接回导入或执行链）：

    • 入库就是原件逐字落 rawJson；
    • 执行由 comfy-cli 按节点类定义做权威转换（送的就是 rawJson）。 历史上「导入时把 raw 转成 API 图存库」已被证明有害（ISSUE #632）：无 ComfyUI 可达时按类名猜控件顺序，猜错就是一份能打开、跑起来结果不对的图。

    _meta 为什么保留：画布的节点 JSON 面板要显示 title / mode，而画布导出 的图在提交前要经 execution-graph.prepareGraphForExecution 做旁路穿透 —— 那一步读的正是 _meta.mode / virtual / value / inputOrder / inputTypes / outputTypes。丢掉它们会让「画布上旁路一个节点再运行」失效。
