    executor-cli.ts — comfy-cli 执行路径（两种格式统一）

    comfy-cli 提交路径。本模块提供：

    • cliProcs 正在运行的 comfy-cli 子进程表（供取消）
    • executeViaComfyCli 工作流提交 + stdout 事件收割
    • applyRawOverrides 把 canvas 的 workflowInputs 注入 raw json

    两种格式都经 comfy-cli（comfy run --workflow 两种都吃：API 格式是它的 默认输入，UI-format 由它自动做权威的 UI→API 转换并展开子图）：

    • RAW 原件：注入画布覆盖 → 剔除无后端实现的纯 UI 控制节点 → 交 cli；
    • API 图 ：剔除 bypass / 静音 / 纯前端节点并穿透连线（见 execution-graph） → 交 cli 直接提交。 统一的好处是提交、校验错误、日志口径只有一套（此前 API 走 postPrompt， 同一份工作流换个格式就有不同的报错文案）。

    成功/失败统一走 executor-finalize 的收口。
