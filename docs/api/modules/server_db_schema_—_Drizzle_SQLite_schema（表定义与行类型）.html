    Module server/db/schema — Drizzle SQLite schema（表定义与行类型）

    schema.ts — Drizzle SQLite schema

    表名严格对齐现有 db.sqlite，保证 drizzle-kit push 以 ALTER 方式同步、 不破坏已有数据。

    列形态（改了就是改库文件格式，别当风格问题）：

    • DateTime 一律 ISO 字符串（TEXT）+ dateNotNull / dateNull 序列化。 不用 Drizzle 默认的 integer(timestamp) —— 库里已有的行是 ISO 文本， 换了读写两端对不上（createdAt 出现过的「裸毫秒串」就是旧格式残留， 读取侧由 dateNotNull.fromDriver 与 ~/lib/time-format 统一归一）。
    • Boolean 用 integer(..., { mode: "boolean" })（列里是 0/1）。
    • Json 用 text(..., { mode: "json" })（列里是 TEXT JSON）。
    • id 默认 cuid2（@paralleldrive/cuid2 的 createId）； Project 复用客户端 proj_* id（无默认）。
