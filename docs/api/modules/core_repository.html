    Module core/repository

    repository.ts — 持久化访问的 Repository 抽象（Repository 模式）

    动机

    当前 44 个 API 路由里有 30 个直接 import { prisma } 并手写 findMany / update / deleteMany，导致：SQL 散落、缺统一校验、缺按用户隔离、 无法单测（强耦合 Prisma 单例）。本文件确立 Repository 模式：

    • Identifiable / Repository：与具体 ORM 无关的契约接口；
    • PrismaRepository：基于 Prisma delegate 的泛型基类，封装 CRUD；
    • ProjectRepository：业务 Repository 范例，附加「按用户隔离」语义。

    收益

    • API 路由只依赖 Repository 接口，不碰 prisma → 可换实现、可 mock 测试；
    • 用户隔离（userId 过滤）集中在 Repository，避免每个路由各写一遍 where；
    • 后续引入缓存/读写分离，只需在基类加一层，调用方无感。
