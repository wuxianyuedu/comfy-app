    Module comfyui/execution-graph — API 图的**执行前规范化**（纯函数）

    execution-graph.ts — API 图的执行前规范化（纯函数）

    与 raw.ts 的分工（两者不再互相缠绕）：

    • raw.ts 只管「两种格式怎么识别 / 坐标怎么取 / 画布怎么配控件名」；
    • 本模块 只管「一份 API 图在提交出去之前要怎么收拾」。

    为什么这一层必须存在（ComfyUI 的真实提交语义）：

    • mode = 2（静音）/ mode = 4（旁路）的节点不会出现在 prompt 里；
    • 旁路节点的连线要「穿透」——按类型在它自己的入参里找同类型的上游；
    • Reroute / PrimitiveNode / Note 这类纯前端节点同样不入 prompt， Reroute 透传连线，PrimitiveNode 把字面量灌给下游。

    存库与画布导出的图保留全部节点（画布要画出来），因此收拾只能放在提交前。 不能省掉这一步：API 格式的载荷是原样交给 comfy-cli 的（它对 API 格式直接 提交，不做 UI→API 那套前端语义），少了它，画布上被旁路/静音的节点会被真的 执行。
