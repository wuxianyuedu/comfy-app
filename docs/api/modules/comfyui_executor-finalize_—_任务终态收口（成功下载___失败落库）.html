    executor-finalize.ts — 任务终态收口（成功下载 / 失败落库）

    终态收口：把一次执行的结束（成功下载 / 失败落库）收到一处。

    • complete 完成入口：抢终态 → completeInner → 兜底失败
    • completeInner 拉 history、收集产物、下载落盘、双写 DB、 写 manifest / workflow.json 快照
    • fail 对外失败入口（先抢终态再收口）
    • finalizeFailure 真正失败收口（不做 settled 判断）

    依赖的通道层（claimSettle / fetchHistoryEntry）在 ./executor-ws， 派发（领取 + 提交）在 ./executor-dispatch。
