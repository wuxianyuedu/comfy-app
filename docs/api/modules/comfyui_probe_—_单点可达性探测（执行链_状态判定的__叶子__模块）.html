    Module comfyui/probe — 单点可达性探测（执行链/状态判定的**叶子**模块）

    probe.ts — 单点可达性探测（执行链/状态判定的叶子模块）

    两个「只发一次请求、不碰会话缓存」的探测单元：

    • probeComfyAtPort 探一个已知端口（不做进程表查询 / 端口扫描）
    • probeBaseOnce 对给定地址各发一次 /system_stats

    本层必须留在叶子的理由是断环（规范 12.7）：status.ts（状态判定）需要 probeComfyAtPort，而 client.ts 又需要 instance-port.ts 的 baseForLocalPort / queryInstanceByPath，instance-port.ts 需要 status.ts 的注册表读取 —— 三方成环。把「零依赖（只有 fetch + 地址拼接）」 的这一层下沉后，依赖方向变成单向：

    client ─┐
instance-port ─┼─→ probe（本模块，只有 fetch + 地址拼接）
status ─┘

    这里刻意不 import 会话缓存：探测必须是「按次事实」，不能污染 client.ts 里「本次会话连哪个地址」的粘性结论（ISSUE #344 的成因）。 需要粘性语义的调用方（client.probeComfyBase）自己包一层缓存回滚。
