    SERVICES_LOG_DIR: string = ...

    常驻服务运行时日志（一次启动一份文件；设置页日志面板跟随读取）。

    这里只有目录，没有「某个来源的固定文件名」——四份 runtime 日志 （comfyui / drizzle-studio / ollama / app-runtime）现在是 <来源>-<日期>_<时分秒>.log，同名规则与解析收在 runtime-log-file.ts， 「本次该写哪一份」收在 runtime-log-pack.server.ts。

    此前这里是 COMFYUI_RUNTIME_LOG / OLLAMA_RUNTIME_LOG / DRIZZLE_STUDIO_RUNTIME_LOG / APP_RUNTIME_LOG 四个固定名常量，写方 直接追加进同一个文件（ISSUE #1326 的用户原话：「这四份也要改成每个文件只 存储单次运行的历史，单次里如果执行多次也存放多个文件，这样看起来清晰」）。 固定名一撤，RUNTIME_LOG_FILES（面板的「来源键 → 文件」表）也随之失去意义 —— 现在一个来源对应一目录下的多份，那一层是 listRuntimeLogFiles()。
