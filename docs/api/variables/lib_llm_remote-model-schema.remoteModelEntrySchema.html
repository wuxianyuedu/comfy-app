    远端模型的线上 / 存储条目形状：extraModels 数组里那一枚对象。

    它是 src/server/api/routers/llm.ts 的 configSave 入参的一部分（服务端只是消费方）， 也是 ~/lib/llm/types.ts 里 RemoteModelEntry 的写侧形状 —— 此前这两件事在路由里 各写一遍，其中 kind 是一条行内字面量枚举 ["chat","image","video"]，与本模块 从 REMOTE_MODEL_KINDS 派生的那一份是两个独立真相：往词表里加一种用途（如 audio） 之后，弹窗能选、条目能存，而服务端入参那一条 zod 直接拒 —— 表现是设置页保存时一句 英文 zod 原文，且 tsc / eslint / 单测全绿（两份枚举在类型上各自自洽）。 现在两边取同一个 z.enum(REMOTE_MODEL_KINDS)。

    hasApiKey 不在这里：它是 getConfigForClient 下发的只读视图字段（明文密钥 一律不落客户端，台账 A4），条目回写时带着它也只是被 zod 剥掉 —— 把它写进入参形状 等于允许客户端替服务端宣布「这条存过密钥」。
