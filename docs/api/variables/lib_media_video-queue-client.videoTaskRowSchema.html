    为什么必须逐行校验，而不是一句 as

    此前这里是 RouterOutputs["task"]["list"]["tasks"][number] & { images?: … } —— 交叉类型只会加列，发现不了「镜像声明的列线上从来不发」。它标成 optional 之后，「取视频产物路径」那句读到的永远是 undefined，video 于是 恒为 null：表现不是报错，而是「封面永远是占位图标、下载按钮一次都没出现过」， 而 tsc / eslint / 全量用例 / 覆盖率门槛全绿（ISSUE #1579）。

    镜子照的是什么

    videoPath 是服务端投影算出来的列（封面是预览图时，cover / mediaType 都答不出成片在哪）。这一行由 tests/task-list-wire-contract.test.ts 从真 router 出发经一次 JSON 传输反向核对：镜像声明的每一列，线上都在发。
