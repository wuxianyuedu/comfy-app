    EXPOSED_PARAM_DISPLAY_LABEL: Record<ExposedParamClass, string> = ...

    各口的界面展示名 —— 整个仓库的唯一出处。

    同一张契约清单会出现在三处（工坊封装的对外口一览、工作流库「画布节点」的 卡片列、模式契约编辑器），三处各写一份字符串必然漂移：ISSUE #596 现场就是 「尺寸」在工坊封装页写成 尺寸（比例 + 分辨率 / (百万像素 + 倍数)）、在同一 页面的画布节点卡片上只写 尺寸，用户读到的像是两个不同的口。

    另外「负向提示词」（契约编辑器）与「负面提示词」（契约表）本来就是同一个口 的两种叫法，在这里统一为一套措辞。

    措辞与具体形态无关的一律不带括号：括号是给「同一类的多种写法」用的， 只有 size 与 duration 各有两类等价表达，需要在这里说清。
