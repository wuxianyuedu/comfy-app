    Variable COMFY_UNBOUND_PORT_TTL_MSConst

    COMFY_UNBOUND_PORT_TTL_MS: 0

    未绑定端口的快照（「进程在、接口还没就绪」）的缓存时长：比普通 TTL 更短。

    这类快照的含义是「正在启动」，而正在启动的下一步就是绑定端口——状态行 必须尽快翻成「运行中」。若沿用 1.5s TTL，设置页的 5s 轮询有相当概率连着 两次都命中同一份「端口未绑定」缓存，用户看到的就是「明明起来了还显示 启动中」（ISSUE #344）。
