    Interface PkgReport

    custom-nodes 解析/探测的服务端 ↔ 前端共享协议类型。

    这些形状由服务端（/api/custom-nodes 路由 + Python 解析脚本）产出、由视图层 CustomNodesSettings 消费——「谁产出、谁定义」应对称，故收在 src/lib（server 与 view 都能安全 import 的地基），不再让视图层的 types.ts 兼任协议源。视图 types.ts 从此处 re-export，既有 importer 路径不变。

    两个 ndjson 事件类型（SettingsStreamEvent / ParseStreamEvent）是流协议的 唯一契约：服务端 send() 与前端消费端都按它对齐——type 拼错、字段漂移在 发出侧即编译不过（此前服务端 send(obj: unknown) 与前端 interface 零约束）。
