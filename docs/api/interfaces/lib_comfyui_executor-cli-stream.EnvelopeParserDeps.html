    onProgress

    onProgress: (
        percent: number,
        node?: {
            classType?: string;
            id: string;
            label?: string;
            max: number;
            value: number;
        },
    ) => void

    进度百分比（已从 completed/total 换算）；node 是事件自带的当前节点信息。

    两类事件的形状不一样，是实测出来的（真出图那一轮，见 ADR §24）： · executing 自带 class_type 与 title —— 直接用它，那是 ComfyUI 展开 子图之后的权威值； · progress 只有 node / completed / total，不带类名 ⇒ 只能靠 deps.patched（提交那一刻真正交出去的图）认，走的是与 WS 帧同一个出口 classTypeForNode（两种图形状都认，含 76:69 这种子图链 id）。 认不出时 classType / label 都不带，id 与步数照旧透出 —— 进度帧不许因为 认不出类名就被丢掉。

    这里顺带更正一句旧口径：3-C（§13-3C）与 4-B2（§14 D1）都写着「comfy-cli 那条 事件源拿不到 class_type」，实测只对 progress 成立；executing 是带的，而 progress 也不是拿不到，只是当年没人去查那张就在手上的图。
