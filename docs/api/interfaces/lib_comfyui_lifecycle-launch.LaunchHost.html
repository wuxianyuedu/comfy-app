    beginRuntimeSession

    beginRuntimeSession: () => string

    开一次启动的日志文件（comfyui-runtime-<时刻>.log），返回它的路径。

    由拉起之前那一步调用 —— 一次启动一份文件之后，「本次启动的日志在哪」 是文件本身回答的（不在是同一份文件里靠横幅分段）。同秒内重复启动由写入器 分叉出 -2 / -3，不会覆盖前一次的现场。
