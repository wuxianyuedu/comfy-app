    proxyAuthorLabels

    proxyAuthorLabels: Record<string, string>

    子图暴露口 → 作者写在外层 wrapper 上的业务名（label）。

    勾选点落在外层封装卡片上时，落库的 name 是 wrapper 本层的槽位名； ComfyUI 在某些路径上把 properties.proxyWidgets 隔离掉 （proxyWidgetErrorQuarantine），顶层富化于是查不到内部「真实的作者名」， 只剩 ComfyUI 通用翻译（seed → localized: "随机种"）——作者写的 Seed 就丢在这一层（ISSUE #349：切成随机值/固定值后名字退回 value_1）。 内层视图的 wrapper 边界记录（-10 边的源节点）与本层槽位名一对就能 把作者名捞回来，作为「按 alias 回退取名」的来源下发给顶层富化。

    键是 节点id::槽位名，不是裸槽位名：一个子图里多个同类节点共享 同一个内部槽位名（四个 PrimitiveInt 的入参都叫 value），只按槽位名 记账会被后写的暴露口覆盖 —— 于是 Seed 节点显示成最后一个 FPS 的口名 （ISSUE #394）。
