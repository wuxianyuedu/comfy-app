    OptionalblockedReason

    blockedReason?: string | null

    无法内嵌时的页签内说明（成因 + 修复动作）。

    为什么挂在页签上而不是弹窗：目标形态是「只有多页签」。当内容打不开时， 页签照常打开、里面渲染这段文字，用户留在同一个窗口里；而不是像以前那样 另开一个（多半也是空白的）独立窗口，把问题搬走却不说原因（ISSUE #310）。

    OptionalblockedUrl

    blockedUrl?: string | null

    无法内嵌时对应的内容地址，渲染在说明里供用户复制/自查。

    为什么必须带上：只剩一句「已阻止此内容」时，用户（和排查的人）都无法判断 到底是哪一层拦的 —— 地址是唯一能自己验证的信息（复制到浏览器能开 → 拦的 是应用外壳；也不能开 → 拦的是对方自己）。ISSUE #310 第三次回归现场就是 「有错误页、没地址」，于是只能再来一轮猜测。
