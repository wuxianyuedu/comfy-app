    failureText

    failureText: string | (() => string)

    失败文案的标题（详情由 errorMessage 从抛出的值里取）。

    收口前这一句在每个落点手写一遍，且同一条账里有两种写法： 「动作名 + 失败」（"更新模式失败"）与光秃秃的 "删除失败"。 后者在用户看到时缺少「删除的是什么」，所以这里要求调用处显式给出。 可以给函数（文案依赖入参时，如「删除「<名字>」失败」）。
