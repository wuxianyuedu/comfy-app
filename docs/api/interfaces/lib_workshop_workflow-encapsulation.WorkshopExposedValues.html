    Interface WorkshopExposedValues

    工坊这一次生成要落下去的对外参数（全部可选）。

    视频模式与生图模式共用同一个入口，只是用到的字段不同： 文生视频只给 prompt / size，图生视频额外给 firstFrame，首尾帧再给 lastFrame。

    尺寸只按 size-presets 的两种表达给（比例 + 分辨率 / 比例 + 百万像素 + 倍数），不填 "WxH" 字符串：宽 / 高由本层按场景尺寸表算出来（目标工作流 要 width+height 时）—— 字符串反解回比例会落在两个预设之间，用户表现就是 「选了 1k 却算出个怪尺寸」。

    这些值是工坊的业务语义（镜头图 / 首帧 / 尾帧各是什么），与「落到工作流的 哪一行」是两件事：后者由作者在工作流库里的连线声明。

    Optionalcustom

    custom?: Record<string, string | number>

    *自定义口**的值（契约口 id → 值，如 { "custom-text-1": "水彩" }）。

    预制的几个口各有业务语义（提示词 / 尺寸 / 首帧…），所以各占一个字段； 自定义口是作者自己声明的，工坊没有第二个地方知道它的语义，只能按 id 收 在一张表里。值原样下发（文本口是字符串，数字口是数字），落点仍由作者连线 声明（applyParamMapping 只认作者画的线）。
