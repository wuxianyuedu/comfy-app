    Optionaldisplay

    display?: string

    卡片行上显示的名字；缺省 = name。

    对外输入卡片给的是这个对外参数自己的名字（「提示词」「尺寸」）： 这一行说「这个口是什么、出去是什么类型」，落到工作流的哪一行由连线表达 —— 行上写 value / text_1 这类 ComfyUI 内部 pin 名，读起来与作者在 ComfyUI 里看到的对不上，也会随工作流改版漂移。落点仍在 name / title 里可查（ioKey）。对外输出卡片不给（那里端口名就是作者要看的名字）。

    type

    type: string

    *这个对外口自己的**声明类型（大写，如 STRING / IMAGE / COMBO）。

    恒不随落点变：卡片上的芯片说的是「这个口对外是什么」，不是「它现在落到 哪一行、那一行声明成什么」。用户口径：「对外参数的类型都不要跟着连线改动， 现在图片节点连过去会变更显示类型」—— 同一个「首帧图片」连到 IMAGEUPLOAD 的装载口就显示成 IMAGEUPLOAD，松手又变回 IMAGE，读起来像口子自己换了类型。 落点那一行的类型仍在（targetType，行 title 里可查）。
