    OptionalproxyField

    proxyField?: {
        field: string;
        label?: string;
        localized?: string;
        nodeId: string;
    }

    子工作流封装节点暴露口背后的「内部真实字段」。

    wrapper 的 inputs[] 里那一条是本层生成的别名槽位（ComfyUI 为 proxyWidgets 自动编号成 value_1 / value_2），字段名与业务语义都在 内部节点上（proxyWidgets[i] = [internalNodeId, fieldName]）。富化只按 name 回查时拿不到内部字段的业务名，标签就退化成别名（ISSUE #349）。 这里把解析结果随条目下发，让富化（workflow-detail-io）能在别名之外 找到真实字段名与它的 label / localized。
