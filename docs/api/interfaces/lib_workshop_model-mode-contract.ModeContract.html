    Optionalrequired

    required?: ModeContractRequired

    必备口（有序子集；缺省 = 内置默认，见 requiredInputsFor）。

    用 undefined 而不是空数组表达「没配过」：内置默认（提示词）与「用户 主动清空了必备口」是两个不同的状态，用空数组一锅端会让「我明明取消勾选了」 与「我还没配过」读起来一样。
