    Interface ParamEntry

    一个「对外参数」（= 契约里的一个统一口子，落到工作流的某个端口上）。

    id 是契约内的稳定键（prompt / size / first-frame…），不含工作流 信息 —— 同一个「提示词」在所有工作流里都是同一个键，落点由映射表决定。

    hostNodeId

    hostNodeId: string

    承载这个对外参数的宿主节点 id —— 库内映射线的宿主端与连线的合法性判定 都以它为准。

    契约路径下 nodeId 是空串（契约条目与工作流无关），但线仍要落在「这个口 真正落到的那一行所在的节点」上：此前各处一律读 nodeId，于是契约路径下 线指向空节点、连线闸门恒定失败 —— 用户表现为「对外参数端点拉不了线」。 宿主 id 从候选端口派生（落点所在节点优先，其次首个候选），是同一份事实的 最近可用近似。
