    OptionalhostNodeId

    hostNodeId?: string

    宿主（外层封装）节点 id，仅在「下钻到子工作流内部」勾选时写入。

    nodeId 此时是子图内部节点 id（1670），它在顶层画布上不存在；而运行期 comfy-cli 展开子图后的节点 id 是 4:1670（宿主 id + 内部 id 用 : 拼接）。 两个 id 都存下来，运行期就能确定性地还原拼接形式，不必靠「拿裸 id 去所有 子图定义里扫一遍」的巧合兜底 —— 后者在同名内部 id 或定义缺失时会静默失效 （表现为「改了参数没生效」）。顶层勾选的条目没有本字段。

    OptionalslotLabel

    slotLabel?: string

    本层槽位上作者写的业务名（与槽位名不同才有值）。

    富化链里它排在通用翻译（localized）之后，故不参与显示；但它是判定 「本地存的那串是不是机器生成的槽位名」的第二判据：富化名恰好停在槽位名 （value_1）时，只有它还能说明本层确实有作者命名。没有它，同名条目在 写入时会被当成作者命名固化回库，显示名随即退回别名（ISSUE #349）。
