    Optionalmirror

    mirror?: { error(msg: string, fields?: Record<string, unknown>): void }

    覆盖 ERROR 镜像的落盘目标（app-runtime 通道）。

    默认走全局 appRuntimeLog（真实 log/services/app-runtime.log）。 用例必须传自己的临时目录：镜像是一条真实写盘的副作用，不隔离就会 往开发者/CI 的 log/ 里写字（实测 pnpm test 会在仓库根新建 log/ 并写入 6 行，其中含被断言的「密钥原文」标记行）。

    Optionalns

    ns?: string

    绑定的命名空间（pino 的 bindings.ns）。

    核心层入口不带 server-only（它被纯 Node 宿主与 Next 服务端同时加载）， 它不能把命名空间塞进 every log call 的对象里，否则同一条日志的字段形状 会随调用方漂移。绑定一次、处处带上，是 pino 的标准做法（log.child({ ns })）。
