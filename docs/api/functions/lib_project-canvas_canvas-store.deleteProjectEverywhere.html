    Function deleteProjectEverywhere

    • deleteProjectEverywhere(id: string, name?: string): void

      删任何一行（含索引里没有、只在服务端的那一种）。

      与 deleteProject 的分工是判据而不是便利：deleteProject 的名字要在 索引里找，找不到就只剩「本机无操作」—— 服务端那一行留在原地、界面上 也没有别的入口（这正是 ISSUE #1522 问的那个口子）。这里反过来以 id 为准： 本机有就一并清（连带 active-id），服务端那份则照旧走 deleteProjectOnServer 那一条出口（失败按「重试有没有用」分两档处置）。

      name 由调用方给：索引里有就取索引的，索引里没有的那一行只有服务端给的 名字可作提示文案（SyncNotice.projectName 要的是用户认得出的那个词）。
