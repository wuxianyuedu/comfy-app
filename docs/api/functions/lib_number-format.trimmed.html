    Function trimmed

    • trimmed(value: number, digits: number): string | null

      按固定小数位写数，去掉末尾的零（1.00 → 1、0.50 → 0.5）。

      这是「精度是上限、不是形态」那一档：ComfyUI 与配置文件里存的就是 剥过零的形态（"1" / "0.85"），节点卡片与滑块读数要跟它一致， 否则同一个值在画布上一个样、在设置里另一个样。

      0 永远返回 "0"（不返回空串）："0.00" 剥完尾零会剩下 "0."， 再去点才是 "0" —— 少走一步就会渲染出一个空单元格。

      trimmed(1, 2)   // "1"
      trimmed(0.5, 2) // "0.5"
      trimmed(0, 2)   // "0"
      trimmed(2.345, 2) // "2.35"（先按两位舍入再剥零）

      • digits: number
