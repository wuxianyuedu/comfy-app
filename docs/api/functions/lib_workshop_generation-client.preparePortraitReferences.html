    Function preparePortraitReferences

    • preparePortraitReferences(
          characters: Character[],
          characterIds: readonly string[],
      ): Promise<{ failedCount: number; files: string[] }>

      收集镜头相关角色的已选定定妆照，上传进 ComfyUI 输入目录， 作为本次镜头生图的参考图（referenceImages 的值）。

      流程口径（docs/guides/feature-workshop-flow.md §4）：定妆照就是「后续分镜图 的参考图基准」。参考图口吃的是已上传文件的文件名，所以逐张经 prepareLocalInputImage 上传；单张失败不拖垮整次生成 —— 跳过并计入 failedCount，由调用方决定是否提示（降级不得静默，规范 10 §10.3.1）。

      顺序按 characterIds（分镜里的角色出场序）。内置默认契约只有两个参考图槽 （reference-image / -2），超过两张的定妆照落不进端口，这里截到两张、 不做无效上传。没有角色选了定妆照 → 空数组，调用方不给这个口。
