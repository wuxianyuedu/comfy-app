    Function pythonCandidates

    • pythonCandidates(platform?: Platform): string[]

      按平台给解释器候选名（只给名字，PATH 上找不找得到由 whichCommand 判）。

      顺序取自「哪个名字最可能真在那儿」，不是偏好： · Windows —— 官方安装器的落点是 python.exe；装了 Store 版时常常只有 py 启动器；python3 在 Windows 上多半只是个占位别名。因此把 py 排在 python3 之前，且判「可用」时它必须带 -3（裸 py 是「列出已装版本」并退非零）。 · POSIX —— python3 才是规范名（多数发行版没有裸 python），顺序相反。

      与 src/lib/comfyui/launch-path.ts 的 WIN32 / POSIX 候选不是同一件事： 那里解析的是 ComfyUI 自带环境的解释器（绝对路径，python_embeded/python.exe）， 这里解析的是宿主 PATH 上那个通用解释器（门禁自检、python -m comfy_cli）。 两者只是恰好共用「先 python3 还是先 python」这条常识。
