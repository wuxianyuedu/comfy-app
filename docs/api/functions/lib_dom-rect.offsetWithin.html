    Function offsetWithin

    • offsetWithin(
          inner: Element | null | undefined,
          outer: Element | null | undefined,
      ): number | null

      inner 相对 outer 的纵向偏移 —— 即「在 outer 的面板内容里的位置」。

      收口前这段算术写在 use-custom-nodes-settings 的滚动定位里，注释明确记着 不能用 inner.offsetTop（offsetParent 会回退到更高层的 fixed 包装， 得到乱值）。这里把正确的算式收一处：两个 rect 的 top 相减 + outer 自身的滚动偏移（外层已滚过一段时，相对内容的位置要把那段加回来）。

      任一侧量不到时返回 null（不返回 0 —— 0 是「就在顶部」，一个合法的位置）。
