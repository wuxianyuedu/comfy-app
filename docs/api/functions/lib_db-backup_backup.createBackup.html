      把库热备份到 data/backups/，并验产物真的能读通。

      用 VACUUM INTO：一条语句产出一致性单文件快照，不停应用、不带 -wal / -shm。 写在临时名上，验完再改名成最终名 —— 中途失败（磁盘满 / 库坏了）不会在 备份目录里留下一个「看着像备份、其实读不通」的文件：那正是台账里说的 「备份看着有了，真要恢复时那份已经坏了」，比没有备份更危险。

      成功返回 { ok: true, ... }；失败返回 { ok: false, reason } —— 不抛， 由调用方决定怎么说（硬规则 4：失败路径必须有日志 + 用户可见出口；备份失败 不该让同步本身崩掉，但也不能不声不响地跳过）。
