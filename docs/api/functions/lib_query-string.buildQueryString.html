    • buildQueryString(
          params: Record<string, QueryValue>,
          __namedParameters?: BuildQueryOptions,
      ): string

      一组键值 → 查询串（不带 前导 ?）。

      典型调用形态：可选参数直接写 undefined，出口会省略整个键（而不是写成 字符串 "undefined"）；数字 0 会被保留（它不是缺值）—— 这两条差别 就是收口前 URLSearchParams 与手拼模板串最大的分歧。 具体落点见 ~/lib/media/media-url 的 comfyImageUrl 与 ~/lib/log/log-file-client 的 fetchFileLogSlice。

      返回空串表示「一个参数都没有」—— 调用处据此决定要不要带 ?： `/api/x${qs ? `?${qs}` : ""}`。这条也收在 withQuery 里。
