    Function enqueueWorkflowTask

    • enqueueWorkflowTask(input: EnqueueTaskInput): Promise<EnqueuedTask>

      「从工作流库的某个模板入队一条任务」的唯一实现。

      为什么必须收在一处：这条链上有三道判据（模板存在性、可执行形状、执行宿主归属） 加一次 createQueued 与一次可选 kickQueue。它们散在路由里时，任何第二个调用方 （风格试验的批量、工坊的镜头重生成）要么照抄一遍（本仓 check-code-duplication 硬闸正是要拦这个），要么少抄一道——少抄的那道不会立刻报错，只会在 ComfyUI 侧变成一个跟入库处对不上的错误。

      ADR 口径（P3 §5 ADR §14 D1 第二刀）：提交只写库里那一行，派发动作不在这里。 队列只许有一份真相（库）；kickQueue() 只是省掉等 2s 节拍，行归对侧（host 片）时 它自然空转，不与 host 抢同一行（领取谓词是 impl 里唯一的 ownedBy()）。
