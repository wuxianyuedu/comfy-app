    • aspectLabelForDims(

          height: number,
          options?: readonly string[],

      宽高 → 某个 aspect_ratio 端口该写的候选值（工坊 / 画布派值用）。

      这类端口是 COMBO，写进去的值必须逐字命中它的 options（如 "16:9 (Widescreen)"）， 否则 ComfyUI 静默回落到第一个选项。因此：options 里有同比例的项就用它； 没有 options（IO 未富化）时按本模块的标准短标签给；相对差超过 2% 的面积 不算命中（如 1000x999 不该被写成 "16:9"）。
