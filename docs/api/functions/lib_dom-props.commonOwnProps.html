    • commonOwnProps<A extends string, B extends string>(
          a: readonly A[],
          b: readonly B[],
      ): (A & B)[]

      「自己的私有 prop 有哪些」的合并：基元同时扩展两类底层（如 img 与 video）时，两张表的交集才是该剔掉的（两个底层共同的字段）。

      单独给这个函数是因为「合并两张剔除表」这件事本身容易被写成 [...A, ...B]（并集）—— 那会把只属于其中一个底层的字段也剔掉， 于是那个底层再也拿不到它该有的属性，且没有报错。

      // 两张表取交集：只有两边都列出的字段才该被剔
      commonOwnProps(["src", "alt"], ["src", "poster"]); // 只给 "src"
