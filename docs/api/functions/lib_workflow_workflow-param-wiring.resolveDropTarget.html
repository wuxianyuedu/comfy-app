    Function resolveDropTarget

    • resolveDropTarget(
          point: { x: number; y: number },
          candidates: readonly { ioKey: string; rect: DOMRectLike }[],
      ): string | null

      拖线落点解析：一次拖拽在某个位置松开时，命中的宿主落点 ioKey（null = 没落上）。

      画布上这件事由 React Flow 的 isValidConnection + onConnect 承担，库内那层 也是 React Flow（ISSUE #529）—— 两边共用同一个闸门判据，不存在「同一个手势在 两个界面一个受理、一个拒绝」的余地。本函数保留给非 React Flow 的落点命中场景 （如按坐标判定「松手处是哪一格」）。

      candidates 由调用方给（本轮渲染真的画出来的落点行/控件）。命中时取最小的 那个矩形：端点圆点（data-port-dot，12px）比整行、比组合控件都小，于是 「精确落在圆点上」永远胜过「大致落在行里」。都没命中（拖到空白处）返回 null， 调用方据此不改动任何映射，不留悬空线。

      point 与 candidates[].rect 必须在同一个坐标系里：库内画布是可缩放 视口，调用方要么两边都取屏幕坐标，要么两边都换算回容器局部坐标 —— 一边屏幕 一边局部，缩放不是 100% 时命中判定会整片偏移（拖到圆点上却落不上，或落在 隔壁行上）。容差随坐标系由调用方按需缩放，这里不做二次换算。
