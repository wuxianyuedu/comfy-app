    • buildInnerNodeInputs(raw: RawWorkflow | null): Record<string, RawInputEntry[]>

      子工作流内部节点的输入元数据索引（nodeId → raw 条目）。

      buildRawInputs 只走顶层 raw.nodes，子图定义里的内部节点不在其中。 当用户「下钻到子工作流内部」勾选参数时，落库的 nodeId 指向的是内部节点 （如 PrimitiveInt.value），顶层富化按 id 回查必然落空 —— 类型退化成 *、 显示名退化成 pin 名（ISSUE #349：IO 编辑里 seed 显示成别名/原始键）。 这里把每个子图定义的内部节点输入打平索引，供富化在顶层找不到时兜底。

      键是内部节点 id 的字符串形式；同名节点在多个子图定义里重复出现时后者覆盖 （ComfyUI 内部节点 id 在工作流内唯一，实际不会冲突）。
