      一个对外参数卡片的输出端口（一个口一颗点）。

      卡片只说「这个口对外是什么」（名字 + 类型），落点由线的另一端声明 —— 拖 这颗点连到宿主的哪一行，这个口就落到哪一行。与尺寸卡「一行 = 一个形态，落点 由另一端声明」同构。

      早前这里是「每个候选落点一颗点」（未连线时逐候选列行）：那只在「尺寸」还是 一个聚合条目时成立（候选是宽 / 高 / 比例 / 像素量这些语义不同的行，作者要 在卡片上挑）；尺寸摊成六个子口之后，普通卡逐候选摆点只会把同一族的行重复列 一遍，还把 handle id 撞成一堆同名点（用户口径：「提示词不是就应该有一个输出端 口吗，每个候选落点一颗有什么意义」）。

      handleId = 条目 id：一卡一颗点，条目 id 在同一画布节点内天然唯一（尺寸卡 的六行各是子口 id，同样唯一）；落点不再需要由 handle id 携带。

      Parameters

      • entry: ParamEntry
      • io: WorkflowIOMap | null | undefined
      • resolvedTarget: string | null | undefined
      • OptionaldisplayName: string

        行上显示的对外参数名。给的是调用方那一份（卡片列会先用契约口清单的 展示名覆盖 entry.label，见 ISSUE #596）—— 两处各取一份会让同一张卡片的 标题与端口行说两个名字。缺省 = entry.label。

      Returns ParamOutputPort[]
