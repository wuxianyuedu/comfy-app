    Function hydrateProjectFromServer

    • hydrateProjectFromServer(id: string): Promise<CanvasProject | null>

      把一条服务端项目行拉进本地索引，并落盘。

      为什么需要它：界面能看见项目，不等于本机能打开它。侧栏与「所有项目」那一屏 读的是并集（listProjectsWithServer），于是「服务端有一行、索引里没有」 的项目看是看得见的；而打开它的一跳读的是 getProject(id)（索引）， 索引里没有 ⇒ 拿到 null ⇒ 闸门照旧弹「先创建或选择一个项目」 （ISSUE #1874：列表里明明点得着，点进去让用户再建一个）。

      判据是「这条是谁的」：索引里有 ⇒ 本机本来就能打开，不碰网络、不写盘 （每次点开项目都发一次请求是另一码事）；索引里没有 ⇒ 这一份此前从来不在 本机，必须先把服务端那一行落下来，getProject(id) 才有东西可交。

      拉不到 / 服务端说没有这一行 ⇒ 交回 null，调用方照旧走「没有这个项目」那条 出口（渲染闸门），不抛：这里在 onClick 里，抛出去就是一句没人接的 unhandled rejection。失败同样不是无声的（硬规则 4）——走 sync-notice 那一条诊断口，本文件不许自己写 console。

      • id: string
