    Function generatedRoot

    • generatedRoot(cwd?: string): string

      产物根：<cwd>/generated，也就是 /api/generated/[...path] 服务的那一层。

      为什么不在 public/ 下（台账 A13 的结构性关法）：public/** 由 Next 按静态文件 直接发出，不经过任何 route handler。产物一旦落在那儿，闸装在 handler 上就等于没装 —— 实测过同一份图 /generated/<tid>/img_0.png 回 200 原图、/api/generated/… 回 401， 唯一的补法是把前缀 rewrite 进 /api/…（src/proxy.ts），而那条又依赖 config.matcher 记得把每个带扩展名的形状列全（漏一个就是「一行代码不动、判据零执行、 零报错」）。根放在 public/ 之外之后，这条静态通道不存在，判据只剩 route 一处。

      顺带关掉一条分发卫生账：build-desktop.mjs 无 filter 整树拷 public/**， 而产物层的顶层名单是默认拒绝（STANDALONE_ALLOWED_TOPLEVEL / STATIC_ALLOWED_TOPLEVEL 里都没有 generated）—— 所以这一层不管带着什么都不进包， 也不必为它新增任何放行条目（规范 launch-and-build §7.3）。

      URL 前缀（ARTIFACT_URL_PREFIX）与磁盘根是两件事：库里存的正是前者 （TaskImage.localPath / Film.localPath），所以搬根不动 URL，历史行照常读得到。
