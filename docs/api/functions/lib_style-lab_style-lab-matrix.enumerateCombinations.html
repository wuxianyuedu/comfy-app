    Function enumerateCombinations

    • enumerateCombinations(traits: StyleLabTraits): Record<string, string>[]

      枚举全部组合：返回 Record<维度 id, 选中值>[]（按 traits 的键序展开）。

      「不约束」的那一维在结果里落成空串 "" —— 它是「这一维不进入提示词」的显式标记， 而不是「这一维不存在」（键一直在，值可空），下游拼提示词据此判断要不要带这一段。

      结果长度恒等于 combinationCount 的返回值：这两条判据必须对得上，否则界面上 「K 格」与真正会展开出来的清单会各报一个数（同一个形状写两处就会漂）。
