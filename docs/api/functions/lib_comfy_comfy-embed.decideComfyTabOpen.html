    Function decideComfyTabOpen

    • decideComfyTabOpen(embeddable: boolean): ComfyTabTarget

      打开 ComfyUI 的目标判决。

      只有两档，且都留在应用内（ISSUE #310 用户明确要求：「不要打开另一个 窗口，我只要多页签的形式」）：

      • 可嵌 → 直接内嵌进页签；
      • 不可嵌 → 同样把页签打开，但里面渲染一张应用内的可见说明（给出 成因与修复动作），而不是弹第二个窗口、也不是把浏览器的空白错误页 摆给用户。

      为什么删掉了「壳内独立窗口」这一档：那是绕开 ComfyUI 跨源 403 的兜底， 而那个开关其实握在我们手里（启动时带 --enable-cors-header，见 lifecycle-derive.ts 的 withEmbedClearanceFlag）。绕道的代价是用户 每点一次都多出一个窗口，体验与「像文件管理器那样多页签」的目标相悖。 保留的 blocked 档只用于「外部实例不受本应用参数控制」这类边缘情形， 且仍在同一个窗口里给出可读的下一步。

      注：早先还有 browser（系统浏览器）一档。它作为这条决策路径的自动回落 已被删除（「点打开查看就跳浏览器」同样把用户从多页签形态里踢出去），但 「在浏览器打开」作为用户主动点击的并列出口保留在设置页 （setting.comfyOpen，见 docs/standards/12-代码组织与文件结构.md §12.8.3）。

      Parameters

      • embeddable: boolean

        探测结论：能否内嵌
