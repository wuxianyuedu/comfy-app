    Function batchBaseSeed

    • batchBaseSeed(params: Record<string, unknown>): number

      这一批的基准 seed。

      每批只定一次（不是每格定一次）：这一屏的缺省语义是「整批共用一枚、只让风格与 特征变」（见 cellTaskSeed），在格内现算就成了「每格各随机一次」，那恰好 把要控制的变量放掉了。快照里没存 seed（或存的不是有限数）时随机定一枚 —— 与工坊 那侧「空值 ⇒ 每次新的随机 seed」的口径一致（randomSeed() 是全库唯一的随机 seed 出口）；定出来这一次整批复用，所以「同一批里两次调用拿到同一个值」是用例之一。
