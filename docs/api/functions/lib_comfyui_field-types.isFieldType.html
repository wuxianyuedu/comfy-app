    • isFieldType(value: unknown): value is FieldType

      FieldType 的运行时守卫。

      manifest（外部 JSON）里的 widget 标记是不受约束的字符串，落成 FieldDef.type 之前必须收窄。此前调用点写 x as FieldType || "string"： as 一句断言就把「manifest 里塞了不认识的值」变成 FieldDef 上那个 不存在的 type，一路传到渲染层才炸（.tsx 里既没有 as 可归因， 也看不出它来自外部输入）。守卫把收窄与兜底收在一处，认不出即「不是控件 类型」，由调用方决定退成什么。
