    Function cellTraitKey

    • cellTraitKey(combo: Record<string, string>): string

      一组的特征键 —— 这一格在库里的身份，不是给人读的那句文案。

      为什么带轴 id（costume=汉服;temperament=清冷）而不是只拼取值：重跑一批要按这个键 判「这一格是不是已经跑过」。只取值时，一旦两个特征维度出现同一个词（四轴今天的 词表互不重字，将来加词并不保证），两格会撞成同一个键 —— 表现是矩阵静默少出 一张图，而界面上「N 风格 × M 特征 = K 格」那句仍照算式报 K。身份键必须按构造 唯一；「这句怎么显示」是另一件事，由视图层的 traitKeyDisplayText 现推。

      分隔符取 ; 与 =：实测本仓四轴词表里没有任何取值含这两个字符（真引入了也不影响 键的唯一性，只是展示那一列会多出一个分号）。不约束的维度整对省略，全空 ⇒ ""。
