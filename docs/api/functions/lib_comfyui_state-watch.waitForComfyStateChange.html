    • waitForComfyStateChange(
          since: number,
          timeoutMs: number,
      ): Promise<ComfyStateChange | null>

      等一次变化（长轮询的等待侧）。

      timeoutMs 到了就返回 null —— 调用方据此回一个空的 204 并重新发起 下一轮，而不是把连接一直挂着（挂死的连接在代理 / 系统休眠之后不会自愈， 而「重发一次」的成本是零）。since 已经是旧值（在订阅之前就变过了）时 立即返回，不然客户端会白等满一个超时窗口才知道自己错过了。
