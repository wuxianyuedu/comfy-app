    Function runtimeNodeId

    • runtimeNodeId(entry: { hostNodeId?: string; nodeId: string }): string

      运行期节点 id：库内 nodeId 是「勾选所在视图的节点 id」。

      · 顶层勾选：nodeId 就是顶层节点 id（4），原样下发； · 子图内部勾选：nodeId 是内部节点 id（1670），而 comfy-cli 展开子图后 真实节点 id 是宿主 id + 内部 id 的拼接（4:1670）——此时用落库的 hostNodeId 拼出 host:inner。

      之所以要把宿主 id 一起存下来，而不是运行期「拿裸 id 去所有子图定义里扫 一遍」：后者在同名内部 id 或子图定义缺失时会静默失效（表现为「改了参数 没生效」），拼出来的 id 才是确定性事实。
