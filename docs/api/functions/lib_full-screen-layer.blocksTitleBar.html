    Function blocksTitleBar

    • blocksTitleBar(className: string): boolean

      顶层浮层的判定：fixed inset-0 开头的 class 串。

      「顶层」= 只有定位（fixed）与铺满（inset-0）两类声明、其后接的仍是 class 单词（z-index / flex / 颜色…），不含 absolute / relative 等 局部定位，也不含 size-* / w-* 这类「另给尺寸」的写法。

      为什么要把「固定元素 = 顶层浮层」划在 src/components/**、src/app/**： 底层 app shell 的 fixed 元素（如状态栏 bottom-0）不在选择器内； 非 fixed 的 inset-0 只铺自己的定位祖先，不受标题行约束。

      Parameters

      • className: string

        组件上的完整 class 串（模板串请传拼好的结果）

      Returns boolean
