    Function startComfyExitWatcher

    • startComfyExitWatcher(deps: ComfyExitWatcherDeps): { stop: () => void }

      轮询进程表，发现「跑着 main.py 的进程」消失时报一次退出。

      保活模式没有子进程句柄（见文件头第 2 条），这是唯一能拿到退出时刻的途径。 它回答的是「什么时候没的、活了多久」，拿不到退出码 —— 那件事由 describeComfyExit 如实讲明，而不是编一个 code。

      Parameters

      • deps: ComfyExitWatcherDeps

      Returns { stop: () => void }

      { stop }：宿主在「用户主动关」或「重新拉起」时必须调用，否则监督器 会把下一次拉起当成「上一次还在跑」。
