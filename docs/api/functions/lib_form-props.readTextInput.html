    Function readTextInput

    • readTextInput(event: ValueEvent, onValue: ValueHandler<string>): void

      就地取值：把事件里的值交给回调，返回 void。

      给那些「必须在同一个事件里做别的事」的落点用 —— 例如输入框要在 change 里读 scrollHeight 调整高度，不能把整个 onChange 换成 textHandler(...)。

      用法：在 onChange 里先 readTextInput(event, setInput)， 再继续用同一个 event 做别的事（例如重设 event.target.style.height）。

      与 textHandler 共用「取值只有一处」的口径：这条路径读的也是 target.value，没有第二份取法可言。
