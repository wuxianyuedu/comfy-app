    Function clamp

    • clamp(value: number, min: number, max: number): number

      把 value 夹进 [min, max]。

      NaN 返回 min —— 这是本条账唯一需要说清的一句：Math.max(0, NaN) 是 NaN，而 NaN 交给 style={{ width: NaN }} 是无效值、交给数据库是 null、交给 Math.round 还是 NaN，它会在整条链路上静默地传播下去。 夹取的语义是「给我一个落在这个区间里的数」，算不出来时给区间起点， 比给 NaN 诚实。

      ±Infinity 则按大小夹取（Infinity 显然大于任何上限）：它不是 「算不出来」，而是一个明确大了 / 小了的数 —— 与 NaN 分两种处理。

      clamp(120, 0, 100)  // 100
      clamp(-3, 0, 100)   // 0
      clamp(42, 0, 100)   // 42
      clamp(NaN, 0, 100)  // 0
      clamp(Infinity, 0, 100) // 100

      区间本身不做校验（min > max 时结果落在 min）：那是调用处的常量写错， 在这里悄悄换序只会把错误藏起来。测试里钉住了这一条。
