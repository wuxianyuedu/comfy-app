    Function normalizeKeyName

    • normalizeKeyName(key: string): string

      把「一个键的名字」归一成只用于比较的形态。

      规则（三条，都可单测）：

      1. 空格归一："Space" 与 " " 是同一个键的两种叫法 → "space"；
      2. 小写归一："Enter" / "ENTER" / 带 Shift 的 "A" → 小写 —— 这是唯一能同时容纳「具名键」与「单字符键」的判据；
      3. 单字符保留原形（只做小写）：" " 这类字符不 trim() （trim() 会把它变成空串，再与「空 key」撞在一起）。

      ⚠️ 只用于比较，不要拿它去显示 —— 展示给用户的键名走 KEY 的具名值。
