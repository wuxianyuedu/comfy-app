    Function deriveComfyuiSubdir

    • deriveComfyuiSubdir(
          comfyuiPath: string,
          subdir: "custom_nodes" | "workflows",
      ): string | null

      从 comfyuiPath 推导 ComfyUI 安装内的只读资源目录（custom_nodes / workflows）。 兼容「comfyuiPath = 源码根」与「comfyuiPath = 桌面实例根（main.py 在 ComfyUI/ 子目录）」两种配置：两处都查 custom_nodes / workflows 所在位置。 找不到时返回 null —— 调用方自行降级（不弹错，只是没有本地工作流/节点可扫）。

      放在本文件是因为判据是目录存在性（existsSync / statSync）：它看起来是 「字符串推导」，实际是一次 fs 探测，留在纯模块里会让纯模块重新带上 fs。

      Parameters

      • comfyuiPath: string
      • subdir: "custom_nodes" | "workflows"

      Returns string | null
