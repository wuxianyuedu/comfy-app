    Function formatClock

    • formatClock(value: TimeInput, opts?: { millis?: boolean }): string

      时刻 → HH:mm:ss（millis 时带 .SSS）。入参与 timeAgo 同口径： 毫秒数或 ISO 串，调用处不必自己 new Date(...)。

      固定 zh-CN + hour12: false：此前 workshop 那几处裸调 toLocaleTimeString()，输出随宿主区域设置变化（本机 12 小时制时会多出 AM/PM 把紧凑的日志行撑开）。

      「跨天时补 MM-DD 前缀」是另一件事，留在 logs/log-format.ts 的 formatTime（它带同天判定）。本函数只负责时刻本身。
