    Function copyText

    • copyText(text: string): Promise<boolean>

      把文本写进剪贴板，返回是否成功。

      两条通道依次尝试：Clipboard API → 临时 <textarea> + execCommand。 后者是非安全上下文 / 权限被拒时的兜底（Clipboard API 在这两种情况下 直接抛错，而 execCommand 仍可能在用户手势里生效）。

      为什么返回 boolean 而不是静默：调用方要据此给出反馈（「已复制」或 「复制失败」），静默的那一份会让「没粘出内容」看起来像应用坏了。不需要 反馈时调用方自己丢弃返回值即可。

      注意 document.execCommand 已废弃但必须保留：它是唯一在 Tauri 的 http:// 非安全上下文里还能工作的通道。
