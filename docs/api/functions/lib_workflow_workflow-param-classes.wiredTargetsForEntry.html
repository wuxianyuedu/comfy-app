    Function wiredTargetsForEntry

    • wiredTargetsForEntry(
          args: { target: string | null | undefined },
      ): { active: boolean; ioKey: string }[]

      一个对外参数当前接到哪个端口 —— 只报作者连上的那一条。

      为什么不是「一对多」：候选是按类型收来的（一族一份，见 pinFamily）， 同族几个口子的候选集合互相重叠（每个数值行都是「尺寸 · 宽」的候选）。逐条 列出来会让一张卡画出十来条线，还把兄弟口子的落点在图上画到这个口名下。 「尺寸 · 宽高比」连的是哪一行，只由它自己那一条线说。

      这与「候选圆点照给」是两件事：圆点给全部候选（作者要能拖，见 paramOutputPorts），线只画连上的那条。

      落点只能来自作者画的线（没有线就没有落点，见 resolveMapping）；没有 落点就报空（未配置，如实呈现）。

      active 标出「作者连上的那个」，供卡片上的实心圆点使用。

      Parameters

        • target: string | null | undefined

          当前模式下这个条目的落点（resolveMapping 的结果；null = 未连线/断开）。
