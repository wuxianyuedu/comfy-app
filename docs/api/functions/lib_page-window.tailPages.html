    Function tailPages

    • tailPages<T>(items: readonly T[], page: number, pageSize: number): PageWindow<T>

      倒序分页：第 1 页是列表末尾的一段（最新的一段），页码越大越靠前。

      日志面板用它：读日志的习惯是「先看最新的」，往前翻才是看历史。 分页在过滤后的时间线上做，所以「最新一页」恒为 page === 1。

      页码越界时钳回（不是返回空页）：用户在 3 页时把日志清到只剩 1 页， 期望的是落回末页那一档，而不是看到一片空白。
