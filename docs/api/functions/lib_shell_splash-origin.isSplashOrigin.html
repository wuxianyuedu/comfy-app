    Function isSplashOrigin

    • isSplashOrigin(origin: string | null): origin is string

      请求的 Origin 是不是启动页那一族；不是（含缺头、null、别的网站）回 false。

      不匹配就一个 CORS 头都不回（而不是回一个别的值）：浏览器于是按同源策略拒绝， 这正是我们要的结果 —— 恶意网页读不到响应体，而启动页在白名单里照常读得到。

      写成类型谓词（而不是 boolean）是为了让调用点少一次断言：断言形态是 「同一件事用两次」（判过一遍，再告诉类型系统「我判过了」），而两次之间任何改动 都可能让它们分叉 —— 收在本仓库的门禁 check-non-null-assertions.cjs 里。
