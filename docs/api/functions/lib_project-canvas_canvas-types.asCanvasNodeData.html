    Function asCanvasNodeData

    • asCanvasNodeData(data: unknown): StrictCanvasNodeData

      把 ReactFlow 上的 node.data（兼容面）收口成严格声明。

      为什么需要它：Node<CanvasNodeData> 的 data 类型仍是宽索引面，直接读 node.data.prompt 会得到 unknown。过去各文件用 as unknown as NodeData 各自绕开——断言散落、改字段无人发现。这里集中一处收口：

      • 输入是运行时真实数据（ReactFlow 给的对象），断言在此是唯一的；
      • 输出是严格类型，下游字段访问全部受类型检查保护。

      收口不做运行时校验（画布数据由本应用写入、结构自持），因此单点断言是 恰当的成本——继续保留零散断言才是问题。

      • data: unknown

      Returns StrictCanvasNodeData
