    Function executableKind

    • executableKind(candidate: string): ExecutableKind

      读文件头几个字节而不是看扩展名 —— Windows 上 .CMD 与 pnpm（shim）后缀 不同但内容形态更要紧，而扩展名只是给 shell 看的。 · shebang —— 以 #! 开头（corepack 的无扩展名 shim 就是）；Node 起不了 （libuv 不解析 shebang），usableCommand() 走同目录回退； · batch —— 批处理（@echo / @setlocal 起头，.cmd / .bat）； Node 同样起不了（只有 cmd.exe 会解释它），照旧走回退 —— 把两者混成 script 曾让 .CMD 被当成「可用」而选中， 真跑起来是 EINVAL（ISSUE #576 第二轮现场）； · script —— 其余文本脚本（.ps1 等），由各自的宿主解释； · binary —— 二进制（.exe / .com），CreateProcess 能直接起； · unknown —— 读不到或形态判不出，按可执行形态处理（交给 spawn 决定）。
