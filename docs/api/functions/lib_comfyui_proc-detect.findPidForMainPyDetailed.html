    Function findPidForMainPyDetailed

    • findPidForMainPyDetailed(mainPy: string): Promise<PidLookup>

      findPidForMainPy 的区分版：把「确认不存在」（failed=false, pid=null）与 「查询失败」（failed=true）分开。

      背景：不带结果的版本把 execFile 错误（含 10s 超时）静默成空串，上层只看到 「没找到进程」。ComfyUI 启动初期机器高负载（CUDA 初始化 / 大量 IO）时 PowerShell 查询很容易超时，把正在启动的实例误判成「没有在运行」， probeComfyUi 随之整体跳过 HTTP 探测——设置页状态行显示「未运行」， 但进程和端口都活着（ISSUE #114：点「打开查看」后状态回退）。
