    Function idleFallback

    • idleFallback(phase?: LaunchPhase, root?: string): LaunchFallback

      壳接手那一刻的常驻快照。

      它替代的是「编排器还没写 = 什么都没有」：启动页读到 fallback 标记就知道 这是壳的快照（不是权威进度），既能显示「壳在做什么」，也能在编排器卡死时 从快照里读出它本来要起什么、日志会写在哪。

      快照必须自带 diagnostics（与 no_status_payload 同形）：编排器一旦写 自己的 launch-status.json，这份快照就被整份顶掉（它不带 diagnostics）， 而它写第一份日志之前磁盘上恰恰什么都没有 —— 那段窗口期里启动页能拿到的 现场只有这份快照里的路径与启动报告（ISSUE #784 手验反馈）。

      Parameters

      • phase: LaunchPhase = "shell-prepare"
      • root: string = ""

      Returns LaunchFallback
