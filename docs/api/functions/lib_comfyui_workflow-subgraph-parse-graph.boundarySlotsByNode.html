    • boundarySlotsByNode(
          boundaryLinkInfoById: Record<number, BoundaryLinkInfo>,
      ): Record<string, number[]>

      按节点归拢「被哨兵边实际关联的槽位」——这是下标口径的唯一权威事实。

      ComfyUI 在不同导出路径上给出的「槽位」下标口径并不一致：有的写它在内层节点 inputs[] 里的下标，有的写控件序号（把 model/negative 这类纯连接口排除 在外，target_slot 于是会超出 inputs[] 的长度）。边界连线的 handle id 必须落在 真的挂载了 Handle 的那一行上，否则 React Flow 找不到锚点、整条边被丢弃并打 error#008 —— 用户看到的是「这个暴露口从来没连上」。

      所以不猜口径，而是把「ComfyUI 实际关联的那个槽位」记下来交给 parseSubgraphSlots 解析：-10 哨兵边的目标槽位就是内层消费节点的输入槽， 槽位名与「哪一行真的有边」于是永远同源。
