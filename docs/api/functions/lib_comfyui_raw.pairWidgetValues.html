    Function pairWidgetValues

    • pairWidgetValues(
          inputs: { name?: string; type?: string; widget?: { name?: string } }[],
          widgetsValues: unknown[],
      ): Record<string, unknown>

      把节点的 raw inputs[]（每项带 widget: {name}，且可能带 type）与 widgets_values[] 按名字配对，自动跳过 ComfyUI 在 seed 类 INT 控件后 插入的 control_after_generate 哨兵槽。

      ComfyUI 序列化时哨兵紧跟在 seed 值之后，因此 widgets_values 比 widget 输入列表多一格——朴素的下标配对（input i → widgets_values[i]）会让 seed 之后的每个控件整体错位一位。这里复刻 resolveWidgetOrder 的哨兵插入逻辑， 使下标与磁盘上的顺序严格对齐。

      返回 widgetName → value 映射；供画布展示用的 raw_inputs 配对（父子图 两个 route 共用），避免重复实现导致再次错位。
