    Function textHandler

    • textHandler(onValue: ValueHandler<string>): (event: ValueEvent) => void

      文本类控件（input[type=text] / textarea / select）的 onChange 适配器。

      用法：<input value={q} onChange={textHandler(setQ)} />； 要就地改写对象则 onChange={textHandler((name) => patch({ name }))}。

      transform 是显式的：过滤 / 限长这类转换写在调用处、以具名函数传入， 而不是塞进箭头函数体 —— 同一件事就不再有两处各自实现的机会。

      两条重载的意义：T = string 时可以省 transform（取到的原值就是最终值）； T 是别的类型时必须显式给 —— 早期单签 + transform = (raw) => raw as unknown as T 的默认值，会让 textHandler<number>(cb) 忘记传 transform 时把 "42" 的字符串 原文交给 (value: number) => void 的回调：TypeScript 看不出、运行时下游 Number.isFinite(str) 一律 false 走 fallback、或者直接落库变字符串。 「值转换是可选的」在这个模块的定位（全库唯一 props 适配器出口）里就是谎言， 现在把它从类型契约上就掐掉。
