    Function toDisplayPath

    • toDisplayPath(raw: string | null | undefined, base?: string | null): string

      把一段路径的相对部分与分隔符一次归一成展示形态。

      • base 给了就取相对它的一截（拿不到相对关系时原样返回，不抛 —— 展示层不该因为「这台机器上两者不同源」而炸）；
      • 反斜杠一律换成正斜杠（/）：界面上的这行文本会被用户复制到终端 / URL / vscode://file/ 里去用，\ 在那一侧是转义符而不是分隔符；
      • 前导 ./ 一并剥掉（path.relative 在同一目录下会给 ""， 在子目录下不会给 ./，但调用处传进来的可能带）。

      不在这里限制长度 —— 上限是调用处的域决定（日志面板与包卡片的宽度不同）， 要截就先 ellipsisMiddle 或 lastSegments。

      // 相对某个根：给相对那一段，分隔符归一
      toDisplayPath("F:\\AI\\ComfyApp\\log\\exports\\a.txt", "F:\\AI\\ComfyApp"); // 相对根
      // 不给根：只归一分隔符
      toDisplayPath("src/components/studio/x.tsx"); // 结果同原串的正斜杠形态
