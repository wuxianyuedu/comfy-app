    Function applyApiOverrides

    • applyApiOverrides(graph: unknown, overrides?: RawWorkflowOverride[]): JsonRecord

      尽力把画布的 workflowInputs 注入到 API 格式 的图里。

      与 applyRawOverrides 同一套语义（(nodeId, name, value) 覆盖项、 数值收窄、control_after_generate=randomize 兜底铸新种子），差别只在落点： API 图的 inputs 是命名 map，按名字直接写即可，没有下标可错位。

      control_after_generate 不入载荷：它是 ComfyUI 前端的控件概念，后端 /prompt 不认（前端在序列化 prompt 时把它解析成具体 seed）。所以这里先把它 从入参里摘掉，再按模式处理 seed —— randomize 铸一个新种子写给 seed 入参 （与 raw 路径在「没有哨兵槽」时的做法一致），其余模式保持 seed 原值。

      图本身不变（不修改入参对象），返回一份深拷贝。

      • graph: unknown
      • Optionaloverrides: RawWorkflowOverride[]
