    Function formatDate

    • formatDate(value: TimeInput): string

      日期 → YYYY-MM-DD（只写日期那一档）。

      三处同形（history-utils 的日期桶 / MessageCenterPanel 的消息时刻 / generation-log 的按天文件名）此前各拼一遍 —— 而它们的分隔符恰好都是 半角连字符，说明这三个落点本来就该是同一件事（不是「碰巧一样」）。

      用本地时间：这些落点全是给本机用户看的（日期桶要与用户所在时区的 「今天」对齐、按天文件名要与用户当天看到的一致）。toISOString() 是 UTC， 在 +8 时区会把凌晨归到前一天。
