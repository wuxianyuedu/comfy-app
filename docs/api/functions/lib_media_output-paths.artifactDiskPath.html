    Function artifactDiskPath

    • artifactDiskPath(url: string, root?: string): string | null

      「地址 → 磁盘绝对路径」的唯一映射。两种形状都吃：写侧的 /api/generated/… 与静态直发时代留在老数据里的 /generated/…。

      返回 null 的两种情况由调用点各自处置（口径同 taskOutputDir()：判据只写一份、 处置留在调用点）：「这根本不是产物地址」与「解出来的位置在产物根之外」。

      剥 api/ 那一段是这条判据存在的理由：compose-steps.ts 曾只剥前导斜杠， 于是执行器写进 TaskImage.localPath 的 /api/generated/… 被解析成 public/api/generated/…（该目录不存在），ffmpeg 每次都报「没有这个文件」， 「合成成片」对每一条镜头必败。

      百分号编码：地址由请求方/画布数据给，坏编码不是越权，但也不能顺着半截字符串 去读盘 —— 判成「不是产物地址」。path.resolve 会把以 / 开头的残留段当绝对路径， 那种位置一定在根外，因此同样落到 null。
