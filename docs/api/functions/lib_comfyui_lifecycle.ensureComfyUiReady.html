      确保 ComfyUI 可用：可达则直接返回；不可达且配置了路径 + 自动启动时， 拉起进程并轮询等待就绪。单飞锁保证并发任务/WS 重连只触发一次启动。

      等待时长：opts.timeoutMs 缺省（undefined / null）= 不设硬超时，一直 等到就绪或进程退出——冷加载（重安装 / CUDA 初始化）慢起来没有准数，固定 上限会在 ComfyUI 随后就绪时误报「启动超时」。设置页手动启动走无限等待 （实时日志可见、可随时手动关闭中止）；任务自动启动路径必须显式传 COMFYUI_AUTOSTART_TIMEOUT_MS，否则 reaper 的启动窗口会被无限拉长。
