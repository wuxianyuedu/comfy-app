    Function upperToken

    • upperToken(value: unknown): string

      归一外来串为大写记号：缺省给空串、吃前后空白。

      upperToken(" script ")   // "SCRIPT"（吃空白）
      upperToken("")           // ""（缺省给空串）
      upperToken(null)         // ""（同上）
      upperToken(undefined)    // ""（同上）

      想「缺省给放开记号 *」的调用处用 upperTokenOr —— 那是个域决定（* 意味着「类型未知、不替作者做决定」）， 不该变成全库默认。
