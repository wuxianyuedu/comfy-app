      把一条会话边界横幅追加进指定日志文件（唯一 IO 出口）。

      目录不存在时自动建（与各 runtime 的 appendRuntimeLog 同口径）；任何 失败都静默吞掉——日志写不进去不该把启动/停止流程带崩。

      Parameters

      • filePath: string

        目标日志文件的绝对路径，一律取自 log-paths.ts

      • kind: SessionBannerKind

        横幅类型（start 表示启动，end 表示停止）

      • title: string

        横幅中间的信息行

      Returns void
