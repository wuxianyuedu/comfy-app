      把「服务端 / 更新器返回的任意形状」归一成 ExternalOpenResult。

      归一而不是要求各家改形状：那三个端点的返回形状有自己的语义 （triggered 表达的是「安装已触发、应用要重启了」，与「成功」不是同一个 概念），改它们的代价大于在这里收一次。
