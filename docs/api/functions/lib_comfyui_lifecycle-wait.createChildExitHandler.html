    • createChildExitHandler(
          deps: ChildExitDeps,
      ): (code: number | null, signal: Signals | null) => void

      构造 child.on("exit") 回调：判「为什么退出」→ 落横幅 + [exit] 两行 → 清句柄。

      signal 是这次补上的：此前回调只接 code，于是「被 SIGKILL 强杀」与 「自己 exit 1」在日志里长得一模一样 —— 而前者是外部动作（任务管理器 / Job Object 关闭 / OOM 杀手），后者是它自己的异常，排查方向完全相反。

      依赖显式传参后可直接单测，不必起真进程。
