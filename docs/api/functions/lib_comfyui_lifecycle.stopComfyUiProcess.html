    Function stopComfyUiProcess

    • stopComfyUiProcess(): Promise<{ detail: string; ok: boolean }>

      关闭 ComfyUI：杀整棵进程树。 Windows 走 taskkill /PID <pid> /T /F（cmd 外壳死了不杀子进程会留下 python 孤儿锁住端口与日志文件）；POSIX 由 killProcessTree 向进程组 发信号（拿不到组时单杀兜底），两条路径都收在 ~/lib/process/kill-process-tree。

      两种来源都能关：

      • bound（默认）：本进程持着子进程句柄 st.child，直接以其 PID 杀树；
      • keepAlive / 重启后接管：本进程没有 st.child（保活实例是 Start-Process 中介拉起的孙进程 / 上一会话遗留的孤儿），改按配置路径的 main.py 在 OS 进程表里定位 PID 再杀树——否则用户点「关闭」只会得到 「不是本应用启动的」而永远关不掉上一会话保活下来的 ComfyUI（ISSUE #100）。

      Returns Promise<{ detail: string; ok: boolean }>
