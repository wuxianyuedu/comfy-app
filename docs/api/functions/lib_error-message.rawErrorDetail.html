    Function rawErrorDetail

    • rawErrorDetail(e: unknown, maxLen?: number): string

      从 unknown 抛值里取出原始报错详情（给日志/「完整错误」区用，不翻译）。

      与 errorMessage 的分工：errorMessage 产出给人看的可读文案 （把「Unexpected token '<'」这类无信息量的原文换成人话），本函数产出 给排查用的原文——tRPC 的 code / 服务端 message / stack 首行。 两者都落进 app-runtime 日志：前者进消息，后者进 raw 字段。没有它时， 面板里只剩翻译后的文案，服务端真实报错（如 no such table: xxx）丢失。

      长度设上限：stack 可达数百行，落盘只需能定位的头几行 —— 取值走 ~/lib/text-clamp 的 LOG_DETAIL_MAX（"给人读的一行"预算， 上限与截断标记都收在那处，见 §16.2.4.48）。

      Parameters

      • e: unknown
      • maxLen: number = LOG_DETAIL_MAX

      Returns string
