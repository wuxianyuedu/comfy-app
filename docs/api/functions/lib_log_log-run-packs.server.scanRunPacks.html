    Function scanRunPacks

    • scanRunPacks(options: RunPackScanOptions): RunPack[]

      列 runs/ 下的运行包（新→旧），只保留有这个来源文件的包。

      过滤掉没有该来源文件的包是必要的而不是优化：一台机器上 ComfyUI 可能一直没 装（那几次运行根本没有 comfyui-runtime.log），把它们列进下拉，用户点开每 一项看到的都是空窗口 —— 那不是「历史」，是噪声。判据就是文件在不在。

      .zip 形态的包（保留策略对超 32MB 的包先压再删）不列：读它需要解压， 而那一层入口在 log/exports（诊断包）而不是这里。留在这里的后果是下拉里 出现一堆点开就报错的项，因此宁可明确不列，并把这件事写进规范。
