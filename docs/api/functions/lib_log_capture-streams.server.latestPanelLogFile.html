    Function latestPanelLogFile

    • latestPanelLogFile(dir?: string): string | null

      目录里按写入时刻最新的那份应用服务转录文件；取不到返回 null。

      文件名（nextjs-panel-<pid>-<毫秒>.log）不能按字面排序取最新：pid 是 变长十进制，字典序比较的是字符而不是数值，…-9876-… 会排在 …-12345-… 之后。于是「取最后一份」实际取到的是某次更早运行留下的文件——它的行时刻 早于本次会话起点，被 dropStaleEntries 整批裁掉，面板「应用服务」一路读到 的就是一个恒为空的来源（用户报的正是「应用服务一条也不显示」）。 与启动器侧 scripts/launcher-core/orchestrator.mjs 的 latestPanelTranscript 同一口径（那边一直按 mtime 取），只是它服务于失败诊断、这边服务于面板。

      本函数是「最新一份转录文件」在服务端进程内的唯一事实来源：读（路由）与 轮转（下面的 prune）都问它，两处各写一份必然漂移。

      • dir: string = NEXTJS_LOG_DIR

      Returns string | null
