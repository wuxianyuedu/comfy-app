    Function toKebabCase

    • toKebabCase(value: string): string

      驼峰 / 帕斯卡 → kebab-case。

      判据是逐字符的（不是 split 再 join）：每个大写字母前插一个 连字符并转小写，其余原样。

      三条刻意不做的花活（每一种都有人以为「该这样」，写下来才不会有人来加）：

      1. 不处理连续大写（HTTPServer → h-t-t-p-server，不是 http-server）—— 本仓库的档名全是单驼峰（canvasUi / popup）， 要处理缩写就得引入「哪里是词边界」的猜测；
      2. 不 trim 连字符（_base → _base，不是 -base）—— 前导下划线 是「私有」的语义，抹掉它等于改名字；
      3. 不转数字与符号（z2 → z2）—— 那不在本条账的形态里。

      已由 ~/lib/shell/overlay-z 的 zClass 消费（canvasUi → z-canvas-ui， 与 globals.css 的 @theme 变量逐字一致）。
