    • parseConsoleLine(line: string): ParsedConsoleLine

      把用户敲的一行拆成 file + args（不走 shell）。

      为什么不用 shell: true / cmd /c：那等于让引号、通配符、&&、重定向、 变量展开都交给平台的 shell 解析器，而两套解析器的规则不同（cmd 认 %VAR%、 sh 认 $VAR、^ 转义只有 cmd 有）—— 同一行在 Windows 与 POSIX 上会跑出 不同的东西，而界面只能有一份「回显的命令」。这里只认空格分段的引号语法 （单引号与双引号都支持，反斜杠转义引号），拼不出 ; / | / > 这类 控制符的语义 —— 要那类语义就写个小脚本（node -e / scripts/*.mjs）， 而不是在输入框里叠一层 shell。

      判据表（也是单测夹具）： · pnpm exec tsc --noEmit → file=pnpm, args=["exec","tsc","--noEmit"] · echo "a b" 'c d' → file=echo, args=["a b","c d"] · echo a\ b → file=echo, args=["a b"] · `` (空 / 全空白) → ok:false, reason=「命令为空」 · echo "未闭合 → ok:false, reason=「引号未闭合」
