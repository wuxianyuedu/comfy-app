    Type Alias ModeContractRequired

    ModeContractRequired: ModeContractInputId[]

    一个契约口在这一模式下是否必备。

    必备 = 工坊/运行环节少不得它：缺了它这条工作流在工坊里驱动不起来（也是 「这条流能不能跑」的判据 —— 与工作流的可执行性是两个问题，别混）。

    为什么做成配置而不是写死：以前判据是代码里一句「id === "prompt"」， 于是「负向提示词要不要必备」「时长对视频是不是必备」这类问题的答案只能靠改 代码。用户口径是「哪个是必备的应该能配」（ISSUE #632）—— 现在它随契约走， 在「模式契约」编辑器里按模式勾选。

    没勾任何口 = 这条模式没有必备口（工坊不因缺某个口而判它不可用）。
