    Type Alias StyleLabCellWithStatus

    StyleLabCellWithStatus: StyleLabCellRow & {
        imageUrl: string | null;
        status: string | null;
    }

    详情用的格子行 = 格子本体 + 它那条任务的当前状态。

    status 不是 styleExperimentCell 的列，而是按 taskId 从 task 联表读回来的 （状态归任务域管，格子表只记归属）。这里仍把它并进同一份 DTO，是因为视图要按格显示 「排队中 / 生成中 / 已完成」——让视图自己去发第二次任务查询，就等于把这一屏的读 拆成两个来源，两边各拿到不同时点的状态时，界面上会出现「格子说在跑、任务说没了」。

    没任务的格子给显式 null 而不是缺键：视图要分得开「还没入队」与「查不到状态」。

    Type Declaration

    • imageUrl: string | null

      这一格产出的第一张图（浏览器可直接引用的地址）；没出图、或产物不是图片时为 null。

      它是读时派生、不是第三份存储：地址从那条任务的 resultImages 里取（任务域 是产物路径的唯一真值），格子表照旧只存 taskId。矩阵按格显示成品的代价就是 详情要多联一次任务表，换掉的是「格子表自己抄一份路径」那种会漂的写法。
