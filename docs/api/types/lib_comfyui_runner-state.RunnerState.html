    lastNodeByTask

    lastNodeByTask: Map<string, { classType: string; node: string; t: number }>

    R-ardot111 (2026-08-17): per-node completion tracking. When ComfyUI emits executing with data.node !== null we record the (node, classType) here; on the next executing with data.node === null we log "✔ 节点 X (classType) 完成" using the recorded values. This gives the user a clear per-node timeline in the log panel, not just "started" markers.
