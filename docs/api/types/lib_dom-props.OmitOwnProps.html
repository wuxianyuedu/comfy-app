    Type Alias OmitOwnProps<Base, Keys>

    OmitOwnProps: Omit<Base, Extract<Keys, keyof Base>>

    类型侧的剔除：Omit 的具名封装。

    与直接写 Omit<Base, "a" | "b"> 等价 —— 存在的意义是让「这一串键是本基元的 私有字段」在类型上有一个说得出口的名字（读代码的人不必去对比解构）， 并且让下面那对 keys / splitDomProps 能在同一行里被引用。

    用法：先写一份 as const 的私有键表，再用它同时算类型与运行时 ——

    const PRIVATE = ["type", "value", "onChange"] as const; // 私有键表，只写一遍
    type Props = OwnProps<React.ComponentProps<"input">, typeof PRIVATE> & {}; // 类型侧
