    autoSyncLocalWorkflow

    autoSyncLocalWorkflow: boolean

    查看「绑定到本地文件的工作流」详情时，是否自动把磁盘上的最新内容同步回库。

    默认 false（手动）：进详情只检出磁盘有没有更新、不写库，真正的更新入口 是工作流库里的「同步」按钮（workflow.resync）—— 否则「切界面」就等于 「同步」，用户还没决定内容就变了、标记也翻回无更新（PR #806 修的就是这个）。

    开启后，「进详情」等价于「点同步」：检出到磁盘有更新就立刻重导入并落库， 用户无需回到列表点按钮。两种入口复用同一条重导入链路（reimportFromSource）， 产物一致。

    comfyCliPython

    comfyCliPython: string

    驱动 ComfyUI 的 comfy-cli Python 解释器（执行链用它跑 -m comfy_cli run）。

    留空 = 退回 <cwd>/python-venv/comfy-cli/{Scripts|bin}/python(.exe)（开发检出的 默认落点）。桌包不随包 Python 与 comfy-cli（百 MB 级环境，且带版本矩阵）， 所以桌面形态要真出图必须由用户自备一个装好 comfy-cli 的解释器，然后在这里指 路径——与 comfyuiPath「用户自备 + 设置项」同一条形态（ISSUE #1239 的签字口径）。

    默认值取 COMFY_CLI_PYTHON：与 comfyuiPath ← COMFYUI_PATH 同形，即环境变量是 这一项的默认值，设置页里填过的值优先（getSettingsSync 是 {...DEFAULTS, ...文件}）。

    comfyuiPath

    comfyuiPath: string

    ComfyUI 安装目录。 comfyuiPath 语义（配置的目录可以不是源码根本身）：

    • 便携版：\python_embeded\python.exe + \main.py
    • 桌面版：配置「实例根」（如 ComfyUI-Installs\ComfyUI2）—— \standalone-env\python.exe + \ComfyUI\main.py（解释器 + 源码） 也可直接配置实例内的 ComfyUI/ 源码根，解释器会向上查找。
    • venv：.venv\Scripts\python.exe + \main.py（同上两件） 配置后任务执行前若 ComfyUI 未运行会自动拉起（comfyuiAutoStart）。

    exitKillComfyui

    exitKillComfyui: boolean

    应用进程退出时是否连带关闭自己拉起的 ComfyUI（进程保活开关，默认 false）。 语义：桌面壳退出是 taskkill /T /F 杀整棵进程树，被杀进程没有任何清理 机会，所以这个开关不是「退出时再决定」，而是「拉起时决定是否脱离进程树」。 true = ComfyUI 挂在应用进程树内，应用退出连带关闭；false = 脱离进程树 保活，下次打开应用直接复用。仅对本应用拉起的实例生效（外部启动的不归它管）。 改动会在「下一次拉起」生效。

    默认取「保活」：ComfyUI 冷启动 + 加载模型是分钟级的成本，默认随应用退出 连杀会让每次打开应用都要重付一遍；且被杀时正在跑的任务没有机会收尾。
